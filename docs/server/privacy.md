# 개인정보와 데이터

친구 서버라도 최소한 **최소 수집, 목적 알리기, 동의 받기, 보관 기한** 네 가지는 지킨다. 서버 주소·지도·저장소(공개)가 외부에 노출될 수 있다는 전제로 설계한다.

## 1. 데이터 목록

| 데이터 | 어디 | 누가 보나 | 보관 |
|---|---|---|---|
| 디스코드 ID ↔ 마크 UUID 연동 | 봇 DB | 운영자 | 시즌 동안 |
| 커스텀 닉네임 | 봇 DB, 서버 캐시 | 모두(게임·디스코드) | 시즌 동안 |
| 접속 가능 시간대(가입 때) | 봇 DB | 운영자(팀 편성용) | **시즌 종료 시 삭제** |
| 상호평가 원자료 | 봇 DB | 아무도 화면으로 못 봄(집계만) | **시즌 종료 시 삭제**, 집계만 남김 |
| 접속 기록 | 봇 DB | 운영자 | **시간대별 접속자 수(집계)만 저장.** 개인별 접속·퇴장 시각은 저장하지 않는다 |
| K/D/A, 좀비 통계 | 서버 `SavedData` | 모두(`/info`) | 시즌 동안 |
| K/D/A 원장 | 서버 `SavedData` | 운영자(분쟁 확인) | 좌표 대신 지역 이름, 시즌 종료 시 삭제 |
| 블록 변경 기록(Ledger) | 서버 | 운영자 | 30일 |
| 서버 로그 | 서버 | 운영자 | 7일 순환 삭제. 접속 IP·채팅이 남으므로 외부 공유 금지 |
| 생존일지 | 디스코드 | 생존자 역할 | 디스코드 메시지로 남음 |

## 2. 생존일지

- 게임 안 사건만, 닉네임으로만 쓴다. 좌표·정확한 시각·접속 시간·채팅·마크 이름·디스코드 계정은 입력 모델에 칸 자체가 없다.
- 외부 AI 서비스로 보내지 않는다(로컬 규칙 기반 생성).
- 표시 동의를 끈 사람은 '한 생존자'로, 웃긴 기록(반복 사고)은 동의한 사람만.
- 상세: simpleNationWar [diary.md](https://github.com/menonng/simpleNationWar/blob/HEAD/docs/discord/diary.md).

## 3. 닉네임 속 개인정보

닉네임 자체에 실명·학교·출생연도·연락처가 들어갈 수 있다. 가입 때 검사기가 거절하거나 운영자 확인으로 돌린다. 상세: simpleNationWar [nickname.md](https://github.com/menonng/simpleNationWar/blob/HEAD/docs/design/nickname.md) 3절.

## 4. 외부 노출 지점

| 지점 | 위험 | 대책 |
|---|---|---|
| 마크 서버 주소 | 서버 목록 핑에 접속자 이름이 보인다 | `server.properties` 의 `hide-online-players=true`, query·RCON 끄기(또는 localhost), 연동 안 된 계정 접속 차단 |
| 웹 지도 | 주소만 알면 누구나 본다 | 리버스 프록시 **기본 인증 필수**, 팝업에는 닉네임만, 실시간 위치·지하 비공개 |
| 디스코드 | 초대 링크 유출 | 생존일지·알림은 생존자 역할만, 초대 링크는 만료형 |
| 봇 DB·로그 | 같은 머신 | 봇 통신은 127.0.0.1, 백업 파일 외부 공유 금지 |
| GitHub 저장소(공개) | 커밋된 파일은 누구나 본다 | 실제 설정·토큰·친구 닉네임·접속 데이터는 커밋하지 않는다. 시뮬레이션 보정도 집계만, 저장소 밖에서 |

## 5. 가입 시 동의 항목

디스코드 가입 모달에 넣는다.

- [필수] 닉네임에 실명·학교·나이·연락처·사는 곳을 넣지 않았다
- [기본 켬] 생존일지에 내 닉네임 표시 (끄면 '한 생존자')
- [기본 끔] 웃긴 기록(같은 사고 반복 등)에 나와도 좋다
