# 플레이 양상·재미도 시뮬레이션

서버 전체 인원과 활성 인구에 따라 실제로 어떤 그림이 나올지, 그리고 설계 선택지(좀비화 산정 방식, 국가 편성 방식)가 어떤 차이를 만드는지 보기 위한 에이전트 기반 몬테카를로 시뮬레이션이다.

- 코드: [tools/sim/zomapo_sim.py](../../tools/sim/zomapo_sim.py) (파이썬 표준 라이브러리만 사용)
- 출력 원본: [tools/sim/results.md](../../tools/sim/results.md)
- 재현: `python3 tools/sim/zomapo_sim.py --runs 300 --seed 20270104` (약 1분)

> 수치는 **예측이 아니라 비교용 지표**다. 특히 '재미'는 아래 가정으로 만든 점수이므로 절대값보다 방식 간 차이를 본다. 개장 첫 주의 실제 접속 기록으로 가정을 보정해서 다시 돌리는 것을 권한다.

## 1. 모델

### 1-1. 시즌과 플레이어

- 기간: 2027-01-04(월) ~ 2027-03-14(일), 70일. 실제 개장 예정일(1/9, [roadmap.md](roadmap.md))보다 며칠 앞서 잡았지만 주 단위 경향은 같다. 2027-03-01 부터 '학생' 플레이어(기본 50%)는 접속 확률 ×0.65, 세션 길이 ×0.8.
- 플레이어 아키타입 (활성 인구 = 핵심 유저 수)

| 아키타입 | 평일 접속 확률 | 주말 접속 확률 | 평균 세션 | 하루 평균 | 특징 |
|---|---|---|---|---|---|
| 핵심 | 0.90 | 0.93 | 3.0h | 약 2.7h | '활성 인구'(하루 2시간 이상) |
| 일반 | 0.45 | 0.65 | 1.7h | 약 0.9h | |
| 라이트 | 0.12 | 0.45 | 1.5h | 약 0.3h | 주말 위주 |
| 유령 | 0.35 → 급감 | 0.45 → 급감 | 1.2h | 첫 2주 뒤 거의 0 | 초반에만 접속 |

- 인원 구성: 활성 인구를 뺀 나머지를 일반 40%, 라이트 35%, 유령 나머지로 나눈다. 15명/활성 4명 = 핵심 4·일반 4·라이트 4·유령 3.
- 첫 주 신선도 보너스(접속 확률 최대 ×1.4, 지수 감소), 금요일·주말은 세션 ×1.2.
- 세션 시작 시각: 평일 21시 전후, 주말 17시 전후(넓은 분포). **이 분포는 가정**이므로 시간대 표는 가정의 결과일 뿐이다.

### 1-2. 한 시간 동안 일어나는 일

- 같은 국가 국민이 접속해 있으면 65% 확률로 함께 논다(그룹).
- 접속 시간의 60% 는 자국 영토·접경, 40% 는 야생에 있다.
- 장비 수준 P = 5 × (1 − e^(−누적 플레이시간/50)). 50시간에 3.2, 100시간에 4.3. 그룹이면 +0.7.
- 좀비 처치 수 ~ 포아송((5 + 4Z) × (0.6 + 0.4·P/5)), 처치당 점수 1 + 0.5Z (Z = 그 자리의 감염 레벨).
- 사망 확률 = 0.035 × e^(0.8(Z − P)) × (솔로 1.25 / 그룹 0.8).
- PvP: 두 국가에 모두 접속자가 있으면 시간당 0.07 × √(양쪽 인원 곱) 회 조우, 보급 투하 시간(수·금 22시)에는 +0.45. 조우의 60% 가 교전. 승률은 (1+P) 합의 제곱 비. 진 쪽 1명(30% 확률로 2명) 사망, 킬러 외 이긴 쪽은 75% 확률로 어시스트.
- 블러드문: 토요일 21시, 처치 ×2.5, 사망 위험 ×1.8.

### 1-3. 재미 점수 (시간당)

| 요소 | 값 |
|---|---|
| 기본 | 1.5 |
| 사회 | 국민과 함께 2.0 / 국민이 접속했지만 따로 1.0 / 다른 국가 사람만 있음 0.4 / 서버에 혼자 0 |
| 몰입(난이도 적합) | 3.0 × e^(−((Z − P − 0.3)/1.4)²) — 레벨이 장비보다 조금 높을 때 최대 |
| 성장 | 1.2 × (1 − e^(−얻은 점수/15)) |
| 이벤트 | 블러드문 그룹 참여 +1.5, 솔로 +0.3 / PvP 교전 참여 +1.0, 승리 +0.8, 피살 −1.5 |
| 사망(PvE) | −1.2 |

하루 평균 재미가 4.6 보다 높으면 다음 날 접속 의욕이 오르고 낮으면 내려간다(민감도: 핵심 0.015 ~ 유령 0.05, 접속하지 않은 날은 평소 수준으로 천천히 회복). 의욕이 0.35 아래로 떨어지면 사실상 이탈한다.

### 1-4. 좀비화 산정 방식

| 방식 | 국가 영토 레벨 | 영토 밖 |
|---|---|---|
| A. 누적 합계 | k × Σ 국민 누적 좀비 스코어 | 0 |
| B. 누적 평균 | k × 평균(국민 전원) | 0 |
| C. 누적 중앙값 | k × 중앙값(국민 전원) | 0 |
| D. (평균+중앙값)/2 | k × (B + C)/2 | 0 |
| E. 편차 보정 평균 | k × 평균(각 값을 평균+1σ 로 상한) | 0 |
| F. 추천 하이브리드 | G(t) + k × ln(1 + 최근 7일 처치 수 / 최근 7일 활동 국민 수 / 100) − 정화 | G(t) + 0.3 |
| G. F + 개인 숙련도 보정 | F 와 같음. 실제 스폰 레벨을 [P − 1, P + 1.5(솔로일 때만)] 로 보정 | 같음 |

- G(t) = 2.0 × (1 − e^(−day/30)), 정화 = min(1, 0.12 × √(최근 7일 국가 그룹 플레이 시간)).
- **공정한 비교를 위해** 모든 방식은 15명/활성 4명에서 6주차 마지막 날 평균 영토 레벨이 3.0 이 되도록 k 를 보정했다. 10명/활성 3명에도 같은 k 를 그대로 썼다(서버 설정은 같은데 인원만 다를 때를 보려고).
- A~E 의 '영토 밖 0' 은 원안("소속 국가의 영토 전체와 그 주변 청크의 레벨을 올린다")을 그대로 옮긴 것이다. 산정 방식 자체의 차이는 '국가 간 격차'와 '상관' 열에서 본다.

### 2-2. 인원별 플레이 양상 서술

- **10명 / 활성 3명**: 평일 밤 접속자는 대개 1~2명. 핵심 유저 한 명이 사실상 국가 하나를 혼자 운영한다. 플레이 시간의 28% 는 서버에 아무도 없다. PvP 는 주 2회꼴이라 '국가전쟁'보다 '이웃 생존자 마을'에 가깝다. 블러드문에 국민끼리 모이는 경우가 13% 뿐이다.
- **12명 / 활성 3~4명**: 평일 22시에 2~3명. 다른 국가 사람과 마주치는 일이 생기기 시작한다. 국가 내부 협동은 여전히 저녁 일부 시간에만.
- **15명 / 활성 4명**: 평일 22시 피크 약 3명. 한 국가에 핵심 2명이 들어가는 편성(2/1/1)이 되므로 그 국가는 함께 노는 시간이 생긴다. 주말 오후에 다른 국가 사람과 겹치는 시간이 가장 많다.
- 공통: 첫 주는 거의 전원(15명 중 14.4명)이 들어오지만 4주차에 약 12명으로 줄고, 3월 개학 이후 하루 2시간 이상 유저가 3.8명 → 2.1명으로 떨어진다.
- 핵심 유저는 장비가 빨리 올라 레벨이 따라오지 못하면 '너무 쉬움' 구간에 머물러 재미가 가장 낮다(4.45). 라이트 유저는 장비가 낮아 난이도가 잘 맞고 주말에 겹치는 사람이 많아 재미가 가장 높다.

읽는 법:

1. **누적 방식(A~E)은 끝없이 오른다.** 6주차에 3.0 으로 맞췄는데 10주차에 4.6~4.8 이다. 시즌 후반에는 모든 영토가 상한 근처에 붙어 레벨이 의미를 잃고, 국가가 레벨을 낮출 방법이 없다.
2. **국가 간 격차가 크다.** 같은 시점에 한 국가는 Lv1, 다른 국가는 Lv4 인 일이 흔하다(격차 1.7~3.2). 활동량과 레벨의 상관이 0.9 에 가까운 B·E 에서는 열심히 하는 국가가 계속 어려워지고, 그 국가의 라이트 유저가 그 난이도를 그대로 맞는다.
3. **중앙값(C)은 불안정하다.** 국민 대다수가 접속이 적어 점수가 0 근처라, 중앙값이 비활성 국민에게 끌려간다. 격차가 가장 크다.
4. **합계(A)는 인원 수에 묶인다.** 15명(5/5/5)에서는 평균(B)과 똑같지만, 같은 설정으로 10명 서버가 되면 레벨이 절반 이하로 떨어진다. 인원이 바뀔 때마다 다시 맞춰야 한다.
5. **원안의 '영토 밖 0' 은 야생을 너무 쉽게 만든다.** '너무 쉬움'이 46~59% 인 주된 이유다. 아포칼립스라면 야생이 오히려 더 위험해야 한다.
6. **하이브리드(F, G)** 는 레벨이 2.5~3.5 사이에서 안정되고 국가 간 격차가 0.5~0.8 레벨로 작다. 최근 7일만 보므로 쉬었다 돌아온 국가도 감당 가능한 레벨에서 다시 시작한다. 처치 수를 로그로 눌러서 '레벨↑ → 처치↑ → 레벨↑' 의 자기 증폭을 막는다.
7. **개인 숙련도 보정(G)** 은 '너무 쉬움'을 35% → 15%(15명), 29% → 8%(10명)로 줄인다. 다만 G 의 재미 우위 일부는 몰입 점수를 '레벨과 장비의 차이'로 정의한 모델 구조에서 나온다는 점을 감안해야 한다.

랜덤 편성은 핵심 유저가 한 국가에 몰릴 때 그들끼리 노는 시간이 늘어 '자국민 없이 노는 시간'이 조금 줄지만, 대신 아무도 없는 국가가 생긴다. 국가 간 플레이시간 차이가 2.6~3.4배까지 벌어진다.

## 3. 설계에 반영한 것

| 발견 | 반영 |
|---|---|
| 플레이 시간의 59~74% 는 자국민 없이 논다 | 국고·국가 프로젝트·연구 납품 같은 비동기 협동, 국가 간 교역·동맹, 서버 공동 이벤트(최후의 호드) |
| 블러드문 국가 단위 단체참여율 13~23% | 블러드문은 국가와 무관하게 근처 누구나 함께 막을 수 있게, 방어 성공 보상은 참여자 전원에게 |
| 서버 전체 PvP 교전 주 2~3.5회 | 보급 투하·거점전으로 '만나는 자리'를 일정에 박는다. 우연한 조우만으로는 K 가 거의 쌓이지 않는다 |
| KDA(전체 사망) ≈ 0.8~1.0, PvP 사망만 세면 ≈ 1.7~1.9 | D 를 '모든 사망'으로 두면 KDA 는 PvP 실력보다 생존력 지표가 된다. 원래 정의대로 표시하되 툴팁에 PvP 사망 기준 KDA 를 함께 보여 준다 |
| 3월 개학 후 핵심 유저 3.8 → 2.1명 | 클라이맥스를 2월 마지막 주에 둔다 |
| 누적 방식의 단조 증가·격차·인원 의존 | 좀비화는 하이브리드(G)로 |
| 핵심 유저가 '너무 쉬움'에 오래 머문다 | 개인 숙련도 보정, 알파 좀비·둥지·스타포스 같은 후반 목표 |
| 랜덤 편성 시 핵심 0명 국가 확률 40~73% | 상호평가 기반 균형 편성 |

## 4. 한계

- 플레이어 행동(어디서 무엇을 할지)을 확률로만 다룬다. 실제로는 기지 위치·친분·디스코드 음성 채널이 동시 접속을 크게 바꾼다.
- 재미 점수의 계수는 경험적 추정이다. 방향(어떤 요소가 재미를 올리고 내리는지)은 일반적인 멀티플레이 설계 원칙을 따랐지만 크기는 검증되지 않았다.
- 설날 연휴(2027년 2월 초), 시험 기간 같은 개인 일정은 넣지 않았다.
- 개장 후 1~2주의 실제 접속 로그(디스코드 봇이 수집)로 아키타입 확률과 세션 시각을 다시 맞추면 2~10주차 예측이 쓸 만해진다.
