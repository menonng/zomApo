# 플레이 양상·재미도 시뮬레이션

서버 전체 인원과 활성 인구에 따라 실제로 어떤 그림이 나올지, 그리고 설계 선택지(좀비화 산정 방식, 국가 편성, 블러드문 방식, 치료제 방식)가 어떤 차이를 만드는지 보기 위한 에이전트 기반 몬테카를로 시뮬레이션이다.

- 코드: [tools/sim/zomapo_sim.py](../../tools/sim/zomapo_sim.py) (파이썬 표준 라이브러리만 사용)
- 출력 원본: [tools/sim/results.md](../../tools/sim/results.md)
- 재현: `python3 tools/sim/zomapo_sim.py --runs 300 --seed 20270116` (약 1분)

> 수치는 **예측이 아니라 비교용 지표**다. 특히 '재미'는 아래 가정으로 만든 점수이므로 절대값보다 방식 간 차이를 본다. 개장 첫 주의 실제 접속 기록으로 가정을 보정해서 다시 돌리는 것을 권한다.
>
> 시즌을 **2027-01-16(토) ~ 2027-02-07(일), 23일**로 줄인 판이다. 앞선 판(1/4 ~ 3/14, 10주)의 결과는 폐기했다.

## 1. 모델

### 1-1. 시즌과 플레이어

- 기간 23일. 시간은 모두 현실 시간이다(게임 시간은 4절 보름달 방식에만 쓴다).
- **겨울방학**: '학생' 플레이어(기본 50%, 가정)는 평일에도 주말처럼 접속한다(평일·주말 접속 확률의 평균, 오후부터 시작).
- **설 연휴**: 2/5~2/7 은 접속 확률 ×0.8(가족 일정, 가정).
- 플레이어 아키타입 (활성 인구 = 핵심 유저 수)

| 아키타입 | 평일 접속 확률 | 주말 접속 확률 | 평균 세션 | 하루 평균 | 특징 |
|---|---|---|---|---|---|
| 핵심 | 0.90 | 0.93 | 3.0h | 약 2.7h | '활성 인구'(하루 2시간 이상) |
| 일반 | 0.45 | 0.65 | 1.7h | 약 0.9h | |
| 라이트 | 0.12 | 0.45 | 1.5h | 약 0.3h | 주말 위주 |
| 유령 | 0.35 → 급감 | 0.45 → 급감 | 1.2h | 첫 2주 뒤 거의 0 | 초반에만 접속 |

- 인원 구성: 활성 인구를 뺀 나머지를 일반 40%, 라이트 35%, 유령 나머지로 나눈다. 15명/활성 4명 = 핵심 4·일반 4·라이트 4·유령 3.
- 첫 주 신선도 보너스(접속 확률 최대 ×1.4, 지수 감소), 금요일·주말은 세션 ×1.2.
- 세션 시작 시각: 평일 21시 전후, 주말·방학 평일 17시 전후. **이 분포는 가정**이므로 시간대 표는 가정의 결과일 뿐이다.

### 1-2. 한 시간 동안 일어나는 일

- 같은 국가 국민이 접속해 있으면 65% 확률로 함께 논다(그룹). 예고된 큰 이벤트(블러드문) 때는 국가와 무관하게 80% 가 모인다.
- 접속 시간의 60% 는 자국 영토·접경, 40% 는 야생에 있다.
- 장비 수준 P = 5 × (1 − e^(−누적 플레이시간/50)). 25시간에 2.0, 50시간에 3.2. 그룹이면 +0.7.
- 좀비 처치 수 ~ 포아송((5 + 4Z) × (0.6 + 0.4·P/5)), 처치당 점수 1 + 0.5Z.
- 사망 확률 = 0.035 × e^(0.8(Z − P)) × (솔로 1.25 / 그룹 0.8).
- PvP: 두 국가에 모두 접속자가 있으면 시간당 0.07 × √(양쪽 인원 곱) 회 조우, 보급 투하(수·금 22시)에는 +0.45. 조우의 60% 가 교전. 블러드문 중에는 PvP 없음.
- 연구 진척(5절): 접속 1시간당 (그룹 1.5 / 솔로 1.0) × (0.8 + 0.4·P/5), 블러드문 참가 +1.0, 보름달 밤 +0.5.

### 1-3. 재미 점수 (시간당)

| 요소 | 값 |
|---|---|
| 기본 | 1.5 |
| 사회 | 함께 놂 2.0 / 국민이 접속했지만 따로 1.0 / 다른 국가 사람만 있음 0.4 / 서버에 혼자 0 |
| 몰입(난이도 적합) | 3.0 × e^(−((Z − P − 0.3)/1.4)²) |
| 성장 | 1.2 × (1 − e^(−얻은 점수/15)) |
| 이벤트 | 블러드문 그룹 +1.5·솔로 +0.3 / 보름달 밤 그룹 +0.8·솔로 +0.4 / PvP 교전 +1.0, 승리 +0.8, 피살 −1.5 |
| 사망(PvE) | −1.2 |

하루 평균 재미가 4.6 보다 높으면 다음 날 접속 의욕이 오르고 낮으면 내려간다. 의욕이 0.35 아래로 떨어지면 사실상 이탈한다.

### 1-4. 좀비화 산정 방식

| 방식 | 국가 영토 레벨 | 영토 밖 |
|---|---|---|
| A. 누적 합계 | k × Σ 국민 누적 좀비 스코어 | 0 |
| B. 누적 평균 | k × 평균(국민 전원) | 0 |
| C. 누적 중앙값 | k × 중앙값(국민 전원) | 0 |
| D. (평균+중앙값)/2 | k × (B + C)/2 | 0 |
| E. 편차 보정 평균 | k × 평균(각 값을 평균+1σ 로 상한) | 0 |
| F. 하이브리드 | G(t) + k × ln(1 + 최근 72시간 처치 수 / 최근 72시간 활동 국민 수 / 40) − 정화 | G(t) + 0.3 |
| G. F + 개인 숙련도 보정 | F 와 같음. 실제 스폰 레벨을 [P − 1, P + 1.5(솔로일 때만)] 로 보정 | 같음 |

- G(t) = 2.0 × (1 − e^(−day/10)), 정화 = min(1, 0.18 × √(최근 72시간 국가 그룹 플레이 시간)).
- 모든 방식은 15명/활성 4명에서 **2주차 마지막 날(1/29)** 평균 영토 레벨이 3.0 이 되도록 k 를 보정했다. 10명/활성 3명에도 같은 k 를 그대로 썼다.

### 2-1. 인원별 서술

- **10명 / 활성 3명**: 평일 밤 접속자는 대개 1~2명. 핵심 유저 한 명이 사실상 국가 하나를 혼자 운영한다. 플레이 시간의 33% 는 서버에 아무도 없다.
- **12명 / 활성 3~4명**: 평일 22시에 2명 안팎. 다른 국가 사람과 마주치기 시작한다.
- **15명 / 활성 4명**: 평일 22시 2.6명, 주말 18~19시 2.9명. 한 국가에 핵심 2명이 들어가는 편성(2/1/1)이 되므로 그 국가는 함께 노는 시간이 생긴다.
- **3주 시즌은 신선도 곡선과 잘 맞는다.** 주 1시간 이상 접속은 15명 중 14.7 → 12.4명으로 완만하게 줄고, 하루 2시간 이상 유저는 방학 효과로 3주 내내 4.3~4.6명을 유지한다(앞선 10주 판에서는 3월 개학 후 2.1명으로 떨어졌다).
- **PvP 킬은 거의 쌓이지 않는다.** 핵심 유저 1인당 시즌 PvP 킬 1.7~2.1회. KDA 는 전체 사망 기준 0.5~0.7, PvP 사망만 세면 1.3~1.6.

읽는 법:

1. **누적 방식(A~E)은 3주 안에 상한에 붙는다.** 1/29 에 3.0 으로 맞췄는데 2/5 에 4.2~4.9, 마지막 날 4.4~5.0 이다. 마지막 주에는 레벨이 의미를 잃고, 국가가 레벨을 낮출 방법이 없다.
2. **국가 간 격차가 크다.** 같은 날 한 국가는 Lv1, 다른 국가는 Lv3~4 인 일이 흔하다(격차 1.8~2.6). 그 국가의 라이트 유저가 그 난이도를 그대로 맞는다.
3. **중앙값(C)은 불안정하다.** 접속이 적은 국민(점수 0 근처)에게 끌려가 격차가 가장 크다.
4. **합계(A)는 인원 수에 묶인다.** 15명(5/5/5)에서는 평균(B)과 똑같지만, 같은 설정으로 10명 서버가 되면 레벨이 절반 이하가 된다.
5. **원안의 '영토 밖 0' 은 야생을 너무 쉽게 만든다.** '너무 쉬움' 23~27% 의 주된 이유다.
6. **하이브리드(F, G)** 는 1.8 → 3.0 → 3.8 로 시즌 흐름에 맞게 오르고 국가 간 격차가 0.6~0.7 레벨로 작다. 최근 72시간만 보므로 하루 이틀 쉬었다 돌아와도 감당 가능한 레벨에서 다시 시작한다.
7. **개인 숙련도 보정(G)** 은 '너무 어려움'을 6~8% → 1% 로 줄인다. G 의 재미 우위 일부는 몰입 점수를 '레벨과 장비의 차이'로 정의한 모델 구조에서 나온다는 점을 감안한다.

## 6. 치료제 방식 비교

비용은 15명/활성 4명에서 선두 국가가 2/2 에 3단계를 끝내도록(레이스), 서버 전체가 2/3 에 끝내도록(공동) 맞췄다.

| 전체/활성 | 방식 | 비용 | 시즌 안 완성 확률 | 완성일(중앙값) | 우승국 = 플레이시간 1위 국가 | 꼴찌 국가 최종 진척 |
|---|---|---|---|---|---|---|
| 15/4 | R1. 국가 레이스 | 고정 | 100% | 2/3 | 96% | 95% |
| 15/4 | R2. 레이스 + 따라잡기 | 고정 | 100% | 2/2 | 98% | 100% |
| 10/3 | R1. 국가 레이스 | 고정 | 2% | 2/6 | 100% | 69% |
| 10/3 | R2. 레이스 + 따라잡기 | 고정 | 8% | 2/7 | 96% | 83% |
| 10/3 | R1. 국가 레이스 | 조정 | 100% | 2/3 | 91% | 97% |
| 10/3 | R2. 레이스 + 따라잡기 | 조정 | 100% | 2/2 | 97% | 100% |

| 전체/활성 | 방식 | 비용 | 시즌 안 완성 확률 | 완성일(중앙값) | 기여 1위 국가 몫 | 기여 꼴찌 국가 몫 |
|---|---|---|---|---|---|---|
| 15/4 | R3. 서버 공동 연구 | 고정 | 100% | 2/3 | 39% | 29% |
| 10/3 | R3. 서버 공동 연구 | 고정 | 0% | — | 37% | 30% |
| 10/3 | R3. 서버 공동 연구 | 조정 | 100% | 2/3 | 37% | 30% |

- 연구가 접속 시간에 비례하는 한 **레이스는 플레이 시간 1위 국가가 91~100% 이긴다.** 따라잡기는 모두를 완성시킬 뿐 순위를 바꾸지 못한다.
- **비용을 고정하면 인원이 줄었을 때 완성 확률이 0~8% 로 무너진다.** '2/3 까지 누적 연구량 ÷ 첫 72시간 연구량'은 인원과 무관하게 중앙값 6.0(10~90% 범위 5.3~7.0)이라, 개장 3일 뒤 활동량으로 비용을 정하면 규모와 관계없이 맞출 수 있다.
- 결론과 제안은 [bloodmoon-and-cure.md](../design/bloodmoon-and-cure.md) 2절: **서버 공동 연구 + 지역 표본 + 국가 기여 순위, 비용은 1/19 에 확정**.

## 7. 설계에 반영한 것

| 발견 | 반영 |
|---|---|
| 플레이 시간의 63~78% 는 자국민 없이 논다 | 국고·연구 납품 같은 비동기 협동, 국가 간 교역(지역 표본), 국가 무관 집결 이벤트 |
| 토 21시 고정 블러드문은 한 번이라도 겪는 사람이 32~35% | 동시 접속 트리거(48시간 간격)로 72~75% |
| 핵심 1인 시즌 PvP 킬 1.7~2.1 | 보급 투하·거점전을 일정에 박는다. KDA 툴팁에 PvP 기준 값을 함께 보여 준다 |
| 누적 방식은 3주 안에 상한 도달, 국가 격차 1.8~2.6 | 좀비화는 하이브리드(G), 창은 72시간 |
| 국가 레이스 = 플레이 시간 경쟁 | 치료제는 서버 공동 연구 |
| 비용 고정은 인원 변화에 취약 | 개장 3일 뒤(1/19) 활동량으로 비용 확정 |
| 랜덤 편성 시 핵심 0명 국가 확률 40~73% | 상호평가 기반 균형 편성 |

## 8. 한계

- 플레이어 행동(어디서 무엇을 할지)을 확률로만 다룬다. 실제로는 기지 위치·친분·디스코드 음성 채널이 동시 접속을 크게 바꾼다.
- 재미 점수의 계수는 경험적 추정이다.
- 학생 비율, 방학 중 접속 패턴, 설 연휴 영향은 모두 가정이다. 디스코드 가입 때 받는 '접속 가능 시간대'와 첫 주 실제 접속 기록으로 다시 맞춘다.
- 블러드문 트리거가 플레이어의 접속 행동 자체를 바꾸는 효과(함께 들어오기를 피하거나, 반대로 모이기)는 모델에 없다.
