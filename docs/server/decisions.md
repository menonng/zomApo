# 결정 사항 상세

각 항목은 **선택지 → 결정 → 이유 → 세부 규칙 → 다시 볼 조건** 순서로 적는다. 수치는 모두 설정 파일로 바꿀 수 있게 만든다.

---

## 0. 클라이언트 정책

| 선택지 | 장점 | 단점 |
|---|---|---|
| 바닐라 클라이언트 (서버 사이드 모드만) | 친구들이 설치할 것이 없다. 버전 올리기가 쉽다 | 새 블록·몹 모델 불가 |
| 모드팩 배포 | 표현 자유도 | 10~15명에게 설치·업데이트 지원 부담, 26.4 전환 때 모드 대기 |

**결정: 바닐라 클라이언트.** 필수 리소스팩도 두지 않는다. 별 표시(★), 변종 외형(머리 아이템, 크기 속성, 장비), 감염 표시(파티클, 액션바)처럼 바닐라 클라이언트가 그릴 수 있는 것만 쓴다.

선택 설치(없어도 플레이에 지장 없는 것)는 허용한다: Sodium 같은 성능 모드, Simple Voice Chat([modlist.md](modlist.md) 참고).

## 1. 주민 거래소(주민작) 허용 여부

거래 자체는 막지 않는다는 전제에서, 주민을 모아 거래소를 차리는 것을 어디까지 허용할지의 문제다.

| 선택지 | 결과 |
|---|---|
| 완전 허용 | 2주 안에 수선·효율 V 책이 쏟아지고 장비가 평준화된다. 아포칼립스의 결핍감이 사라진다 |
| 금지 | 주민의 존재 의미가 사라지고, 단속 기준이 애매하다 |
| **제한적 허용** | 주민이 귀한 자원이 된다 |

**결정: 제한적 허용.**

- **국가당 주민 상한** 12명(설정). 영토 안에서 상한을 넘는 주민이 생기면 가장 최근 주민부터 '피난민'으로 표시되고 거래가 잠긴다. 상한은 국가 GUI 에서 보인다.
- **영토 안 주민 번식 불가.** 주민은 마을에서 데려오거나, 좀비 주민을 치료해서만 얻는다. 감염 레벨이 오르면 마을이 좀비 주민으로 바뀌므로(어려움 난이도에서 주민은 좀비에게 죽으면 항상 좀비 주민이 된다) "치료해서 데려오기"가 자연스러운 목표가 된다.
- 철 농장은 허용한다. 주민 상한 안에서만 가능하므로 규모가 제한된다.
- 커스텀 인첸트는 주민 거래 목록에 넣지 않는다([enchantments.md](../design/enchantments.md)).

**다시 볼 조건**: 시즌 중반에 국가 간 장비 격차가 주민 수 때문에 벌어지면 상한을 조정한다.

## 2. 초기 정착지

| 선택지 | 결과 |
|---|---|
| 완전 랜덤 스폰 | 한 국가는 사막, 한 국가는 숲 같은 지형 격차. 국민끼리 흩어져 시작 |
| 자유 선택 | 초반 1~2일에 핵심 유저가 좋은 땅을 독점, 늦게 온 국가가 불리 |
| **반랜덤 공정 배치** | 공정성과 의외성을 함께 |

**결정: 반랜덤 공정 배치.**

1. 월드 중심(0, 0)에서 반경 약 1,200블록, 120° 간격의 세 지점을 후보로 잡는다. 수도 사이 거리는 약 2,080블록.
2. 각 후보지 주변 반경 160블록의 바이옴 구성(나무, 물, 평지, 동굴 입구)을 스크립트로 점수화해서 점수 차가 가장 작은 회전각·시드를 고른다. canvasworldgen 으로 맵을 직접 그리면 이 단계는 설계로 대신한다(아래 9번).
3. 국가와 후보지의 짝은 개장 방송에서 **무작위 추첨**한다.
4. 국민은 처음 접속하면 자국 후보지로 이동한다. 같은 자리에서 시작하니 첫날부터 '집단'이 된다.
5. 첫 주 안에 **수도 이전 1회**를 허용한다(후보지 반경 300블록 안). 다른 국가 수도 반경 600블록 안에는 수도를 둘 수 없다.
6. 중앙(0, 0)은 중립 구역 '생존자 캠프'(월드 스폰, 보호 구역, 공용 게시판)로 둔다.

## 3. 서버맵(BlueMap, squaremap) 공개 범위

| 선택지 | 결과 |
|---|---|
| 전체 공개 (플레이어 위치 포함) | 위치 추적으로 PvP 사냥이 쉬워지고 기지 위치가 그대로 드러난다 |
| 비공개 (운영자만) | 지도 연동을 만든 의미가 없다 |
| **부분 공개** | 지형·영토·감염은 공유, 실시간 위치·지하는 숨김 |

**결정: 부분 공개.**

| 레이어 | 공개 | 비고 |
|---|---|---|
| 지형 (지상) | O | 생성된 청크만 렌더된다 |
| 지하·동굴 | X | BlueMap 동굴 제거 설정, squaremap 지하 렌더 끔 |
| 플레이어 실시간 위치 | X | 양쪽 모두 플레이어 트래커 끔 |
| 국가 영토 | O | 국가 색 반투명 다각형, 팝업에 국가명·원수·국민 닉네임 |
| 수도·거점 | O | 거점 소유국 표시 |
| 감염 레벨 | O | 4×4 청크 단위 타일, Lv1 이상만 |
| 보급 투하 | 이벤트 중에만 | 투하 5분 전 공개 |
| 감염 둥지 | 발견된 것만 | 누군가 반경 32블록 안에 들어가면 공개 |

- 지도 주소는 디스코드 공지에만 올린다. 필요하면 리버스 프록시(nginx) 기본 인증을 붙인다.
- 영토가 보이는 것은 의도된 설계다. 서로의 위치를 알아야 교역·동맹·경계가 생긴다.

## 4. 목표

세 층으로 나눈다.

### 4-1. 국가 목표: 치료제 연구 레이스

각 국가는 수도에 **연구소**(바닐라 블록 구조물 + 국가 GUI 의 연구 탭)를 두고 5단계 연구를 진행한다. 가장 먼저 5단계를 끝낸 국가가 시즌 우승.

| 단계 | 이름 | 필요 조건 (예시, 비동기 납품 가능) |
|---|---|---|
| 1 | 표본 채취 | 좀비 변종 5종 처치, 바이러스 결정 32개 납품 |
| 2 | 배양 | 감염 둥지 2개 파괴, 감염 레벨 3 이상 지역에서 1시간 생존(누적) |
| 3 | 분석 | 위더 스켈레톤 좀비 머리 1개, 거점 1곳 48시간 보유 |
| 4 | 시험 | 블러드문 방어 성공 2회, 알파 좀비 처치 |
| 5 | 완성 | 엔더 드래곤 처치 참여, 최종 재료 납품 |

- 어느 국가든 한 단계를 끝내면 **서버 전체 전역 감염 램프가 잠깐 내려간다**(아래 서버 공동 목표). 경쟁 국가의 진척이 나에게도 이득이 되므로 방해보다 경쟁이 된다.
- 납품은 국고·연구 탭에 언제든 할 수 있다. 동시 접속이 적은 서버에서 비동기로 협동하는 장치다.

### 4-2. 서버 공동 목표: 감염 억제

전역 감염 램프(좀비화 문서의 G(t))는 시간이 갈수록 오른다. 연구 단계 완료, 블러드문 방어 성공, 둥지 파괴가 램프를 깎는다. 서버 전체 감염도는 디스코드 상태 채널에 매일 표시한다.

### 4-3. 개인 목표: 칭호와 통계

- 좀비 스코어 순위, K/KDA, 강화 최고 기록, 망자 회수율 같은 지표로 **칭호**를 준다. 칭호는 `/info` 와 탭 목록 닉네임 앞에 붙는다.
- 시즌 종료 시 디스코드 '명예의 전당'에 결산을 올린다.

### 4-4. 엔딩

첫 치료제 완성 또는 시즌 마지막 주(3월 둘째 주) 중 빠른 쪽에 **최후의 호드** 이벤트를 연다. 모든 국가가 중앙 생존자 캠프를 함께 지키는 협동 이벤트로 시즌을 닫는다.

## 5. 인벤세이브

| 선택지 | 결과 |
|---|---|
| keepInventory 켬 | 죽음이 가벼워져 하드 좀비 아포칼립스의 긴장이 사라진다 |
| 바닐라(끔) | 아이템이 5분 뒤 사라진다. 소수 인원 서버에서 이탈 사유 1순위 |
| 무덤 모드 | 안전하지만 테마와 무관 |
| **망자 좀비** | 사망 지점에 내 소지품을 든 좀비가 남는다. 처치하면 돌려받는다 |

**결정: keepInventory 끔 + 망자 좀비.** 처음 구상했던 "좀비에게 죽으면 추격자가 된다"를 인원이 적은 서버에 맞게 바꾼 것이다. 사람이 추격자가 되는 대신, 내 장비를 든 '나의 좀비'가 남는다.

- PvE 사망: 10분 동안 본인과 자국민만 망자를 공격할 수 있다.
- PvP 사망: 보호 시간 없음. 이긴 쪽이 바로 회수할 수 있는 것이 전투의 보상이다.
- 세부 규칙은 [death-and-revenant.md](../design/death-and-revenant.md).

## 7. PvP 정책

| 장소 | 플레이어 간 피해 | 블록 파괴·상자 |
|---|---|---|
| 야생 | 허용 | 허용 (주인 없는 땅) |
| 자국 영토 | 국민끼리 불가 | 국민만 |
| 타국 영토 | 적대 관계일 때만 허용 | 불가 (상시) |
| 생존자 캠프 | 불가 | 불가 |
| 거점 | 거점전 시간에 허용 | 불가 |

- **오프라인 약탈은 불가능하다.** 영토의 블록 보호는 전쟁 중에도 풀리지 않는다.
- 충돌의 장은 야생 조우, 보급 투하(수·금 22:00), 거점전이다. 시뮬레이션상 서버 전체 PvP 교전은 주 2~3.5회 수준이라 의도적으로 만나는 자리를 만들어야 한다.

## 8. 모드 채택

### 8-1. InfraCraft: 시즌 1 미채택

- 블록·아이템을 추가하는 모드라 클라이언트 설치가 필요하다(`environment: "*"`, 클라이언트 진입점 있음).
- Create Fly 와 함께 쓰는 것을 전제로 하고, 현재 26.2 만 지원한다. 26.3 은 공식 Create Fly 가 나와야 지원 예정이다.
- 겉날개 금지·네더 1:1 규칙은 매력적이지만 이동이 더 고되면 소수 인원 서버에서 서로 만나기가 더 어려워진다.

**다시 볼 조건**: 시즌 2 에서 모드팩 배포를 받아들이고, InfraCraft·Create Fly 가 26.4 를 지원할 때.

### 8-2. couriersRoost: 채택 (26.4 포팅 후)

- 서버 사이드 전용, 리소스팩 불필요, 26.1.2/26.2/26.3 지원. 같은 계정의 저장소라 26.4 포팅을 직접 할 수 있다.
- 채팅이 전서구로 실제로 날아가 도착해야 전달된다. '통신 두절된 아포칼립스'라는 테마에 잘 맞는다.
- 권장 설정: `bird_speed` 40, `bird_death_chance` 0.0(시즌 초반), `global_chat_cooldown` 5, `base_dimension_delay` 4. 블러드문 밤에는 `bird_death_chance` 를 올리는 이벤트 훅을 검토한다.
- 연동 주의점
  - 전서구는 닭 엔티티다. zomApo 의 좀비 변환·좀비 기수(아기 좀비가 닭을 타는 바닐라 동작) 대상에서 `courierpost_bird` 태그를 가진 개체를 뺀다.
  - 디스코드 연동은 채팅을 중계하지 않고 시스템 이벤트(사망, 접속, 국가 이벤트)만 보낸다. 채팅을 중계하면 전서구 지연이 무의미해진다.
  - 표시 이름: couriersRoost 가 발신자 이름을 `getName()` 으로 쓰는지 표시 이름으로 쓰는지 확인하고, 커스텀 닉네임이 보이도록 맞춘다.

### 8-3. biomesmod: 미채택

- 새 블록 84종(클라이언트 필수), TerraBlender 필수, 1.21.1 / 26.2 만 지원.
- 원칙 0번(바닐라 클라이언트)과 충돌한다.

**다시 볼 조건**: 모드팩 시즌에서 26.4 지원 시.

### 8-4. 기타 월드젠

- **canvasworldgen(MineWorldGen) 1순위.** 바닐라 블록·바이옴만 쓰는 월드 생성 데이터팩이고, 브라우저 디자이너로 대륙 모양·고도·기후·바이옴·지형 특징을 직접 그린다. 세 국가의 출발지를 대칭에 가깝게 설계하고, 중앙에 폐허·거점용 지형을 둘 수 있다. 서버에만 넣으면 된다.
  - 확인 필요: 현재 26.2 대상이다. 26.3(데이터팩 포맷 121.0) 과 26.4 에서 동작하는지, 26.4 의 얼음 동굴이 함께 생성되는지 테스트한다.
- 대안: 바닐라 생성 + 시드 탐색 스크립트(2번 항목의 점수화). 둘 다 안 되면 Tectonic 데이터팩 버전(바닐라 블록만 씀)을 검토한다.
- 구조물 데이터팩(던전·폐허류)은 바닐라 블록만 쓰는 것에 한해 선택 추가. 26.4 지원 여부를 보고 결정한다.

### 8-5. 가방 모드: 미채택

- 바닐라 번들(64 무게)과 셜커 상자로 충분하다. 인벤토리 압박은 "무엇을 들고 나갈까"라는 생존 긴장의 일부다.
- 서버 사이드 가방(Polymer 기반 Server Backpacks 등)은 26.3 빌드가 있지만, 착용하려면 클라이언트 쪽 모드가 필요하고 26.4 대응을 기다려야 하는 의존성이 늘어난다.
- 망자 좀비는 번들·셜커 상자 안의 내용물까지 그대로 보관한다.

### 8-6. Enchanting Infuser: 미채택

- 클라이언트와 서버 양쪽에 설치해야 하고 Puzzles Lib 이 필요하다. 확인된 Fabric 최신 빌드가 26.2 용이다.
- 원하는 인첸트를 고르는 재미는 커스텀 인첸트와 스타포스로 대신한다. 꼭 필요해지면 서버 사이드 상자 GUI 로 '선택 인첸트'를 zomApo 에 따로 만드는 편이 낫다.

### 8-7. 커스텀 인첸트: 채택

데이터팩으로 6종을 등록하고, 효과는 모드가 처리한다. 인첸트 정의는 클라이언트로 동기화되므로 정의 안에는 바닐라 효과 컴포넌트만 쓴다. [enchantments.md](../design/enchantments.md).

### 8-8. 스타포스: 채택 (순한 맛)

최대 15성, 파괴 없음, 연속 하락 보정. 강화 보너스는 좀비 계열에 100%, 플레이어에 30% 만 적용해 PvP 격차를 줄인다. [starforce.md](../design/starforce.md).

## 9. 월드 크기

| 항목 | 값 |
|---|---|
| 오버월드 월드보더 | 반경 3,000 (6,000 × 6,000) |
| 사전 생성 | Chunky 로 보더 전체 (서버 개장 전, 26.4 에서) |
| 네더 | 바닐라 8:1, 보더 반경 375 (오버월드 보더를 따라감) |
| 엔드 | 바닐라. 치료제 5단계와 연결 |

반경 3,000이면 수도 사이 약 2,080블록, 수도에서 보더까지 약 1,800블록 여유가 있다. 15명 서버에 넉넉하되 서로 마주칠 수 있는 크기다.

## 10. 국가 편성

**결정: 상호평가 기반 균형 편성안 → 플레이어 합의 → 운영자 확정.**

- 완전 랜덤 편성 시 핵심 유저가 한 명도 없는 국가가 생길 정확한 확률은 15명/활성 4명에서 45.1%, 10명/활성 3명에서 70.0% 다([simulation.md](simulation.md) 3-1).
- 디스코드 봇이 상호평가 결과와 접속 가능 시간대를 바탕으로 균형 편성안 상위 3개를 내고, 친구 묶음 같은 합의 조건을 반영한다. 세부 알고리즘은 simpleNationWar 의 [peer-rating.md](https://github.com/menonng/simpleNationWar/blob/HEAD/docs/discord/peer-rating.md).
- 시즌 중 이적은 원칙적으로 막고, 국가 간 활동 인원 차가 2명 이상으로 1주 넘게 유지되면 운영자가 이적 창을 연다.
