# 결정 사항 상세

각 항목은 **선택지 → 결정 → 이유 → 세부 규칙 → 다시 볼 조건** 순서로 적는다. 수치는 모두 설정 파일로 바꿀 수 있게 만든다.

> 시즌은 **2027-01-16 ~ 2027-02-07(23일)** 이다. 문서의 일·주·시간·분은 모두 현실 시간이고, 게임 시간은 '게임 일'로 따로 쓴다([bloodmoon-and-cure.md](../design/bloodmoon-and-cure.md) 0절).

## 0. 클라이언트 정책

| 선택지 | 장점 | 단점 |
|---|---|---|
| 바닐라 클라이언트 (서버 사이드 모드만) | 친구들이 설치할 것이 없다. 버전 올리기가 쉽다 | 새 블록·몹 모델 불가 |
| 모드팩 배포 | 표현 자유도 | 20명 안팎에게 설치·업데이트 지원 부담, 26.4 전환 때 모드 대기 |

**결정: 바닐라 클라이언트 + 선택 리소스팩.** 모드 설치는 없다.

- 2026-11-20 개정: 좀비화 몹을 '원종 모델에 좀비 느낌을 더한' 외형으로 보여 주려면 리소스팩이 필요하다(Fabric·Paper 모두 같다). 다만 **강요하지 않는다**(`require-resource-pack=false`). 거절해도 커스텀 플레이어 머리·바닐라 갑옷·디스플레이 엔티티·파티클로 된 '리소스팩 없는 외형'으로 플레이에 지장이 없다([visuals.md](../design/visuals.md) 0절).
- 리소스팩 내려받기는 처음 한 번, 접속할 때마다 몇 초의 적용 로딩은 있다.

선택 설치(없어도 플레이에 지장 없는 것)는 허용한다: Sodium 같은 성능 모드, Simple Voice Chat([modlist.md](modlist.md) 참고).

## 1. 주민 거래소(주민작) 허용 여부

거래 자체는 막지 않는다는 전제에서, 주민을 모아 거래소를 차리는 것을 어디까지 허용할지의 문제다.

| 선택지 | 결과 |
|---|---|
| 완전 허용 | 2주 안에 수선·효율 V 책이 쏟아지고 장비가 평준화된다. 아포칼립스의 결핍감이 사라진다 |
| 금지 | 주민의 존재 의미가 사라지고, 단속 기준이 애매하다 |
| **제한적 허용** | 주민이 귀한 자원이 된다 |

**결정: 제한적 허용.**

- **국가당 주민 상한** 12명(설정). 영토 안에서 상한을 넘는 주민이 생기면 가장 최근 주민부터 '피난민'으로 표시되고 거래가 잠긴다. 상한은 국가 GUI 에서 보인다.
- **영토 안 주민 번식 불가.** 주민은 마을에서 데려오거나, 좀비 주민을 치료해서만 얻는다. 감염 레벨이 오르면 마을이 좀비 주민으로 바뀌므로(어려움 난이도에서 주민은 좀비에게 죽으면 항상 좀비 주민이 된다) "치료해서 데려오기"가 자연스러운 목표가 된다.
- 철 농장은 허용한다. 주민 상한 안에서만 가능하므로 규모가 제한된다.
- 커스텀 인첸트는 주민 거래 목록에 넣지 않는다([enchantments.md](../design/enchantments.md)).

**다시 볼 조건**: 시즌 중반에 국가 간 장비 격차가 주민 수 때문에 벌어지면 상한을 조정한다.

**인원 상향 재검토(2026-11-20)**: 12명 유지. 상한이 '국가당'이라 국가당 인원이 5.0 → 6.7명(활성 1.3 → 3.3명)이 되면 국민 1인당 주민은 2.4 → 1.8명, 활성 1인당 9 → 3.6명으로 빡빡해진다([simulation.md](simulation.md) 2-2). '주민은 귀하다'는 의도에는 더 맞는 쪽이고, 거래는 국민이 나눠 쓰며 주민 보충은 하루 2번이라 바로 올릴 근거는 없다. 다만 시뮬레이션에 주민이 없어 계산이 아니라 추론이다. 상한 수치와 영토 상한식은 simpleNationWar [nation.md](https://github.com/menonng/simpleNationWar/blob/HEAD/docs/design/nation.md) 에 있으므로, 그쪽 상한이 국민 수나 국가 좀비 스코어 합에 비례하는지 확인해야 한다(국가 스코어 합 ×2.06, √ 보너스면 ×1.44).

## 2. 초기 정착지

| 선택지 | 결과 |
|---|---|
| 완전 랜덤 스폰 | 한 국가는 사막, 한 국가는 숲 같은 지형 격차. 국민끼리 흩어져 시작 |
| 자유 선택 | 초반 1~2일에 핵심 유저가 좋은 땅을 독점, 늦게 온 국가가 불리 |
| **반랜덤 공정 배치** | 공정성과 의외성을 함께 |

**결정: 반랜덤 공정 배치.**

1. **국가 스폰 지점(= 수도 후보지) 세 곳은 (0, 0) 에서 1,000블록 이상 3,000블록 미만인 고리 안**에 둔다. 공정성을 위해 세 지점의 중심 거리 차는 400블록 이내, 서로 1,500블록 이상, 중심에서 본 각도 차 90° 이상(대략 120° 간격). 판정 코드: simpleNationWar `logic` 의 `NationSpawn.validate`.
2. **시드 탐색 도구**로 후보 시드를 수천 개 채점해 세 후보지의 조건이 가장 비슷한 시드·회전각을 고른다(아래 8-4). 채점 항목: 후보지 반경 160블록의 바이옴 구성(나무, 물, 평지 비율), 바다·험지 비율, 마을 유무.
3. 국가와 후보지의 짝은 개장 방송에서 **무작위 추첨**한다.
4. **시즌 시작 전**에는 모두 중앙 생존자 캠프(대기실: 모험 모드, 피해 없음)에 모인다. 운영자가 **`/snw season start`** 를 치면 국가에 따라 모두 각자 국가 스폰 지점 주변으로 옮겨진다. 같은 자리에서 시작하니 첫날부터 '집단'이 된다.
   - **개인 스폰 지점**: 국가 스폰 지점에서 **40~60블록** 떨어진 무작위 땅 위(물·용암·나뭇잎 위·다른 국가 영토 제외). 시즌 시작 때 한 번 정해 저장하고, 침대·리스폰 정박기가 없을 때 이곳에서 되살아난다.
   - 시즌 시작 뒤 처음 들어오는 사람은 접속하자마자 자기 개인 스폰 지점으로 간다.
   - 수도를 옮기면(5번) 국가 스폰 지점이 옮겨지고, 국민 개인 스폰 지점도 새 자리 기준으로 다시 정한다.
5. 개장 후 72시간 안에 **수도 이전 1회**를 허용한다(후보지 반경 250블록 안). 다른 국가 수도 반경 400블록 안에는 수도를 둘 수 없다.
6. 중앙(0, 0)은 중립 구역 '생존자 캠프'(월드 스폰, 보호 구역, 공용 게시판)로 둔다.

## 3. 서버맵(BlueMap, squaremap) 공개 범위

| 선택지 | 결과 |
|---|---|
| 전체 공개 (플레이어 위치 포함) | 위치 추적으로 PvP 사냥이 쉬워지고 기지 위치가 그대로 드러난다 |
| 비공개 (운영자만) | 지도 연동을 만든 의미가 없다 |
| **부분 공개** | 지형·영토·감염은 공유, 실시간 위치·지하는 숨김 |

**결정: 부분 공개.**

| 레이어 | 공개 | 비고 |
|---|---|---|
| 지형 (지상) | O | 생성된 청크만 렌더된다 |
| 지하·동굴 | X | BlueMap 동굴 제거 설정, squaremap 지하 렌더 끔 |
| 플레이어 실시간 위치 | X | 양쪽 모두 플레이어 트래커 끔 |
| 국가 영토 | O | 국가 색 반투명 다각형, 팝업에 국가명·원수·국민 닉네임 |
| 수도·거점 | O | 거점 소유국 표시 |
| 감염 레벨 | O | 4×4 청크 단위 타일, Lv1 이상만 |
| 보급 투하 | 이벤트 중에만 | 투하 5분 전 공개 |
| 감염 둥지 | 발견된 것만 | 누군가 반경 32블록 안에 들어가면 공개 |

- 지도 주소는 디스코드 공지에만 올리고, 리버스 프록시(nginx) **기본 인증을 반드시** 붙인다([privacy.md](privacy.md)).
- 영토가 보이는 것은 의도된 설계다. 서로의 위치를 알아야 교역·동맹·경계가 생긴다.

## 4. 목표

> 친구들이 목적의식을 갖고 시간을 맞춰 주리라 기대하기 어렵고, 물질 보상을 걸어도 참여가 크게 늘지 않았다는 이전 테스트 결과에 따라 **목표를 '쫓는 것'에서 '겪는 것'으로** 바꿨다. 치료제 공동 연구·국가 레이스 검토 기록은 [bloodmoon-and-cure.md](../design/bloodmoon-and-cure.md) 2절에 남겨 둔다.

### 4-1. 큰 틀: 목표가 아니라 시계

- 감염은 시간이 갈수록 퍼지고(전역 램프), **2/7 에 세상이 끝난다.** 해야 할 일이 아니라 배경이다.
- 끝이 정해져 있으니 허전하지 않다. 마지막 밤(최후의 호드)은 그날 들어온 사람들끼리 치른다.

### 4-2. 일은 찾아오게

- 보름달 밤(게임 시간), 동시 접속 조건이 맞을 때 열리는 블러드문, 보급 투하, 감염 둥지. 참여 의무도, 일정을 맞출 필요도 없다.

### 4-3. 보상 대신 이야기와 인정

- **생존일지**: 매일 아침 디스코드에 전날 이야기를 자동으로 올린다. 시간이 안 겹치는 친구끼리도 서로의 이야기를 본다. 외부 AI 없이 규칙 기반으로 쓰고, 게임 안 사건과 닉네임만 쓴다(simpleNationWar [diary.md](https://github.com/menonng/simpleNationWar/blob/HEAD/docs/discord/diary.md), [privacy.md](privacy.md)).
- **생존 도감**: 커스텀 발전과제 30~50개(데이터팩, 바닐라 클라이언트에 알림 그대로). 하고 싶은 사람만, 깰 때마다 일지에 이름이 오른다.
- **칭호**: 웃긴 쪽 위주. `/info` 와 탭 목록 닉네임 앞.
- 시즌 종료 시 디스코드 '명예의 전당'.

### 4-4. 경쟁은 보여 주기만

- 국가별 좀비 스코어·영토·거점은 일지와 상태 채널에 순위로만 보여 준다. 상품이나 승패는 걸지 않는다.

### 4-5. 치료제는 엔딩 분기

- 게이지·단계 없이, 알파 좀비·감염 둥지에서 가끔 **백신 조각**이 나온다.
- 마지막 밤에 모인 조각 수에 따라 **구원 엔딩**(백신 로켓 발사 → 감염 지역이 차례로 정화되는 연출, monun series-survival 의 하이퍼 백신 연출을 옮긴 것, [monun.md](../reference/monun.md) 2절)과 **멸망 엔딩**이 갈린다.
- 신경 안 써도 되고, 누가 모아 뒀다면 깜짝 반전이 된다. 공동 연구 게이지·지역 표본 교역 의무·연구 비용 확정이 빠져 개발량과 운영 부담이 줄었다.

### 4-6. 성향 확인

디스코드 가입 모달에 '이 서버에서 주로 하고 싶은 것'(건축 / 전투 / 탐험 / 수집 / 수다)을 받아, 개장 전에 이벤트와 도감 항목의 비중을 맞춘다.

## 5. 인벤세이브

| 선택지 | 결과 |
|---|---|
| keepInventory 켬 | 죽음이 가벼워져 하드 좀비 아포칼립스의 긴장이 사라진다 |
| 바닐라(끔) | 아이템이 5분 뒤 사라진다. 소수 인원 서버에서 이탈 사유 1순위 |
| 무덤 모드 | 안전하지만 테마와 무관 |
| **망자 좀비** | 사망 지점에 내 소지품을 든 좀비가 남는다. 처치하면 돌려받는다 |

**결정: keepInventory 끔 + 망자 좀비.** 처음 구상했던 "좀비에게 죽으면 추격자가 된다"를 인원이 적은 서버에 맞게 바꾼 것이다. 사람이 추격자가 되는 대신, 내 장비를 든 '나의 좀비'가 남는다.

- 2026-11-20 개정: **망자는 주인만 쓰러뜨릴 수 있다.** 다른 플레이어를 공격하지 않고 어그로도 끌리지 않으며, 사망 지점 주변을 배회하고, 낮에도 타지 않는다. 다시 죽으면 이전 망자가 새 자리로 와서 합쳐진다.
- 그래서 PvP 로 남의 소지품을 가져갈 수 없다. PvP 의 보상은 K, 거점전, 영토다.
- 세부 규칙은 [death-and-revenant.md](../design/death-and-revenant.md).

## 6. 수면·게임룰

| 항목 | 결정 |
|---|---|
| 난이도 | 어려움 |
| 수면으로 밤 넘기기 | 접속자 전원이 자야 넘어간다(접속자가 적어 사실상 1~2명). **보름달 밤(8 게임일마다)과 블러드문에는 잠들 수 없다** |
| 서버가 비었을 때 | `pause-when-empty-seconds` 기본값(60초) 유지. 게임 시간은 접속자가 있을 때만 흐른다 |
| 서버 목록 | `hide-online-players=true` (서버 목록 핑에 접속자 이름이 나가지 않게), query·RCON 끄기 |
| 로케이터 바 | 켬. 단, 같은 국가 국민끼리만 보이도록 서버에서 거른다(simpleNationWar) |
| 몹 그리핑 | 켬. 영토 안 몹 폭발·굴착은 5분 뒤 자동 복구(simpleNationWar) |
| 엘리트라 | 허용. 엔드는 후반 콘텐츠라 초중반 긴장에는 영향이 작다 |

게임룰 이름은 26.x 에서 바뀐 것이 있다. 실제 이름은 서버에서 `/gamerule` 자동완성으로 확인한다.

## 7. PvP 정책

| 장소 | 플레이어 간 피해 | 블록 파괴·상자 |
|---|---|---|
| 야생 | 허용 | 허용 (주인 없는 땅) |
| 자국 영토 | 국민끼리 불가 | 국민만 |
| 타국 영토 | 적대 관계일 때만 허용 | 불가 (상시) |
| 생존자 캠프 | 불가 | 불가 |
| 거점 | 거점전 시간에 허용 | 불가 |

- **오프라인 약탈은 불가능하다.** 영토의 블록 보호는 전쟁 중에도 풀리지 않는다.
- 충돌의 장은 야생 조우, 보급 투하(수·금 22:00), 거점전(목·일)이다. 시뮬레이션상 새 인원(17/8~23/12)에서 서버 전체 PvP 교전은 주 7~11회로 이전 가정(2~4회)보다 늘지만, 나눠 갖는 사람이 많아 핵심 유저 1인당 시즌 PvP 킬은 2.4~2.8회에 그친다. 그래서 의도적으로 만나는 자리를 만든다는 방침은 그대로다.

### 8-2. couriersRoost: 채택 (26.4 포팅 후)

- 서버 사이드 전용, 리소스팩 불필요, 26.1.2/26.2/26.3 지원. 같은 계정의 저장소라 26.4 포팅을 직접 할 수 있다.
- 채팅이 전서구로 실제로 날아가 도착해야 전달된다. '통신 두절된 아포칼립스'라는 테마에 잘 맞는다.
- 권장 설정: `bird_speed` 40, `bird_death_chance` 0.0(시즌 초반), `global_chat_cooldown` 5, `base_dimension_delay` 4. 블러드문 밤에는 `bird_death_chance` 를 올리는 이벤트 훅을 검토한다.
- 연동 주의점
  - 전서구는 닭 엔티티다. zomApo 의 좀비 변환·좀비 기수(아기 좀비가 닭을 타는 바닐라 동작) 대상에서 `courierpost_bird` 태그를 가진 개체를 뺀다.
  - 디스코드 연동은 채팅을 중계하지 않고 시스템 이벤트(사망, 접속, 국가 이벤트)만 보낸다. 채팅을 중계하면 전서구 지연이 무의미해진다.
  - 표시 이름: couriersRoost 가 발신자 이름을 `getName()` 으로 쓰는지 표시 이름으로 쓰는지 확인하고, 커스텀 닉네임이 보이도록 맞춘다.
  - **채팅 경로: 그냥 치는 채팅은 국가(바닐라 팀) 채팅, 전체 채팅은 `/g <메시지>` 로만.** couriersRoost 는 원래 모든 채팅을 전체 전서구로 보낸다. simpleNationWar 가 Fabric 채팅 이벤트의 앞선 단계에서 먼저 받아 바닐라 `/teammsg` 전송부로 돌리고, couriersRoost 의 팀 채팅 믹스인이 그것을 전서구로 배달한다. `global_chat_cooldown` 은 `/g` 에만 걸린다. 26.3 에서 두 모드를 함께 띄워 경로를 확인했다. 자세한 규칙은 simpleNationWar [commands.md](https://github.com/menonng/simpleNationWar/blob/HEAD/docs/design/commands.md) '채팅'.

### 8-4. 기타 월드젠

- **바닐라 생성 + 시드 탐색 도구 (채택).**
  - 개발용 서버 명령(운영 서버에는 넣지 않음)으로, 월드를 만들지 않고 시드마다 **실제 26.4 바이옴 생성기**를 돌려 세 후보지 주변을 채점한다. 버전과 100% 같은 결과라 별도 지도 사이트에 의존하지 않는다.
  - 상위 10개 시드는 테스트 서버에서 실제로 열어 눈으로 확인하고 고른다.
  - 26.4 의 얼음 동굴처럼 새 지형이 들어가도록 운영 월드는 26.4 에서 생성한다.
- **canvasworldgen: 시즌 1 미채택(보류).** 바닐라 블록만 쓰는 데이터팩이라 서버 사이드로는 맞지만, 개발이 사실상 멈춰 있고 26.2 대상이다. 다시 살려서 의도대로 동작하게 만드는 작업량을 예측하기 어려워 1월 개장 일정의 위험 요소가 된다. 시드 탐색만으로 공정한 출발지를 만들 수 있으므로 필요하지 않다. 직접 그린 맵이 꼭 필요해지는 시즌이 오면 그때 상태를 따로 진단한다.
- Tectonic 등 지형 데이터팩은 넣지 않는다. 시드 탐색 결과가 마음에 들지 않을 때만 재검토.
- 구조물 데이터팩(던전·폐허류)은 바닐라 블록만 쓰는 것에 한해 선택 추가. 26.4 지원 여부를 보고 결정한다.

## 9. 월드 크기

| 항목 | 값 |
|---|---|
| 오버월드 월드보더 | **반경 4,000 (8,000 × 8,000)**. 2026-11-20 확대(이전 반경 2,000) |
| 수도 후보지 | 반경 1,200, 120° 간격 → 수도 사이 약 2,080블록 (2절) |
| 사전 생성 | Chunky 로 보더 전체 = 25만 청크, 디스크 약 3GB. 측정 컨테이너 초당 116청크(36분), 9600X 급이면 10~15분 추정 (서버 개장 전, 26.4 에서) |
| 네더 | 바닐라 8:1, 보더 반경 500 (오버월드 보더를 따라감) |
| 엔드 | 바닐라. 드래곤 처치는 업적(칭호), 치료제 필수 조건은 아님 |

인원 가정을 최대 20±3명으로 올리면서 월드를 8,000 × 8,000 으로 넓혔다. 국가당 7명 안팎이면 영토·자원·탐험 거리가 더 필요하다.

- **수도는 너무 멀리 두지 않는다.** 보더가 4,000 이어도 수도 후보지는 반경 1,200(수도 사이 약 2,080블록)에 둔다. 블러드문 10분 예고 안에 달려서 건널 수 있고(약 6분), 국가 간 교역·거점전이 생긴다. 수도 바깥 약 2,800블록은 탐험·자원·둥지·랜드마크 지대.
- **성능 비용**: 넓을수록 사람들이 흩어지고, 렉은 떨어진 무리 수에 비례한다. 동시 접속 15명 이상일 때 흩어짐이 크면 틱 예산을 넘을 수 있어 안전장치(부하 연동 몹 상한, ServerCore)를 둔다([performance.md](performance.md) 9절).
- 사전 생성·BlueMap 렌더·백업 용량이 4배가 된다(performance.md 9절).
- 랜드마크·둥지 개수는 면적에 맞춰 늘린다(설계 수치 재조정 필요).

## 10. 국가 편성

**결정: '국가 추첨식'. 팀장 3명을 먼저 세우고, 전력 점수(별점 + 참여도)가 국가 평균을 전체 평균 쪽으로 당기는 사람일수록 뽑힐 확률이 높은 가중 추첨으로 한 번에 뽑는다. 서로 지목한 단짝은 한 묶음, 결과가 기준을 넘으면 보이지 않게 다시 뽑는다. 추첨 뒤 24시간 맞교환 창.**

### 10-1. 비교 (20명/활성 10명, 2,000회, `tools/sim/team_sim.py`)

| 방식 | 별점 격차 | 활동량 격차 | 약소국 몫 | 핵심 유저 2명 이상 차이 | 단짝 유지 | 함께 접속 |
|---|---|---|---|---|---|---|
| 자유 선택 (강한 쪽 쏠림 있음) | 0.60 | 112% | 17.8% | 100% | 93% | 64.8% |
| 자유 선택 (친구끼리만, 쏠림 없음) | 0.50 | 56% | 24.0% | 71% | 97% | 65.0% |
| 완전 랜덤 | 0.48 | 51% | 24.8% | 66% | 30% | 60.2% |
| 팀장 드래프트(팀장이 직접 지명) | 0.39 | 36% | 27.3% | 40% | 65% | 62.3% |
| 제안안: 별점 가중 추첨 | **0.24** | 44% | 26.1% | 53% | 30% | 59.5% |
| 제안안 + 참여도 | 0.33 | 36% | 27.4% | 40% | 28% | 59.3% |
| 제안안 + 참여도 + 단짝 | 0.39 | 43% | 26.1% | 55% | 91% | 64.4% |
| **제안안 + 참여도 + 단짝 + 재추첨 가드(별점 포함)** | **0.22** | **22%** | **29.8%** | **7%** | **91%** | **63.9%** |
| 최적화 상위 3안 투표(이전 문서안) | 0.34 | 32% | 28.0% | 29% | 100% | 64.6% |

- 별점 격차 = 국가 평균 별점의 최대 − 최소. 활동량 격차 = 국가 총 플레이 시간의 (최대 − 최소)/평균. 약소국 몫 = 가장 적게 노는 국가의 플레이 시간 비중(33.3% 가 완벽). 함께 접속 = 접속한 시간 가운데 같은 국가 사람이 함께 있던 비율.
- 별점(상호평가 5항목 평균)은 활동량과 0.45 상관, 단짝은 인원의 약 70%, 단짝끼리는 접속을 맞추는 경향(같이 들어올 확률 ×1.3)으로 가정했다. 17/8·23/12 결과도 순위가 같다(team-results.md).

읽는 법:

1. **자유 선택은 친구와 함께 노는 시간은 가장 길지만 국가 격차가 가장 크다.** 쏠림을 빼고 친구끼리만 모여도 활동량 격차 56%, 가장 약한 국가의 몫 24%. 3주 시즌에는 되돌릴 시간이 없어서, 약한 국가가 첫 주에 밀리면 그 친구들이 통째로 접속을 끊는다. 이 서버에서 가장 피해야 할 일이다.
2. **제안안(별점만)은 별점은 가장 잘 맞추지만 참여도를 못 본다.** 핵심 유저 수가 2명 이상 벌어질 확률이 53%. 이 서버에서 국가의 체감 세기는 실력보다 '매일 들어오는 사람이 몇 명인가'로 정해진다. 또 친구를 떼어 놓아(단짝 유지 30%) 함께 접속 시간이 5%p 줄어든다.
3. **참여도와 단짝을 넣으면 별점 균형이 흐트러지고, 재추첨 가드가 그것을 되찾는다.** 최종안은 별점 격차 0.22 로 제안안만큼 맞고, 활동량·핵심 유저 균형은 모든 방식 중 가장 좋으며, 친구와 함께 노는 시간은 자유 선택과 거의 같다(63.9% 대 65.0%).
4. 최적화안도 괜찮지만, 결과를 '운영자가 계산한 정답'으로 받아들이게 된다. 추첨은 공개 행사가 되고, 결과를 운에 돌릴 수 있어 불만이 적다. 참여를 끌어올리는 데는 이쪽이 낫다.
5. **새 인원에서는 '핵심 유저 0명 국가'가 사실상 생기지 않는다.** 완전 랜덤으로 나눠도 17/8 3.4%, 20/10 0.9%, 23/12 0.2%(정확한 확률, [simulation.md](simulation.md) 4절)로, 이전 가정(15명 활성 4명 45%, 10명 활성 3명 70%)에서 균형 편성을 고른 첫 이유는 사라졌다. 대신 **핵심 유저 수가 국가마다 2명 이상 벌어질 확률이 59~87%**(20/10 에서 5/3/2 같은 결과)라 균형이 여전히 필요하다. 재추첨 가드 ①(핵심 유저 수 차이 1 이하)이 바로 이 지표를 본다. 결정은 그대로다. 23/12 에서는 가드를 통과해도 실제 핵심 격차 2명 이상이 22%(20/10 7%)라, 시즌 중 이적 창 규칙(아래 10-2 끝)이 받친다.

### 10-2. 절차

| 단계 | 내용 |
|---|---|
| 1. 가입 | 예상 플레이 시간(라디오), 접속 시간대, **단짝 1명**(비공개 입력, 서로 지목했을 때만 유효) |
| 2. 상호평가 | 48시간 라운드 → 사람마다 5항목 별점 평균 |
| 3. 팀장 | 원수 지망자 중 3명. 지망자가 많으면 전체 투표. 단, 팀장은 예상 플레이 시간 상위 절반에서만 나온다(국가마다 매일 들어오는 사람 1명 보장). 팀장의 단짝은 팀장 국가로 바로 간다 |
| 4. 전력 점수 | 0.5 × 별점(표준화) + 0.5 × 참여도(표준화: 가입 때 적은 예상 시간과 '열정' 항목의 평균) |
| 5. 추첨 | 국가 순서를 무작위로 정하고 돌아가며 한 단위(단짝 묶음 또는 한 명)씩 뽑는다. 뽑힐 가중치 = 0.08 + (그 단위를 넣었을 때 국가 평균 전력이 전체 평균에 가까워지는 정도 × 지금 국가 인원). 국가 평균이 높으면 낮은 사람이, 낮으면 높은 사람이 잘 뽑히고, 격차가 클수록 확률이 커진다 |
| 6. 재추첨 가드 (보이지 않음) | 결과가 ① 핵심 유저(예상 시간 상위) 수 차이 1 이하 ② 국가 총 예상 시간 차이 18% 미만 ③ 국가 평균 별점 차이 0.35 이하를 모두 만족할 때까지 봇이 처음부터 다시 뽑는다. 평균 30~45번, 500번 안에 99% 이상 통과 |
| 7. 추첨식 | 통과한 결과를 디스코드 #공지에서 한 명씩 공개(10초 간격). 추첨 전에 시드의 해시를 먼저 올리고, 끝난 뒤 시드를 공개해 누구나 같은 결과를 재현할 수 있게 한다(조작 의심 차단) |
| 8. 맞교환 창 | 24시간. 서로 다른 국가의 두 사람이 둘 다 원하면 맞바꾼다. 봇이 6단계 기준을 계속 만족하는지 확인하고 허락 |
| 9. 확정 | 국가 역할·채널, 팀장 = 원수, 국가 이름 투표 |

알고리즘 상세: simpleNationWar [peer-rating.md](https://github.com/menonng/simpleNationWar/blob/HEAD/docs/discord/peer-rating.md) 5절.

- 시즌 중 이적은 원칙적으로 막고, 국가 간 '최근 72시간 활동 인원' 차가 2명 이상으로 72시간 넘게 이어지면 운영자가 이적 창을 연다.

## 11. 서버 플랫폼과 사양

**결정: Fabric 모드 유지 + 최적화 모드 7종. Folia(플러그인 전환) 미채택. 서버 힙 6GB.**

- 인원 가정을 최대 20±3명/활성 8~10+α명으로 올리고 26.3 서버에 봇을 띄워 실측했다. 렉은 접속자 수보다 **떨어진 무리 수**에 비례하고, 같은 무리에 한 명이 더 붙는 비용은 거의 없다.
- 시뮬레이션상 동시 접속은 대개 3~4명, 붐빌 때 7~8명, 시즌 최고 12~13명이다. 최적화 모드를 넣으면 보급형 데스크톱 이상에서 틱이 50ms 를 넘는 시간이 0.01% 이하라, Folia 의 병렬 틱이 줄여 줄 렉이 거의 없다.
- Folia 는 16코어 권장, 스코어보드 API 전체 미지원('국가 = 바닐라 팀' 설계와 충돌), 믹스인 불가, 모든 코드의 스레드 규칙 준수가 필요하다. zomApo·simpleNationWar·snw-discord·couriersRoost 를 모두 다시 짜야 한다.
- 실사용 힙은 시즌 최대 순간에도 약 2.2GB(봇 실측 + 실제 플레이 보정)라 힙 6GB 면 넉넉하다. RAM 을 더 줘도 렉은 줄지 않는다.
- 상세: [performance.md](performance.md). 측정 도구: `tools/perf/bench.py`(자기 PC 에서도 돈다).

**다시 볼 조건**: 동시 접속이 상시 25명을 넘고 넓게 흩어지는 시즌, 또는 서버 기계가 16코어 이상이고 단일 코어가 약할 때.

## 12. 인원 상향 재검토 (2026-11-20)

인원 가정을 10~15명/활성 3~4명에서 **최대 20±3명/활성 8~10+α명**으로 올리고 플레이 양상 시뮬레이션을 17/8 · 20/10 · 23/12 로 다시 돌렸다([simulation.md](simulation.md), 원자료 [tools/sim/results.md](../../tools/sim/results.md)). 서버 사양은 [performance.md](performance.md) 에서 따로 다시 계산했다. 결정마다 아래처럼 판정한다.

## 13. 겉날개

| 선택지 | 결과 |
|---|---|
| 그대로 허용 | 8,000 × 8,000 월드에서 이동이 편하다. 대신 폭죽 비행으로 좀비 떼·블러드문에서 그냥 날아 도망칠 수 있고, 초당 30블록 이상으로 날며 새 청크를 계속 불러와 서버 부하가 크다(시야 10 이면 1초에 약 40청크) |
| 금지 | 엔드 시티 보상이 사라지고, 넓은 월드에서 국가 사이를 오가기가 너무 고되다 |
| **허용 + 폭죽 추진 금지** | 높은 곳에서 활공하는 이동은 남고, 오래 나는 비행과 공중 도주는 막힌다 |

**결정 (2026-11-20 개정): 겉날개 전면 허용(바닐라 그대로).**

- 폭죽 추진 금지·속도 절반은 둘 다 "내 겉날개가 이상하다"는 체감이 커서, 얻는 것(공중 도주·청크 부하 억제)보다 반발이 크다고 판단했다. 엔드 시티까지 가서 얻은 보상을 깎으면 그 노력을 깎는 셈이다.
- 서버 부하: 폭죽 비행 한 명이 1초에 약 40청크를 불러온다. 월드를 전부 사전 생성해 두므로 디스크에서 읽기만 하고, 9600X 에서 몇 명이 동시에 날아도 견딘다. 틱이 밀리면 ServerCore 가 시야 거리를 자동으로 줄인다.
- 좀비 떼·블러드문에서 날아 도망치는 건 허용한다. 대신 좀비 떼는 '목표 고정'이라 착지하면 다시 쫓아온다(떼가 해산되기까지 2분).
- 다시 볼 조건: 블러드문이 '날아서 피하는 행사'가 되면 블러드문 중에만 폭죽 추진을 막는다.

## 14. 플레이어 강화와 보상

좀비 쪽은 레벨이 오를수록 많아지고(밤 ×1.5 → ×2.0), 낮에도 나오고(Lv2+), 타지 않고, 체력이 늘고(Lv4+ ×1.5), 떼로 찾아온다. 플레이어 쪽이 따라갈 수단이 있는지 확인했다.

**처치에 필요한 타수** (어려움, 좀비 체력 20 / Lv4+ 30, 알레르기 낮)

| 무기 | Lv0 낮 (15) | Lv0~3 밤 (20) | Lv3 낮 (18) | Lv4+ (30) |
|---|---|---|---|---|
| 철 검 (6) | 3 | 4 | 3 | 5 |
| 다이아 검 날카로움 III (9) | 2 | 3 | 2 | 4 |
| 네더라이트 검 날카로움 V + 스타포스 10성 (약 14) | 2 | 2 | 2 | 3 |

**받는 피해** (어려움 좀비 한 대 4.5, Lv5 5.4)

| 방어구 | 한 대당 | 좀비 떼 13마리가 한꺼번에 붙으면 |
|---|---|---|
| 철 풀세트 | 약 2.2 | 1~2초 |
| 다이아 풀세트 | 약 1.1 | 2~3초 |
| 네더라이트 + 보호 IV | 약 0.4 | 버틴다 |

결론: **바닐라 장비 진행 + 스타포스 + 커스텀 인첸트로 '3~4타' 감각은 끝까지 유지된다.** 따로 능력치를 올려 주는 강화는 넣지 않는다. 대신 위험이 큰 쪽에 보상을 둔다.

| 보상 | 내용 |
|---|---|
| 좀비화 몹 드랍 | 원종 + 좀비 루트를 둘 다 준다. 높은 레벨 땅일수록 같은 시간에 얻는 자원이 많다 |
| 경험치 | 원종 × (1 + 0.1 × 스폰 레벨) |
| 좀비 떼 보급 상자 | 3분 안에 80% 이상 쓰러뜨리면 음식·화살·철/금 조각·바이러스 결정(레벨 비례) |
| 낮의 이점 | 태양광 알레르기 덕분에 Lv0~3 땅은 낮에 훨씬 쉽다. 일은 낮에, 밤에는 기지에서 |
| 좀비 떼를 두 무리로 | 한꺼번에 덮치지 않게(15초 간격), 철 장비로도 길목에서 받아칠 수 있다 |
| 조명 | 블록 빛 8 이상이면 낮 스폰이 없다. 횃불로 기지를 지킬 수 있다 |

다시 볼 조건: 생존일지·통계에서 '좀비 떼 사망'이 한 사람에게 하루 2번 이상 반복되면 떼 규모를 −2 하거나 철 장비 구간의 받는 피해를 낮춘다.
