# 사망 처리: 망자 좀비

keepInventory 를 끄는 대신, 죽은 자리에 **내 소지품을 든 좀비('망자')** 가 남는다. 처치하면 소지품이 돌아온다.

처음 구상했던 "좀비에게 죽은 플레이어가 추격자가 된다"를 10~15명 서버에 맞게 바꾼 것이다. 사람이 좀비 편이 되면 인원이 적은 서버에서는 생존자 쪽이 금방 무너진다. 대신 '나의 좀비'가 내 장비를 들고 기다린다.

## 1. 흐름

1. 플레이어가 죽는다. 아이템(번들·셜커 상자 내용물 포함)과 드랍될 경험치를 바닥에 떨어뜨리지 않고 회수한다.
2. 사망 지점에 망자 좀비가 생긴다.
3. 망자를 처치하면 그 자리에 소지품과 경험치가 모두 떨어진다.
4. 처치한 사람이 본인이 아니면 그 사람이 가져갈 수 있다.

## 2. 망자 좀비

| 항목 | 규칙 |
|---|---|
| 외형 | 사망자 스킨의 플레이어 머리, 사망 당시 입던 방어구·손에 든 아이템을 **보이기만** 한다 |
| 이름표 | `망자 · {커스텀 닉네임}` (항상 표시) |
| 능력치 | 사망 지점의 영역 레벨 기준 고정값(체력 = 일반 좀비 × 2). 입고 있는 장비의 능력치는 적용하지 않는다. 맨몸으로 돌아와도 되찾을 수 있어야 한다 |
| 이동 | 사망 지점 반경 16블록에 묶인다. 그 밖으로 끌려가면 순간이동으로 돌아온다 |
| 지속 | 디스폰하지 않는다. 햇빛에 타지 않는다. 아이템을 줍지 않는다. 변환·변종 대상이 아니다 |
| 공격 | 일반 좀비처럼 근처 플레이어를 공격한다 |
| 점수 | 좀비 스코어·처치 수 없음 (자기 죽음으로 점수를 쌓는 악용 방지) |

## 3. 보호 시간

| 사망 원인 | 보호 |
|---|---|
| PvE (좀비·환경 등) | 10분 동안 본인과 자국민만 망자에게 피해를 줄 수 있다 |
| PvP (다른 국가 플레이어의 처치) | **보호 없음.** 이긴 쪽이 바로 망자를 처치해 가져갈 수 있다. 전투의 보상이다 |

보호 시간이 끝나면 누구나 처치할 수 있다. 시간은 설정값이다.

## 4. 위험한 장소

| 상황 | 처리 |
|---|---|
| 용암·공허·질식 위치 | 플레이어가 마지막으로 단단한 땅 위에 서 있던 위치(1초마다 기록)에 생성 |
| 공허(엔드 바깥) | 엔드 출구 포탈 근처 안전 지점 |
| 생존자 캠프 | 캠프 경계 바로 밖 |
| 타국 영토 | 그 자리 그대로(적의 땅에서 죽은 대가) |

## 5. 개수 제한

- 한 사람당 망자는 최대 3마리. 네 번째가 생기면 가장 오래된 망자가 사라지면서 그 소지품은 사망 지점에 **잠긴 상자**(본인만 열 수 있음, 바닐라 상자 + 서버 보호)로 남는다.
- 망자가 있는 청크가 언로드되면 그대로 멈춰 있다가 다시 불러오면 이어진다.

## 6. 알림

- 사망자에게: `망자가 남았습니다. 좌표 x, y, z (10분 보호)`. 나침반 대신 액션바에 방향·거리를 1분 동안 표시.
- **본인과 자국민에게만 보이는 마커**: 망자 머리 위에 발광하는 가짜 엔티티(패킷 전용 표시 엔티티)를 띄운다. 다른 국가 사람에게는 이 마커가 보내지지 않으므로 벽 너머로 위치가 드러나지 않는다. monun 의 series-survival 이 생존자 위치를 좀비 진영에게만 보이는 가짜 엔티티로 알려 준 기법이다([monun.md](../reference/monun.md) 2절).
- 디스코드: 알림 채널에는 "철수 님이 망자가 되었습니다"만, **좌표는 해당 국가 채널에만** 보낸다.
- 망자를 되찾으면 망자 회수 통계가 올라간다.

## 7. 다른 선택지와 비교

| 방식 | 긴장감 | 복구 | 테마 | 분쟁 |
|---|---|---|---|---|
| keepInventory | 없음 | 완전 | 없음 | 없음 |
| 바닐라 드랍 | 높음 | 5분 안에 가야 함, 자주 실패 | 보통 | 줍기 경쟁 |
| 무덤 모드 | 낮음 | 안전 | 없음 | 적음 |
| **망자 좀비** | 높음 | 싸워서 되찾음, 시간 제한 없음 | 강함 | PvP 사망만 약탈 허용으로 명확 |

## 8. 구현 메모

- 사망 이벤트에서 드랍 목록을 가로채 비우고, 아이템 스택 목록과 경험치를 망자 엔티티의 저장 부착(`RevenantData{owner, items, xp, deathTime, protectedUntil, cause, anchor}`)에 넣는다.
- 망자는 바닐라 좀비 엔티티 + 부착. 지속성 설정(디스폰 금지), 아이템 줍기 금지, 햇빛 연소 무시는 믹스인으로 처리한다.
- 망자의 장비 슬롯에는 사망 당시 장비의 **복사본**을 두고 드랍 확률을 0 으로 한다. 실제 아이템은 부착 데이터에만 있다(복제 방지).
- 보호 시간 판정은 피해 이벤트에서 공격자의 국가를 `snw-api` 로 확인한다.
- K/D/A 의 D 는 원래 사망 시점에 한 번만 센다. 망자 처치는 K 에 들어가지 않는다.
