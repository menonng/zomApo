# 사망 처리: 망자 좀비

keepInventory 를 끄는 대신, 죽은 자리에 **내 소지품을 든 좀비('망자')** 가 남는다. 처치하면 소지품이 돌아온다.

처음 구상했던 "좀비에게 죽은 플레이어가 추격자가 된다"를 20명 안팎(국가당 7명 안팎) 서버에 맞게 바꾼 것이다. 사람이 좀비 편이 되면 인원이 적은 서버에서는 생존자 쪽이 금방 무너진다. 대신 '나의 좀비'가 내 장비를 들고 기다린다.

## 1. 흐름

1. 플레이어가 죽는다. 아이템(번들·셜커 상자 내용물 포함)과 드랍될 경험치를 바닥에 떨어뜨리지 않고 회수한다.
2. 사망 지점에 망자 좀비가 생긴다.
3. **망자는 주인만 쓰러뜨릴 수 있다.** 쓰러뜨리면 그 자리에 소지품과 경험치가 모두 떨어진다(주인만 주울 수 있게 1분 잠금).

2026-11-20 개편: 다른 사람이 망자를 잡아 소지품을 가져가는 규칙(PvP 사망 약탈)을 없앴다. 망자는 '나와 나의 좀비' 사이의 일이다.

## 2. 망자 좀비

| 항목 | 규칙 |
|---|---|
| 외형 | 사망자 스킨의 플레이어 머리, 사망 당시 입던 방어구·손에 든 아이템을 **보이기만** 한다 |
| 이름표 | `망자 · {커스텀 닉네임}` (항상 표시) |
| 능력치 | 사망 지점의 영역 레벨 기준 고정값(체력 = 일반 좀비 × 2). 입고 있는 장비의 능력치는 적용하지 않는다. 맨몸으로 돌아와도 되찾을 수 있어야 한다 |
| 이동 | **사망 지점 주변을 배회한다.** 반경 16블록에 묶이고, 그 밖으로 끌려가면 순간이동으로 돌아온다 |
| 지속 | 디스폰하지 않는다. **햇빛에 타지 않고 태양광 알레르기도 없다.** 아이템을 줍지 않는다. 좀비화·변종·레벨 강화 대상이 아니다 |
| 공격 | **주인만 노린다.** 다른 플레이어는 공격하지 않고, 다른 플레이어가 가까이 오거나 때려도 어그로가 끌리지 않는다 |
| 피해 | **주인이 준 피해만 받는다.** 다른 플레이어·몹·용암·낙하·폭발·익사 피해는 모두 무시한다(소지품이 사라질 길이 없다) |
| 문·블록 | 문을 부수지 않고 압력판을 밟지 않는다(남의 기지를 흔들지 않게) |
| 점수 | 좀비 스코어·처치 수 없음 (자기 죽음으로 점수를 쌓는 악용 방지) |

## 3. 주인 전용 규칙의 결과

| 항목 | 전 | 후 |
|---|---|---|
| 보호 시간 | PvE 사망 10분 보호, PvP 사망 보호 없음 | 필요 없음(항상 주인만) |
| PvP 사망 | 이긴 쪽이 망자를 잡아 소지품을 가져감 | **가져갈 수 없다.** PvP 의 보상은 K, 거점전, 영토로만 |
| 친구 도움 | 자국민이 대신 잡아 줄 수 있었음 | 대신 잡아 줄 수 없다. 대신 **주변 좀비를 치워 주는** 협동이 된다. 망자는 주인이 올 때까지 기다린다 |
| 생존일지 | '망자 약탈' 사건 | 더 이상 생기지 않는다. '망자 회수'만 남는다 |

PvP 로 남의 장비를 빼앗을 수 없게 되면서 '전쟁은 양념' 원칙이 더 분명해진다. 싸움에 져도 장비는 내 망자가 지킨다.

## 4. 위험한 장소

| 상황 | 처리 |
|---|---|
| 용암·공허·질식 위치 | 플레이어가 마지막으로 단단한 땅 위에 서 있던 위치(1초마다 기록)에 생성 |
| 공허(엔드 바깥) | 엔드 출구 포탈 근처 안전 지점 |
| 생존자 캠프 | 캠프 경계 바로 밖 |
| 타국 영토 | 그 자리 그대로. 주인만 잡을 수 있으므로 상대 국가가 가져갈 수는 없다. 대신 적의 땅까지 다시 가야 한다 |

## 5. 개수: 한 사람당 망자 1마리, 다시 죽으면 합쳐진다

- 망자가 남아 있는 상태에서 또 죽으면, **이전 망자가 새 사망 지점으로 옮겨 와 소지품을 합친다.** 소지품을 잃는 길이 없고, 여러 군데를 돌아다닐 필요도 없다.
- 합친 망자의 체력은 새 사망 지점 레벨 기준으로 다시 정한다.
- 망자가 있는 청크가 언로드되면 그대로 멈춰 있다가 다시 불러오면 이어진다. 시즌이 끝날 때까지 남는다.

## 6. 알림

- 사망자에게: `망자가 남았습니다. 좌표 x, y, z`. 나침반 대신 액션바에 방향·거리를 1분 동안 표시.
- **본인에게만 보이는 마커**: 망자 머리 위에 발광하는 가짜 엔티티(패킷 전용 표시 엔티티)를 띄운다. 다른 사람에게는 이 마커가 보내지지 않으므로 벽 너머로 위치가 드러나지 않는다. monun 의 series-survival 이 생존자 위치를 좀비 진영에게만 보이는 가짜 엔티티로 알려 준 기법이다([monun.md](../reference/monun.md) 2절).
- 디스코드: 알림 채널에는 "철수 님이 망자가 되었습니다"만. **좌표는 본인 DM 으로만** 보낸다(이제 주인만 잡을 수 있으므로 국가 채널에 올릴 이유가 없다).
- 망자를 되찾으면 망자 회수 통계가 올라간다.

## 7. 다른 선택지와 비교

| 방식 | 긴장감 | 복구 | 테마 | 분쟁 |
|---|---|---|---|---|
| keepInventory | 없음 | 완전 | 없음 | 없음 |
| 바닐라 드랍 | 높음 | 5분 안에 가야 함, 자주 실패 | 보통 | 줍기 경쟁 |
| 무덤 모드 | 낮음 | 안전 | 없음 | 적음 |
| **망자 좀비 (주인 전용)** | 높음 | 싸워서 되찾음, 시간 제한 없음 | 강함 | 없음(주인만 잡음) |

## 8. 구현 메모

- 사망 이벤트에서 드랍 목록을 가로채 비우고, 아이템 스택 목록과 경험치를 망자 엔티티의 저장 부착(`RevenantData{owner, items, xp, deathTime, cause, anchor}`)에 넣는다.
- 망자는 바닐라 좀비 엔티티 + 부착. 지속성 설정(디스폰 금지), 아이템 줍기 금지, 햇빛 연소 무시, 문 부수기 끔은 믹스인으로 처리한다.
- 주인 전용: 피해 처리(`hurtServer`)에서 공격자가 주인이 아니면 취소. 표적 목표는 주인만 고르는 전용 목표로 바꾸고, 다른 플레이어에게 맞아도 `setTarget` 하지 않는다. 다른 몹의 표적 후보에서도 뺀다.
- 합치기: 같은 주인의 망자가 이미 있으면 그 엔티티를 새 위치로 옮기고 부착의 아이템 목록을 이어 붙인다(엔티티를 새로 만들지 않아 복제 위험이 없다).
- 망자의 장비 슬롯에는 사망 당시 장비의 **복사본**을 두고 드랍 확률을 0 으로 한다. 실제 아이템은 부착 데이터에만 있다(복제 방지).
- 보호 시간 판정은 피해 이벤트에서 공격자의 국가를 `snw-api` 로 확인한다.
- K/D/A 의 D 는 원래 사망 시점에 한 번만 센다. 망자 처치는 K 에 들어가지 않는다.
