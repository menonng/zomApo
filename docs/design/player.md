## 좀비 통계

PvP 통계(K/D/A)는 국가 모드 쪽에 있다: simpleNationWar 의 [nation.md](https://github.com/menonng/simpleNationWar/blob/HEAD/docs/design/nation.md#kda). 이 문서는 zomApo 가 기록하는 좀비 쪽 통계다.

### 1. 기록 항목

| 항목 | 정의 | 인게임 표시 |
|---|---|---|
| 좀비 처치 수 | 좀비 계열 개체를 플레이어가 처치한 횟수 | O |
| 좀비 스코어 | 처치한 좀비마다 점수표 × 보정을 더한 값 | O |
| 변종별 처치 수 | 변종·변환형별 처치 수 | `/info` 상세(마우스 올림) |
| 최고 레벨 생존 | 머문 적 있는 가장 높은 스폰 레벨 | 칭호 조건용 |
| 둥지 파괴 수, 블러드문 참여·성공 수 | | 칭호 조건용 |
| 망자 회수 수 / 망자 발생 수 | 자기 망자를 되찾은 비율 | `/info` 상세 |
| 최고 강화 성 | 스타포스 최고 기록 | `/info` 상세 |

**좀비 계열**: 바닐라 좀비 계열 엔티티 타입(`#zomapo:zombies`)이거나, zomApo 가 변환해서 부착 정보가 붙은 개체(치환형·감염형·기수형의 기수). 망자 좀비는 제외한다.

**처치 판정**: 바닐라 처치 크레딧을 따른다. 플레이어가 마지막으로 피해를 준 지 5초 안에 죽으면 그 플레이어의 처치다(투사체 소유자, 길들인 늑대 주인 포함).

### 2. 점수

```
획득 점수 = 기본 점수 × 레벨 보정 × 출처 보정 × 기여 보정 × 농장 감쇠
```

| 요소 | 값 |
|---|---|
| 기본 점수 | [zombies.md](zombies.md#몹-좀비화) 의 변환표·변종표 (일반 좀비 1 ~ 알파 25) |
| 레벨 보정 | 1 + 0.1 × 스폰 레벨 (Lv5 = ×1.5) |
| 출처 보정 | 자연 스폰 ×1.0 / 몬스터 스포너 ×0.2 / 감염 둥지 스포너 ×0.5 / 블러드문 웨이브 ×1.2 |
| 기여 보정 | 처치자가 준 피해가 전체의 50% 이상 ×1.0, 미만 ×0.5. 낙하·용암·질식 등 환경 피해만으로 죽으면 0 |
| 농장 감쇠 | 같은 64×64 구역에서 한 플레이어가 1시간에 50마리를 넘게 잡으면 그 뒤로 ×0.3 |

- 처치 **수**는 보정 없이 1씩 올라간다. 감염 레벨의 국가 열기(H)는 처치 수를 쓰지만 농장 감쇠를 적용한 '유효 처치 수'를 쓴다(좀비 농장으로 자국 레벨을 올리거나 내리는 조작 방지).
- 공동 처치 보너스(둥지 파괴, 블러드문)는 참여자에게 균등 분배한다. 참여 = 해당 이벤트 동안 반경 48블록 안에서 좀비 계열에 피해를 1 이상 준 플레이어.

### 3. 저장

- 플레이어 부착(attachment)이 아니라 **월드 `SavedData`(`zomapo_stats`)에 UUID 별로** 저장한다. 오프라인 플레이어의 `/info`, 국가 합계, 디스코드 봇 조회를 플레이어를 불러오지 않고 처리하기 위해서다.
- 일 단위 기록(날짜별 처치 수·유효 처치 수·점수)을 함께 남긴다. 감염 레벨의 '최근 72시간' 계산과 시즌 결산 그래프에 쓴다.

```json
{
  "uuid": "…",
  "zombieKills": 1284,
  "zombieScore": 2391.4,
  "byForm": { "zombie": 702, "runner": 133, "archer_zombie": 98, "alpha": 2 },
  "daily": { "2027-01-09": { "kills": 41, "effectiveKills": 41, "score": 52.0 } },
  "nestsDestroyed": 3,
  "bloodMoons": { "joined": 5, "won": 4 },
  "revenants": { "created": 7, "recovered": 6 },
  "maxStar": 11,
  "peakSpawnLevel": 4.6
}
```

### 4. 인게임 확인

명령어를 따로 만들지 않는다. simpleNationWar 의 `/info` 와 국가 GUI 국민 목록에 **통계 제공자**로 줄을 끼워 넣는다(`snw:stat_provider` 엔트리포인트, [architecture.md](../tech/architecture.md#구조)).

```
철수 (Steve123)  ·  적국 · 간부
K 12   KDA 1.84
좀비 처치 1,284   좀비 스코어 2,391
```

simpleNationWar 가 없는 환경(zomApo 단독 테스트)에서는 관리자 명령 `/zomapo stats <플레이어>` 로만 본다.

### 5. 쓸 곳 (2026-11-22 채택)

| 용도 | 방식 |
|---|---|
| 감염 레벨 | 국가 열기 H 의 입력 (유효 처치 수) |
| 영토 상한 | simpleNationWar 의 영토 상한에 국가 좀비 스코어 보너스: floor(√합 / 3)(2026-11-22 인원 상향 반영, nation.md 5-3) |
| 치료제 | 게이지·단계 없음(백신 조각 엔딩 분기, decisions 4-5). 처치 수·스코어는 엔딩 연출의 기록으로만 |
| 칭호 | 학살자(처치 수 1위), 사냥꾼(알파 처치), 정화자(둥지 파괴), 불사(망자 회수율) 등 |
| 디스코드 | 주간 랭킹, 시즌 결산 그래프 |
| 다음 시즌 | 점수표·확률 밸런스 자료 |

## 망자 좀비

keepInventory 를 끄는 대신, **좀비에게 죽으면** 죽은 자리에 **내 소지품을 든 좀비('망자')** 가 남는다. 처치하면 소지품이 돌아온다.

| 사망 원인 | 소지품 |
|---|---|
| **좀비 계열에게 죽음**(바닐라 좀비, 좀비화 몹, 좀비 떼, 블러드문) | **망자** |
| 좀비에게 맞은 지 10초 안에 낙하·용암·익사·폭발·다른 몹으로 죽음 | 좀비 탓으로 보고 **망자** |
| PvP (다른 국가) | **바닐라 드랍**. 이긴 쪽이 주울 수 있다(전투의 보상) |
| 같은 국가 사람에게 죽음 | **그 자리에서 바로 부활, 소지품·경험치 그대로**(인벤세이브, 2026-11-22). 망자·드랍 없음, K/D 에 넣지 않음 |
| 그 밖의 죽음(환경, 좀비가 아닌 몹) | **보존 드랍**: 바닐라처럼 떨어지되 15분 동안 사라지지 않고, 불·용암·폭발·선인장에 타지 않는다. 공허에서 죽으면 마지막으로 서 있던 단단한 땅에 떨어진다 |

2026-11-20 결정: 망자는 좀비 아포칼립스다운 죽음에만 남긴다. PvP 약탈은 다시 허용하고(전쟁의 보상), 억울한 사고사(용암·공허)는 보존 드랍으로 살린다. 판정 코드: `logic` 의 `DeathRules.decide`.

처음 구상했던 "좀비에게 죽은 플레이어가 추격자가 된다"를 20명 안팎(국가당 7명 안팎) 서버에 맞게 바꾼 것이다. 사람이 좀비 편이 되면 인원이 적은 서버에서는 생존자 쪽이 금방 무너진다. 대신 '나의 좀비'가 내 장비를 들고 기다린다.

### 1. 흐름

1. 플레이어가 죽는다. 아이템(번들·셜커 상자 내용물 포함)과 드랍될 경험치를 바닥에 떨어뜨리지 않고 회수한다.
2. 사망 지점에 망자 좀비가 생긴다.
3. **망자는 주인만 쓰러뜨릴 수 있다.** 쓰러뜨리면 그 자리에 소지품과 경험치가 모두 떨어진다(주인만 주울 수 있게 1분 잠금).

2026-11-20 개편: 다른 사람이 망자를 잡아 소지품을 가져가는 규칙(PvP 사망 약탈)을 없앴다. 망자는 '나와 나의 좀비' 사이의 일이다.

### 2. 망자 좀비

| 항목 | 규칙 |
|---|---|
| 외형 | 사망자 스킨의 플레이어 머리, 사망 당시 입던 방어구·손에 든 아이템을 **보이기만** 한다 |
| 이름표 | `망자 · {커스텀 닉네임}` (항상 표시) |
| 능력치 | 사망 지점의 영역 레벨 기준 고정값(체력 = 일반 좀비 × 2). 입고 있는 장비의 능력치는 적용하지 않는다. 맨몸으로 돌아와도 되찾을 수 있어야 한다 |
| 이동 | **사망 지점 주변을 배회한다.** 반경 16블록에 묶이고, 그 밖으로 끌려가면 순간이동으로 돌아온다 |
| 지속 | 디스폰하지 않는다. **햇빛에 타지 않고 태양광 알레르기도 없다.** 아이템을 줍지 않는다. 좀비화·변종·레벨 강화 대상이 아니다 |
| 공격 | **주인만 노린다.** 다른 플레이어는 공격하지 않고, 다른 플레이어가 가까이 오거나 때려도 어그로가 끌리지 않는다 |
| 피해 | **주인이 준 피해만 받는다.** 다른 플레이어·몹·용암·낙하·폭발·익사 피해는 모두 무시한다(소지품이 사라질 길이 없다) |
| 문·블록 | 문을 부수지 않고 압력판을 밟지 않는다(남의 기지를 흔들지 않게) |
| 점수 | 좀비 스코어·처치 수 없음 (자기 죽음으로 점수를 쌓는 악용 방지) |

### 3. 주인 전용 규칙의 결과

| 항목 | 전 | 후 |
|---|---|---|
| 보호 시간 | PvE 사망 10분 보호, PvP 사망 보호 없음 | 필요 없음(항상 주인만) |
| PvP 사망 | 이긴 쪽이 망자를 잡아 소지품을 가져감 | 망자가 생기지 않고 **바닐라처럼 떨어진다.** 이긴 쪽이 주울 수 있다 |
| 친구 도움 | 자국민이 대신 잡아 줄 수 있었음 | 대신 잡아 줄 수 없다. 대신 **주변 좀비를 치워 주는** 협동이 된다. 망자는 주인이 올 때까지 기다린다 |
| 생존일지 | '망자 약탈' 사건 | 더 이상 생기지 않는다. '망자 회수'만 남는다 |

망자는 '나와 나의 좀비' 사이의 일로만 남기고, 사람끼리의 싸움은 바닐라 규칙(떨어진 것을 줍는다)으로 돌려놓았다.

### 4. 위험한 장소

| 상황 | 처리 |
|---|---|
| 용암·공허·질식 위치 | 플레이어가 마지막으로 단단한 땅 위에 서 있던 위치(1초마다 기록)에 생성 |
| 공허(엔드 바깥) | 엔드 출구 포탈 근처 안전 지점 |
| 생존자 캠프 | 캠프 경계 바로 밖 |
| 타국 영토 | 그 자리 그대로. 주인만 잡을 수 있으므로 상대 국가가 가져갈 수는 없다. 대신 적의 땅까지 다시 가야 한다 |
| 망자가 아닌 죽음 | 위 표의 '보존 드랍' 또는 바닐라 드랍 |

### 5. 망자는 죽은 자리에서 움직이지 않는다

2026-11-21 개정. 원래는 "다시 죽으면 옛 망자가 새 사망 지점으로 옮겨 와 합친다"였다. 그러면 **멀리서 죽은 뒤 집 근처에서 흙 하나 들고 한 번 더 죽어 망자를 불러올 수 있다.** 반대로 '먼저 죽은 망자에 합치기'로 바꾸면 집 옆에서 한 번 죽어 두고 원정 중 죽을 때마다 소지품을 집으로 보낼 수 있다. 그래서 **소지품이 다른 장소로 옮겨지는 길을 모두 없앴다.**

| 다시 좀비에게 죽었을 때 | 처리 |
|---|---|
| 같은 차원 **64블록 안**에 내 망자가 있다 | **그 망자에** 합친다(가장 가까운 것). 망자는 제자리, 체력도 그대로 |
| 더 멀거나 다른 차원 | 새 망자를 **따로** 만든다. 한 사람당 **최대 3마리** |
| 이미 3마리 | **가장 오래된 망자가 무너져** 그 자리에 소지품이 보존 드랍(15분, 불·용암·폭발에 안 탐)으로 떨어진다. 본인에게 좌표와 함께 알린다 |
| 빈손(소지품·경험치 모두 없음) | 아무것도 만들지 않는다 |

- 64블록인 이유: 두 번째 죽음은 대개 첫 망자를 되찾으러 가다 같은 싸움터에서 생긴다. 그 경우 한 곳에서 다 되찾는다. 64블록 안에서는 소지품이 움직여도 최대 64블록이고, 그것도 내가 어차피 갈 옛 망자 쪽이다.
- 멀리 떨어진 두 곳에서 죽었으면 두 곳에 망자가 있는 게 자연스럽다. 3마리까지는 잃지 않는다. 그 이상 쌓아 두면 가장 오래된 것부터 위험해진다(바닐라 드랍에 가까워진다).
- 망자가 있는 청크가 언로드되면 그대로 멈춰 있다가 다시 불러오면 이어진다. 무너지지 않는 한 시즌이 끝날 때까지 남는다.
- 소지품은 망자마다 따로 **주인 플레이어 데이터**에 있다(8절). 망자 엔티티는 (주인, 망자 번호)만 들고, 장부에 없는 번호의 망자는 불려 올 때 아무것도 떨어뜨리지 않고 사라진다. 잃거나 복제될 길이 없다.

### 6. 알림과 사망 지점 빛기둥

**모든 죽음**(망자·보존 드랍·PvP)에서 사망 지점을 **본인에게만** 보여 준다. 2026-11-21 개정: 로케이터 바는 끄고(게임룰 `locator_bar=false`), 액션바 화살표 대신 **빛기둥** 하나로 보여 준다. 코드: `logic` 의 `death/DeathMarker.kt`.

| 언제 | 어디 | 내용 |
|---|---|---|
| 죽은 직후 | 본인 채팅 | `쓰러진 곳: 오버월드 120, 64, -340 — 망자가 소지품을 들고 기다립니다. 빨간 빛기둥을 따라가세요.` (보존 드랍이면 "소지품이 15분 동안 그 자리에 남습니다.", PvP 면 "소지품이 그 자리에 떨어졌습니다.") 남아 있는 다른 망자가 있으면 그 좌표도 한 줄씩 |
| 부활한 뒤 | 화면 속 세계 | 사망 지점에 **비콘 빛줄기 같은 빨간 빛기둥**(`#FF0045`). 본인에게만 보인다 |
| 끄는 때 | | 4블록 안에 도착하거나 15분(보존 드랍이 남는 시간)이 지나면. **망자는 되찾을 때까지** |

**빛기둥이 어디서든 보이는 방법**

- 바닐라 클라이언트는 시야 거리(10청크, 160블록) 밖의 것을 그리지 않는다. 그래서 사망 지점이 **96블록보다 멀면 그 방향으로 96블록 떨어진 곳에** 기둥을 옮겨 세운다. 방향이 맞으므로 멀리 있는 비콘처럼 보이고, 걸어가면 기둥도 따라 물러나다가 96블록 안에 들어오면 진짜 자리에 선다. 같은 차원이면 **거리와 상관없이 늘 보인다.**
- 다른 차원에 있으면 기둥 대신 채팅의 좌표를 본다.
- 만드는 법: 패킷으로만 보내는 표시 엔티티(아이템 디스플레이) 하나에 리소스팩의 빛기둥 모델(바닐라 비콘 빛줄기 텍스처, 높이 320블록, 최대 밝기)을 씌운다. 다른 사람에게는 이 엔티티를 보내지 않으므로 위치가 드러나지 않는다. 0.5초마다 자리를 옮기고, 표시 엔티티의 보간으로 부드럽게 움직인다.
- 망자가 여럿이면(최대 3) 망자마다 하나씩.
- 망자 자체는 주인에게만 발광 테두리로 보인다(32블록 안, 패킷으로 주인에게만 발광 표시).

**그 밖**

- 바닐라 회복 나침반도 그대로 쓸 수 있다(바닐라 사망 위치 기록은 건드리지 않는다).
- 좌표는 본인 화면에만 간다. 생존일지·디스코드 채널·지도에는 보내지 않는다([privacy.md](../server/privacy.md)). 디스코드 알림 채널에는 "철수 님이 망자가 되었습니다"만, **좌표는 본인 DM 으로만**.
- 망자를 되찾으면 망자 회수 통계가 올라간다(남용 대비 조건은 9절).

### 8. 구현 메모

- **2026-11-22 구현**: 게임 `death/RevenantSystem.kt`(장부 = 플레이어 저장 부착 `revenant_stash`, 사망 드랍 믹스인 `DeathLootMixin`, 드라운드 변환·잠 방해 믹스인), `death/DeathBeam.kt`(본인 전용 빛기둥, 리소스팩 `zomapo:death_beam`). 아직: 망자 충돌 없음(길막 방지)·압력판 무시·주인에게만 발광, 망자 회수 통계.

- 사망 이벤트에서 드랍 목록을 가로채 비우고, 아이템 스택 목록과 경험치를 **주인 플레이어의 저장 부착**(`RevenantStash{entries[{id, 차원, 위치, items, xp, createdAt, changedAt}] 최대 3}`)에 넣는다. 인벤토리를 비우는 일과 같은 플레이어 파일에 함께 저장되므로, 그 사이에 서버가 꺼져도 복제·유실이 없다(2026-11-21 개정: 원래는 망자 엔티티에 넣으려 했다). 망자 엔티티의 부착에는 `RevenantTag{owner, id}` 만 둔다.
- 망자는 바닐라 좀비 엔티티 + 부착. 지속성 설정(디스폰 금지), 아이템 줍기 금지, 햇빛 연소 무시, 문 부수기 끔은 믹스인으로 처리한다.
- 주인 전용: 피해 처리(`hurtServer`)에서 공격자가 주인이 아니면 취소. 표적 목표는 주인만 고르는 전용 목표로 바꾸고, 다른 플레이어에게 맞아도 `setTarget` 하지 않는다. 다른 몹의 표적 후보에서도 뺀다.
- 합치기: 64블록 안의 망자 장부 항목에 아이템 목록을 이어 붙인다. 엔티티는 그대로 둔다. 무너짐: 장부 항목을 빼고 그 위치에 보존 드랍을 떨어뜨린다(청크가 언로드돼 있으면 그 청크를 잠깐 불러와 떨어뜨린다). 판정: `logic` 의 `death/RevenantGuard.kt`.
- 망자의 장비 슬롯에는 사망 당시 장비의 **복사본**을 두고 드랍 확률을 0 으로 한다. 실제 아이템은 부착 데이터에만 있다(복제 방지).
- 보호 시간 판정은 피해 이벤트에서 공격자의 국가를 `snw-api` 로 확인한다.
- K/D/A 의 D 는 원래 사망 시점에 한 번만 센다. 망자 처치는 K 에 들어가지 않는다.


### 9. 의도적으로 망자를 만드는 행위 대비 (2026-11-21)

망자 수는 5절이 묶는다(가까우면 합침, 한 사람당 최대 3마리). 그래도 일부러 죽어서 망자를 만들 이유가 남는지 하나씩 따져 막는다. 코드: `logic` 의 `death/RevenantGuard.kt`.

| 노릴 만한 것 | 대책 |
|---|---|
| 한 번 더 죽어서 **먼 망자를 불러오기** | 망자는 움직이지 않는다(5절). 64블록 안이면 그 망자에 합치고, 멀면 따로 생긴다 |
| 반대로 집 옆 망자에 소지품을 모으기 | 64블록 밖의 죽음은 집 옆 망자에 합쳐지지 않는다 |
| 여러 마리 만들기 | 최대 3마리. 넘치면 가장 오래된 망자가 무너져 보존 드랍. 장부에 없는 망자는 불려 올 때 사라진다 |
| 빈손 자살로 망자 만들기(아래 방해 목적) | 소지품·경험치가 없으면 **망자를 만들지 않는다** |
| 남의 침대 옆에서 죽어 **잠을 못 자게** (바닐라는 근처 몬스터가 있으면 잘 수 없고, 망자는 주인 말고는 못 잡는다) | 망자는 주인 말고는 잠을 막지 않는다(`Monster.isPreventingPlayerRest` 를 주인에게만 true) |
| 길목·문·포탈에 망자를 세워 **길막** | 주인 말고는 부딪히지도 밀리지도 않는다(충돌 없음). 포탈을 타지 않고, 보트·광산 수레에 타지 않는다 |
| 남의 장치 건드리기 | 압력판·인계철선을 무시하고(`isIgnoringBlockTriggers`), 발걸음 진동을 내지 않는다(스컬크 감지기). 문을 부수지 않고, 거북알을 밟지 않는다 |
| 물에 빠뜨려 **드라운드로 바꾸기**(엔티티가 바뀌며 꼬임) | 물속 변환을 끈다 |
| 망자를 잡아 경험치·전리품·점수 얻기 | 좀비 전리품·경험치 0(넣어 둔 소지품과 경험치만 돌려준다), 좀비 스코어·처치 수·국가 열기 없음, 증원 소환 0 |
| '망자 회수' 통계·보상 노리기 | 생기거나 합쳐진 지 **2분** 이 지나야 세고, **10분에 1번**까지만 |
| 블러드문 근처 부활로 죽고 살아나기 반복 | 5분 안 3번째 죽음은 원래 리스폰 지점, 부활 직후 5초 보호(좀비 '감염 레벨' 6-1) |
| 망자를 금고·운반 수단으로 | 망자는 움직이지 않으므로 운반은 불가능. 금고로 쓰는 것은 엔더 상자가 이미 같은 일(나만 여는 금고)을 하므로 실익이 없다 |
| 좀비 떼·둥지·감염도 계산 흔들기 | 망자는 좀비 떼 대상 판정, 기억 좀비 구역 상한, 감염 레벨 계산 어디에도 들어가지 않는다 |
| 서버가 꺼지는 순간을 노린 복제 | 소지품은 주인 플레이어 파일에만 있다(8절). 망자 장비 칸은 보이기만 하는 복사본, 떨어뜨릴 확률 0 |

- 운영자 확인용: 좀비에게 **1시간에 7번째로** 쓰러지면 운영자 로그(관리 프로그램 콘솔)에 한 줄 남긴다. 자동 처벌은 없다. 친구 서버라 의도는 사람이 판단한다.
- 부계정은 화이트리스트(가입한 사람만)로 막는다.

2026-11-21. 두 가지 모두 **별도의 자체 상태 효과**(`zomapo:bleeding`, `zomapo:infection`)이고, **좀비 기믹**으로 들어간다. 좀비에게 맞을 때마다 확률로 걸리는 게 아니라, 일정 레벨 이상에서 태어난 좀비 일부가 **특성**을 받고, 그 개체에게 맞으면 **확정으로** 걸린다. 특성마다 눈에 보이는 신호가 있어 보고 피하거나 먼저 잡는다. 코드: `logic` 의 `effects/Wounds.kt`.

| 특성 | 누가 받나 (태어날 때) | 맞으면 | 신호 |
|---|---|---|---|
| **찢는 손톱** | Lv2 이상에서 태어난 모든 좀비 계열(바닐라 좀비·좀비화 몹·변종). Lv2 4%, 레벨마다 +1%p, Lv5 7% | 출혈 | 손에서 핏방울 파티클 |

- 망자·보스는 받지 않는다. 두 특성이 함께 붙을 수 있다(아주 드묾).
- 근접 공격과 투사체(해골 계열의 화살, 도끼잡이의 도끼 등) 모두. 방패로 막으면 걸리지 않는다. 진홍 브루트는 찢는 손톱이 확정이다(좀비 '몹 좀비화' 3절).

#### 3-1. 해독제 (2026-11-21, 4차 손질)

| 항목 | 내용 |
|---|---|
| 아이템 | 바닐라 물약(`minecraft:potion`) + 부품. 바닐라 물약처럼 보이게: **흰 이름 + 바닐라 효과 줄 모양의 속성 한 줄**, 설명 문장은 없다 |
| 속성 | 이름: 물약 이름 키 `zomapo_antidote`(물약은 `item_name` 을 무시하고 물약 내용물로 이름을 정하므로, 리소스팩 언어 파일의 '해독제'). 희귀도 없음(바닐라 물약과 같은 흰 이름). 효과 줄: `감염 해제`(파랑, 기울임 없음 — 바닐라 물약 효과 줄과 같은 모양, 번역 키 `effect.zomapo.cure_infection`). 바닐라 '효과 없음' 줄은 숨김. 물약 색 황금(#E2B23A). 그림 `custom_model_data` `zomapo:antidote`. 판별 `custom_data` |
| 그림 | 고유 디자인(하늘빛 유리 병, 황금색 약물, 금실 감은 코르크). 병 옆 녹색 십자 꼬리표·끈은 뺐다 |
| 효과 | 마시면(1.6초) **감염이 풀린다.** 다른 효과는 없다 |
| **양조기** (효율) | **효과 없는 물병**(물병·어색한·평범한·진한 물약) + **꿀병** → 해독제. 한 번에 3병을 채우면 **꿀병 1개로 3병**. 네더 사마귀가 없어도 물병에서 바로 된다 |
| 제작대 (급할 때) | **꿀병** + **반짝이는 수박 조각 또는 황금 당근** + **썩은 살점** → 해독제 1병(꿀병의 빈 병은 돌려받는다) |

- 두 방식 모두 **바닐라 재료만** 쓴다. 비싼 황금 사과를 뺐다. 양조기는 제작대 재료 중 가장 비싼 꿀병 하나로, 효과 없는 물병에서 만든다.
- 양조가 꿀병 기준 3배 효율이다. 양조기 연료(블레이즈 가루)가 있어야 하므로 초반에는 제작대로 급히 만들고, 네더를 연 뒤 양조기로 넘어간다.
- 썩은 살점은 좀비가 흔히 떨어뜨리므로 '좀비를 잡아 약을 만든다'가 된다. 반짝이는 수박·황금 당근은 바닐라 치유 재료.
- 바이러스 결정은 해독제 재료가 아니다(연구·백신 엔딩·국고 납품 쪽). 같은 방식의 아이템: 자수정 조각 + 이름 번역 키, 희귀도 없음, 갑옷 장식 재료 속성을 떼어 냈고 바닐라 조합법 재료로도 막는다.
- 수치 원본: `logic` 의 `effects/Wounds.kt` (`Antidote`).

얼마나 자주: Lv3 땅에서 하룻밤에 좀비 30~60마리와 부딪히면 보균 개체는 평균 1마리 안팎이다. 신호를 보고 먼저 잡으면 감염되지 않고, 놓치면 한 세션에 한 번쯤 감염된다.

### 4. 표시: 덮어쓰지 않고 자체 HUD 로

바닐라 클라이언트의 **상태 효과 목록은 고정**이다. 서버가 새 효과를 등록해도 효과 번호를 클라이언트로 동기화하지 않으므로(26.3 확인: 클라이언트로 보내는 데이터 레지스트리 목록에 상태 효과가 없다) 바닐라 화면의 효과 칸(인벤토리 옆, 오른쪽 위 아이콘)에는 넣을 수 없다. 보내면 클라이언트가 모르는 번호라 접속이 끊긴다.

| 방법 | 효과 칸에 보임 | 덮어쓰기 | 결정 |
|---|---|---|---|
| 바닐라 효과(행운·불운)로 바꿔 보내고 리소스팩으로 이름·아이콘 교체 | 보임 | 바닐라 효과를 덮어씀 | 안 함(요청) |
| **자체 효과는 서버에만 두고, 화면 위 보스바 한 줄에 아이콘 + 남은 시간** | 효과 칸에는 안 보임 | 없음 | **채택** |

- 표시: 걸려 있는 동안만 화면 위에 보스바 한 줄. 바닐라가 쓰지 않는 **흰색 보스바**를 쓰고, 리소스팩이 흰색 막대 그림을 투명하게 바꿔 **글자와 아이콘만** 보인다(구현: `mod` 의 `wounds/WoundsSystem.kt`, 자산: `respack/`, 만드는 스크립트 `tools/respack/hud_icons.py`). 예: `[핏방울 아이콘] 출혈 0:24   [포자 아이콘] 감염 II 발열`. 블러드문 보스바와 함께 뜨면 두 줄로 쌓인다.
- 아이콘은 리소스팩의 작은 비트맵 글꼴(9×9 그림 2~3장, `zomapo:hud`)로 그린다. 바닐라 글꼴을 바꾸지 않는 새 이름공간 글꼴이라 로딩 부담이 거의 없다(기술 구조 '좀비화 외형' 0-3 개정).
- 효과는 바닐라 상태 효과 목록에 등록하지 않고 **서버가 따로 관리**한다(플레이어 저장 부착 `zomapo:wounds`). 레지스트리에 새 효과를 넣으면 Fabric 레지스트리 동기화가 바닐라 클라이언트를 받지 않으려 하므로 쓰지 않는다. 우유·불사의 토템이 지우는 바닐라 효과 목록과도 저절로 분리된다.
- 운영자 명령: `/zomapo effect give <플레이어> bleeding|infection [단계]`, `/zomapo effect clear <플레이어>`.
- 생존일지·통계: '감염 → 해독' 횟수만 센다.

#### 4-1. 체력 하트 (2026-11-22)

바닐라 클라이언트는 **독·위더·얼어붙음일 때만** 하트 그림을 바꾼다(그 밖의 상태는 하트를 바꿀 방법이 없다). 그 세 자리를 모두 상처가 빌려, 출혈·감염이 따로 걸려도 같이 걸려도 모두 구별되게 한다. 그림은 리소스팩(우리 손그림, `tools/respack/hud_icons.py`).

| 상태 | 빌리는 자리 | 하트 그림 | 그 밖에 보이는 것 |
|---|---|---|---|
| 출혈만 | 위더 하트 | **금 간 붉은 하트**(가운데를 가르는 검붉은 금) | 위 상태 줄 '출혈 0:24' |
| 감염만 | 얼어붙은 하트 | **썩어 가는 하트**(회녹색 살에 녹색 핏줄·검은 괴사 점, 바닐라 독 하트의 노란 초록과 다름) | 화면 가장자리에 녹색 핏줄(바닐라 가루눈 서리 자리), 몸이 열에 떨듯 흔들림(다른 사람에게도 보임) |
| 둘 다 | 독 하트 | **금 가고 썩은 하트**(썩어 가는 하트에 붉은 금) | 상태 줄에 둘 다 |

- 바닐라 우선순위가 독 > 위더 > 얼어붙음이라 둘 다 걸리면 '둘 다' 하트가 보인다.
- 하트용으로 거는 위더·독은 숨겨서(입자·아이콘 없음) 걸고 피해를 막는다. 감염의 얼어붙음은 가루눈 밖이면 감속·동상 피해가 없다.
- **진짜 독·위더**(동굴 거미·물약·복어·위더 스켈레톤·위더 장미 등)는 zomApo 가 같은 피해로 대신 처리한다(독: 체력 1 아래로는 안 내려감, 위더: 죽을 수 있음). 하트는 바뀌지 않고 위 상태 줄에 '독 I 0:12', '위더 II 0:08' 로 보인다. 우유·불사의 토템은 바닐라처럼 이것도 지운다.
- 남는 겹침: 진짜 가루눈에 오래 빠져 얼면 감염과 같은 하트·가장자리가 보인다(가루눈은 드물어 받아들임).

### 5. 구현 메모

- 특성: 좀비 계열이 태어날 때(자연·떼·블러드문·둥지) `ZombieTraits.roll(스폰 레벨)` 한 번, 저장 부착 `zomapo:traits`. 파티클은 2초마다 근처 플레이어에게만.
- 출혈 바닥: 출혈 피해만 체력 1 에서 멈춘다. 감염 유지: 자체 효과라 우유·토템이 건드리지 않는다. 부활해도 플레이어 저장 부착이 그대로 남는다(복사 시 유지).
- 기침·피 냄새는 소음 이벤트로 보낸다.

## 스타포스

> **시즌 1 에서는 꺼 둔다**(2026-11-21, 이유는 [decisions.md](../server/decisions.md) 8-8). 아래 설계와 코드는 다시 켤 때를 위해 남긴다. 2026-11-23 구현: `enchant/StarforceSystem.kt`, 설정 `starforce.enabled=true` 로 켠다(기본 꺼짐). 켜면 대장장이 작업대 웅크리고 우클릭 → 강화·성 옮기기 창.

무기·방어구에 별을 쌓아 강화한다. 장기 목표이자 바이러스 결정·경험치의 소모처다. 이름과 구조는 익숙한 '스타포스' 방식을 따르되, 친구 서버에 맞게 **순한 맛**으로 한다.

### 1. 원칙

- **파괴 없음.** 실패하면 유지되거나 한 단계 떨어질 뿐이다. 오래 모은 장비가 한 번에 사라지는 일은 소수 인원 서버에서 이탈 사유가 된다.
- **좀비 특효.** 강화 보너스는 좀비 계열에 100%, 플레이어에게는 30% 만 적용한다. "바이러스 결정으로 벼린 장비"라는 설정과 맞고, PvP 격차를 억제한다.
- **시즌 1 최대 10성.** 시즌이 3주(핵심 유저 기준 약 75시간)라 15성까지는 닿지 않는다. 11~15성 표는 긴 시즌을 위해 남겨 둔다.

### 2. 대상

| 대상 | 보너스 |
|---|---|
| 근접 무기 (검, 도끼, 철퇴, 창 등) | 좀비 계열에 주는 피해 +2% / 성 |
| 원거리 무기 (활, 석궁) | 좀비 계열에 주는 투사체 피해 +2% / 성 |
| 방어구 (4부위 각각) | 좀비 계열에게 받는 피해 −0.8% / 성 (부위 합산) |

5·10성 달성 보너스: 무기는 피해 +5%p 추가, 방어구는 해당 부위 넉백 저항 +0.05.

| 예 | 좀비 대상 | 플레이어 대상 |
|---|---|---|
| 10성 무기 | 피해 +30% | +9% |
| 10성 방어구 4부위 | 받는 피해 −32% | −9.6% |

### 3. 확률

| 단계 (현재 → 다음) | 성공 | 실패(유지) | 실패(하락) |
|---|---|---|---|
| 0 → 1 ~ 4 → 5 | 95% → 75% (단계마다 −5%p) | 나머지 | 0% |
| 5 → 6 ~ 9 → 10 | 60% → 40% (단계마다 −5%p) | 나머지 | 0% |
| 10 → 11 ~ 14 → 15 (긴 시즌용) | 35% → 15% (단계마다 −5%p) | 나머지의 절반 | 나머지의 절반 |

- **실패 보너스**: 같은 단계에서 실패할 때마다 다음 성공 확률 **+5%p**(성공하면 초기화). 9 → 10 (40%) 도 최대 12번 안에 반드시 성공한다.
- **실패 환급**: 실패하면 바이러스 결정 절반을 돌려준다.
- **찬스 타임**: 연속 2번 하락하면 다음 시도는 100% 성공(11성 이상, 긴 시즌용).
- **스타캐치(선택 구현)**: 강화 GUI 에서 움직이는 별을 목표 칸에서 클릭하면 성공 확률 ×1.05.

### 4. 비용

| 단계 | 바이러스 결정 | 경험치 레벨 | 기타 |
|---|---|---|---|
| 0 ~ 4 | 1 | 2 | |
| 5 ~ 9 | 3 | 3 | |
| 10 ~ 14 (긴 시즌용) | 6 | 10 | 에메랄드 8 |

바이러스 결정은 좀비 계열 처치 시 드랍된다([zombies.md](zombies.md#몹-좀비화) 6절).

#### 4-1. 민심 점검 (2026-11-20, `tools/sim/starforce_sim.py`, 장비 하나 0 → 10성, 5만 번)

| 안 | 시도 평균 | 운 나쁜 10% | 운 나쁜 1% | 결정 평균 | 결정 (운 나쁜 10%) | 경험치 레벨 평균 | 연속 실패 최대 (운 나쁜 10%) |
|---|---|---|---|---|---|---|---|
| 이전안 | 16.1 | 21 | 26 | 36.6 | 50 | 63 | 6번 |
| **현재안** (실패 보너스·환급·5~9성 3레벨) | 15.3 | 19 | 23 | 27.1 | 32 | 40 | 4번 |

친구 서버에서 '스타포스'라는 이름이 주는 불안은 **파괴·하락·연속 실패·남과의 격차** 네 가지다. 그래서:

| 걱정 | 대책 |
|---|---|
| 장비가 터진다 | 파괴 없음 |
| 성이 떨어진다 | 시즌 1(최대 10성)에는 하락 없음 |
| 연속으로 실패한다 | 실패 보너스 +5%p, 실패 환급. 운 나쁜 10% 도 연속 실패 4번 |
| 장비를 바꾸면 성이 날아간다 | **성 옮기기**: 같은 종류의 새 장비(철 검 → 다이아 검)로 성의 80%(내림)를 옮긴다. 다이아 → 네더라이트 업그레이드는 대장장이 작업대에서 성이 그대로 유지된다. 일찍 강화해도 손해가 아니다 |
| 강화한 사람에게 PvP 로 진다 | 플레이어 대상 보너스는 30% 만(10성 무기 +9%, 방어구 −9.6%) |
| 남의 강화 소식이 부담 | 디스코드 알림은 **10성 달성만**. 8~9성은 인게임 소리·파티클만 |
| 경험치를 강화에 다 쓴다 | 5~9성 비용을 5 → 3 레벨로. 인첸트에 쓸 경험치를 남긴다 |

### 5. 사용 방법 (명령어 없음)

- **대장장이 작업대를 웅크리고 우클릭** → 강화 GUI(상자 메뉴)가 열린다. 일반 우클릭은 바닐라 대장장이 작업대 그대로.
- GUI 구성: 가운데 대상 아이템 칸, 아래 재료 칸, 오른쪽에 현재 성·다음 성 확률·비용 표시, '강화' 버튼.
- 결과는 소리·파티클·타이틀로 연출한다. **10성 달성만** 서버 공지와 디스코드 알림.
- 같은 GUI 에 **성 옮기기** 칸: 왼쪽에 옛 장비, 오른쪽에 같은 종류의 새 장비를 놓으면 성의 80% 를 옮긴다(옛 장비의 성은 0).

### 6. 표시

아이템 설명(lore) 첫 줄에 별을 표시한다.

```
★★★★★★★☆☆☆  7성
좀비에게 주는 피해 +14%   (플레이어 +4.2%)
```

- 채워진 별은 노랑 `#FFCC11`, 빈 별은 회색. 바닐라 기본 글꼴에 있는 문자(★☆)만 쓰므로 리소스팩이 필요 없다.
- 아이템 이름에 `+7` 을 붙이지 않는다(이름표·모루 이름을 존중).

### 7. 데이터와 상호작용

- 아이템 컴포넌트 `custom_data` 에 `{"zomapo": {"star": 7, "downStreak": 0, "failBonus": 0.05}}` 저장, lore 는 성이 바뀔 때 다시 만든다.
- 보너스는 공격력 속성이 아니라 **피해 계산 시점**에 적용한다(대상이 좀비 계열인지 플레이어인지에 따라 배율을 달리해야 하므로).
- 모루 수리·인첸트 합치기: 왼쪽 아이템의 성을 유지한다. 오른쪽 아이템의 성은 사라진다(GUI 에 경고).
- 숫돌: 성 유지.
- 망자: 성 포함 그대로 보관된다.
- (폐지) 장비 점수 P 에 성을 반영하던 감염 레벨 개인 보정은 2026-11-20 레벨 규칙 개편에서 없앴다([zombies.md](zombies.md#감염-레벨) 3-5).

## 커스텀 인첸트

### 1. 방식

- 인첸트는 1.21 이후 **데이터 기반**이다. 데이터팩으로 새 인첸트를 등록하면 바닐라 클라이언트도 이름·레벨·툴팁을 그대로 보여 준다.
- 인첸트 정의는 클라이언트로 동기화된다. 그래서 **정의 안에는 바닐라 효과 컴포넌트만** 넣는다. 모드가 새 효과 타입을 등록해서 정의에 넣으면 바닐라 클라이언트가 해석하지 못해 접속이 끊긴다.
- 바닐라 컴포넌트로 표현할 수 없는 효과는 **정의는 비워 두고 모드가 "이 인첸트가 붙어 있는가"를 검사해서** 처리한다.
- 데이터팩은 zomApo jar 에 내장한다(`zomapo-enchants`).

### 2. 목록 (6종)

| 이름 | 대상 | 최대 레벨 | 효과 | 처리 | 획득 |
|---|---|---|---|---|---|
| **정화** | 근접 무기 | V | 좀비 계열(감염형·기수형 포함)에 레벨당 +2.5 피해. 날카로움·강타·살충과 배타 | 모드 (강타는 언데드 타입만 인식하므로 감염형 크리퍼·거미에도 통하게) | 인첸트 테이블 |
| **백신** | 흉갑 | III | 감염(허기·나약함)·독·위더 지속 시간 레벨당 −20% | 모드 | 인첸트 테이블 |
| **수확자** | 무기 | III | 좀비 계열 처치 시 바이러스 결정 추가 드랍 확률 레벨당 +5%p | 루트 테이블 조건(바닐라 `match_tool`) | 보물 (둥지·블러드문 보상) |
| **결속** | 레깅스 | II | 반경 10블록 안에 자국민·동맹이 있으면 받는 피해 레벨당 −6% | 모드 | 인첸트 테이블 |
| **등불** | 투구 | I | 반경 8블록 안 좀비 계열이 **본인에게만** 발광해 보인다 | 모드 (해당 플레이어에게만 발광 플래그를 담은 엔티티 데이터 패킷 전송) | 보물 |
| **질주** | 장화 | II | 반경 12블록 안에 좀비 계열 3마리 이상이면 이동 속도 레벨당 +10% | 모드 | 인첸트 테이블 |

- **결속**은 국가 모드의 '집단 형성' 목표와 맞물리게 넣었다. 함께 다니면 강해진다.
- **등불**은 구현 난이도가 가장 높다(패킷 단위 처리). 일정이 밀리면 시즌 1 에서 뺀다.

### 3. 규칙

- 커스텀 인첸트는 **주민 거래 목록에 넣지 않는다.** 거래소로 찍어내는 것을 막는다.
- 보물 인첸트(수확자, 등불)는 인첸트 테이블에 나오지 않는다(`#minecraft:treasure`).
- 이름은 한국어 리터럴 텍스트로 정의한다. 친구들이 모두 한국어 클라이언트이므로 번역 키 대신 리터럴이 확실하다. 영어 클라이언트 대비가 필요하면 `translate` + `fallback` 으로 바꾼다.
- 정의 파일 경로: `data/zomapo/enchantment/<id>.json`, 태그: `data/minecraft/tags/enchantment/in_enchanting_table.json` 등.

### 4. 예시 (정화)

효과는 모드가 처리하므로 정의에는 표시·비용·대상·배타 관계만 둔다.

```json
{
  "description": { "text": "정화" },
  "supported_items": "#minecraft:enchantable/melee_weapon",
  "primary_items": "#minecraft:enchantable/sword",
  "exclusive_set": "#minecraft:exclusive_set/damage",
  "weight": 5,
  "max_level": 5,
  "min_cost": { "base": 5, "per_level_above_first": 8 },
  "max_cost": { "base": 25, "per_level_above_first": 8 },
  "anvil_cost": 2,
  "slots": ["mainhand"]
}
```

2026-11-23 구현: 정의 6개는 `mod/src/main/resources/data/zomapo/enchantment/`, 태그는 `data/minecraft/tags/enchantment/`(비보물·보물·피해 배타 집합에 덧붙임). 26.3 서버에서 등록을 확인했다. 효과는 `enchant/ZomEnchants.kt`(정화·결속은 피해 계산 믹스인, 백신은 효과 추가 믹스인, 수확자는 처치 시 드랍, 등불은 본인에게만 보내는 발광 패킷, 질주는 1초마다 속도 수정자). 백신은 바닐라 독·위더·허기·나약함에만 듣는다(zomApo 의 출혈·감염은 해독제·붕대가 맡는다). 블러드문 보물 책은 수확자·등불 중 하나.
