## 좀비 통계

PvP 통계(K/D/A)는 국가 모드 쪽에 있다: simpleNationWar 의 [nation.md](https://github.com/menonng/simpleNationWar/blob/HEAD/docs/design/nation.md#kda). 이 문서는 zomApo 가 기록하는 좀비 쪽 통계다.

### 1. 기록 항목

| 항목 | 정의 | 인게임 표시 |
|---|---|---|
| 좀비 처치 수 | 좀비 계열 개체를 플레이어가 처치한 횟수 | O |
| 좀비 스코어 | 처치한 좀비마다 점수표 × 보정을 더한 값 | O |
| 변종별 처치 수 | 변종·변환형별 처치 수 | `/info` 상세(마우스 올림) |
| 최고 레벨 생존 | 머문 적 있는 가장 높은 스폰 레벨 | 칭호 조건용 |
| 둥지 파괴 수, 블러드문 참여·성공 수 | | 칭호 조건용 |
| 망자 회수 수 / 망자 발생 수 | 자기 망자를 되찾은 비율 | `/info` 상세 |
| 최고 강화 성 | 스타포스 최고 기록 | `/info` 상세 |

**좀비 계열**: 바닐라 좀비 계열 엔티티 타입(`#zomapo:zombies`)이거나, zomApo 가 변환해서 부착 정보가 붙은 개체(치환형·감염형·기수형의 기수). 망자 좀비는 제외한다.

**처치 판정**: 바닐라 처치 크레딧을 따른다. 플레이어가 마지막으로 피해를 준 지 5초 안에 죽으면 그 플레이어의 처치다(투사체 소유자, 길들인 늑대 주인 포함).

### 2. 점수

```
획득 점수 = 기본 점수 × 레벨 보정 × 출처 보정 × 기여 보정 × 농장 감쇠
```

| 요소 | 값 |
|---|---|
| 기본 점수 | [zombies.md](zombies.md#몹-좀비화) 의 변환표·변종표 (일반 좀비 1 ~ 알파 25) |
| 레벨 보정 | 1 + 0.1 × 스폰 레벨 (Lv5 = ×1.5) |
| 출처 보정 | 자연 스폰 ×1.0 / 몬스터 스포너 ×0.2 / 감염 둥지 스포너 ×0.5 / 블러드문 웨이브 ×1.2 |
| 기여 보정 | 처치자가 준 피해가 전체의 50% 이상 ×1.0, 미만 ×0.5. 낙하·용암·질식 등 환경 피해만으로 죽으면 0 |
| 농장 감쇠 | 같은 64×64 구역에서 한 플레이어가 1시간에 50마리를 넘게 잡으면 그 뒤로 ×0.3 |

- 처치 **수**는 보정 없이 1씩 올라간다. 감염 레벨의 국가 열기(H)는 처치 수를 쓰지만 농장 감쇠를 적용한 '유효 처치 수'를 쓴다(좀비 농장으로 자국 레벨을 올리거나 내리는 조작 방지).
- 공동 처치 보너스(둥지 파괴, 블러드문)는 참여자에게 균등 분배한다. 참여 = 해당 이벤트 동안 반경 48블록 안에서 좀비 계열에 피해를 1 이상 준 플레이어.

### 3. 저장

- 플레이어 부착(attachment)이 아니라 **월드 `SavedData`(`zomapo_stats`)에 UUID 별로** 저장한다. 오프라인 플레이어의 `/info`, 국가 합계, 디스코드 봇 조회를 플레이어를 불러오지 않고 처리하기 위해서다.
- 일 단위 기록(날짜별 처치 수·유효 처치 수·점수)을 함께 남긴다. 감염 레벨의 '최근 72시간' 계산과 시즌 결산 그래프에 쓴다.

```json
{
  "uuid": "…",
  "zombieKills": 1284,
  "zombieScore": 2391.4,
  "byForm": { "zombie": 702, "runner": 133, "archer_zombie": 98, "alpha": 2 },
  "daily": { "2027-01-09": { "kills": 41, "effectiveKills": 41, "score": 52.0 } },
  "nestsDestroyed": 3,
  "bloodMoons": { "joined": 5, "won": 4 },
  "revenants": { "created": 7, "recovered": 6 },
  "maxStar": 11,
  "peakSpawnLevel": 4.6
}
```

### 4. 인게임 확인

명령어를 따로 만들지 않는다. simpleNationWar 의 `/info` 와 국가 GUI 국민 목록에 **통계 제공자**로 줄을 끼워 넣는다(`snw:stat_provider` 엔트리포인트, [architecture.md](../tech/architecture.md#구조)).

```
철수 (Steve123)  ·  적국 · 간부
K 12   KDA 1.84
좀비 처치 1,284   좀비 스코어 2,391
```

simpleNationWar 가 없는 환경(zomApo 단독 테스트)에서는 관리자 명령 `/zomapo stats <플레이어>` 로만 본다.

### 5. 쓸 곳 (제안)

| 용도 | 방식 |
|---|---|
| 감염 레벨 | 국가 열기 H 의 입력 (유효 처치 수) |
| 영토 상한 | simpleNationWar 의 영토 상한에 국가 좀비 스코어 보너스(√ 비례) |
| 치료제 연구 | 단계별 '변종 n종 처치' 조건 |
| 칭호 | 학살자(처치 수 1위), 사냥꾼(알파 처치), 정화자(둥지 파괴), 불사(망자 회수율) 등 |
| 디스코드 | 주간 랭킹, 시즌 결산 그래프 |
| 다음 시즌 | 점수표·확률 밸런스 자료 |

## 망자 좀비

keepInventory 를 끄는 대신, **좀비에게 죽으면** 죽은 자리에 **내 소지품을 든 좀비('망자')** 가 남는다. 처치하면 소지품이 돌아온다.

| 사망 원인 | 소지품 |
|---|---|
| **좀비 계열에게 죽음**(바닐라 좀비, 좀비화 몹, 좀비 떼, 블러드문) | **망자** |
| 좀비에게 맞은 지 10초 안에 낙하·용암·익사·폭발·다른 몹으로 죽음 | 좀비 탓으로 보고 **망자** |
| PvP | **바닐라 드랍**. 이긴 쪽이 주울 수 있다(전투의 보상) |
| 그 밖의 죽음(환경, 좀비가 아닌 몹) | **보존 드랍**: 바닐라처럼 떨어지되 15분 동안 사라지지 않고, 불·용암·폭발·선인장에 타지 않는다. 공허에서 죽으면 마지막으로 서 있던 단단한 땅에 떨어진다 |

2026-11-20 결정: 망자는 좀비 아포칼립스다운 죽음에만 남긴다. PvP 약탈은 다시 허용하고(전쟁의 보상), 억울한 사고사(용암·공허)는 보존 드랍으로 살린다. 판정 코드: `logic` 의 `DeathRules.decide`.

처음 구상했던 "좀비에게 죽은 플레이어가 추격자가 된다"를 20명 안팎(국가당 7명 안팎) 서버에 맞게 바꾼 것이다. 사람이 좀비 편이 되면 인원이 적은 서버에서는 생존자 쪽이 금방 무너진다. 대신 '나의 좀비'가 내 장비를 들고 기다린다.

### 1. 흐름

1. 플레이어가 죽는다. 아이템(번들·셜커 상자 내용물 포함)과 드랍될 경험치를 바닥에 떨어뜨리지 않고 회수한다.
2. 사망 지점에 망자 좀비가 생긴다.
3. **망자는 주인만 쓰러뜨릴 수 있다.** 쓰러뜨리면 그 자리에 소지품과 경험치가 모두 떨어진다(주인만 주울 수 있게 1분 잠금).

2026-11-20 개편: 다른 사람이 망자를 잡아 소지품을 가져가는 규칙(PvP 사망 약탈)을 없앴다. 망자는 '나와 나의 좀비' 사이의 일이다.

### 2. 망자 좀비

| 항목 | 규칙 |
|---|---|
| 외형 | 사망자 스킨의 플레이어 머리, 사망 당시 입던 방어구·손에 든 아이템을 **보이기만** 한다 |
| 이름표 | `망자 · {커스텀 닉네임}` (항상 표시) |
| 능력치 | 사망 지점의 영역 레벨 기준 고정값(체력 = 일반 좀비 × 2). 입고 있는 장비의 능력치는 적용하지 않는다. 맨몸으로 돌아와도 되찾을 수 있어야 한다 |
| 이동 | **사망 지점 주변을 배회한다.** 반경 16블록에 묶이고, 그 밖으로 끌려가면 순간이동으로 돌아온다 |
| 지속 | 디스폰하지 않는다. **햇빛에 타지 않고 태양광 알레르기도 없다.** 아이템을 줍지 않는다. 좀비화·변종·레벨 강화 대상이 아니다 |
| 공격 | **주인만 노린다.** 다른 플레이어는 공격하지 않고, 다른 플레이어가 가까이 오거나 때려도 어그로가 끌리지 않는다 |
| 피해 | **주인이 준 피해만 받는다.** 다른 플레이어·몹·용암·낙하·폭발·익사 피해는 모두 무시한다(소지품이 사라질 길이 없다) |
| 문·블록 | 문을 부수지 않고 압력판을 밟지 않는다(남의 기지를 흔들지 않게) |
| 점수 | 좀비 스코어·처치 수 없음 (자기 죽음으로 점수를 쌓는 악용 방지) |

### 3. 주인 전용 규칙의 결과

| 항목 | 전 | 후 |
|---|---|---|
| 보호 시간 | PvE 사망 10분 보호, PvP 사망 보호 없음 | 필요 없음(항상 주인만) |
| PvP 사망 | 이긴 쪽이 망자를 잡아 소지품을 가져감 | 망자가 생기지 않고 **바닐라처럼 떨어진다.** 이긴 쪽이 주울 수 있다 |
| 친구 도움 | 자국민이 대신 잡아 줄 수 있었음 | 대신 잡아 줄 수 없다. 대신 **주변 좀비를 치워 주는** 협동이 된다. 망자는 주인이 올 때까지 기다린다 |
| 생존일지 | '망자 약탈' 사건 | 더 이상 생기지 않는다. '망자 회수'만 남는다 |

망자는 '나와 나의 좀비' 사이의 일로만 남기고, 사람끼리의 싸움은 바닐라 규칙(떨어진 것을 줍는다)으로 돌려놓았다.

### 4. 위험한 장소

| 상황 | 처리 |
|---|---|
| 용암·공허·질식 위치 | 플레이어가 마지막으로 단단한 땅 위에 서 있던 위치(1초마다 기록)에 생성 |
| 공허(엔드 바깥) | 엔드 출구 포탈 근처 안전 지점 |
| 생존자 캠프 | 캠프 경계 바로 밖 |
| 타국 영토 | 그 자리 그대로. 주인만 잡을 수 있으므로 상대 국가가 가져갈 수는 없다. 대신 적의 땅까지 다시 가야 한다 |
| 망자가 아닌 죽음 | 위 표의 '보존 드랍' 또는 바닐라 드랍 |

### 5. 개수: 한 사람당 망자 1마리, 다시 죽으면 합쳐진다

- 망자가 남아 있는 상태에서 또 죽으면, **이전 망자가 새 사망 지점으로 옮겨 와 소지품을 합친다.** 소지품을 잃는 길이 없고, 여러 군데를 돌아다닐 필요도 없다.
- 합친 망자의 체력은 새 사망 지점 레벨 기준으로 다시 정한다.
- 망자가 있는 청크가 언로드되면 그대로 멈춰 있다가 다시 불러오면 이어진다. 시즌이 끝날 때까지 남는다.

### 6. 알림

- 사망자에게: `망자가 남았습니다. 좌표 x, y, z`. 나침반 대신 액션바에 방향·거리를 1분 동안 표시.
- **본인에게만 보이는 마커**: 망자 머리 위에 발광하는 가짜 엔티티(패킷 전용 표시 엔티티)를 띄운다. 다른 사람에게는 이 마커가 보내지지 않으므로 벽 너머로 위치가 드러나지 않는다. monun 의 series-survival 이 생존자 위치를 좀비 진영에게만 보이는 가짜 엔티티로 알려 준 기법이다([monun.md](../reference/monun.md) 2절).
- 디스코드: 알림 채널에는 "철수 님이 망자가 되었습니다"만. **좌표는 본인 DM 으로만** 보낸다(이제 주인만 잡을 수 있으므로 국가 채널에 올릴 이유가 없다).
- 망자를 되찾으면 망자 회수 통계가 올라간다.

### 7. 다른 선택지와 비교

| 방식 | 긴장감 | 복구 | 테마 | 분쟁 |
|---|---|---|---|---|
| keepInventory | 없음 | 완전 | 없음 | 없음 |
| 바닐라 드랍 | 높음 | 5분 안에 가야 함, 자주 실패 | 보통 | 줍기 경쟁 |
| 무덤 모드 | 낮음 | 안전 | 없음 | 적음 |
| **망자 좀비 (주인 전용)** | 높음 | 싸워서 되찾음, 시간 제한 없음 | 강함 | 없음(주인만 잡음) |

### 8. 구현 메모

- 사망 이벤트에서 드랍 목록을 가로채 비우고, 아이템 스택 목록과 경험치를 망자 엔티티의 저장 부착(`RevenantData{owner, items, xp, deathTime, cause, anchor}`)에 넣는다.
- 망자는 바닐라 좀비 엔티티 + 부착. 지속성 설정(디스폰 금지), 아이템 줍기 금지, 햇빛 연소 무시, 문 부수기 끔은 믹스인으로 처리한다.
- 주인 전용: 피해 처리(`hurtServer`)에서 공격자가 주인이 아니면 취소. 표적 목표는 주인만 고르는 전용 목표로 바꾸고, 다른 플레이어에게 맞아도 `setTarget` 하지 않는다. 다른 몹의 표적 후보에서도 뺀다.
- 합치기: 같은 주인의 망자가 이미 있으면 그 엔티티를 새 위치로 옮기고 부착의 아이템 목록을 이어 붙인다(엔티티를 새로 만들지 않아 복제 위험이 없다).
- 망자의 장비 슬롯에는 사망 당시 장비의 **복사본**을 두고 드랍 확률을 0 으로 한다. 실제 아이템은 부착 데이터에만 있다(복제 방지).
- 보호 시간 판정은 피해 이벤트에서 공격자의 국가를 `snw-api` 로 확인한다.
- K/D/A 의 D 는 원래 사망 시점에 한 번만 센다. 망자 처치는 K 에 들어가지 않는다.

## 스타포스

> **시즌 1 에서는 꺼 둔다**(2026-11-21, 이유는 [decisions.md](../server/decisions.md) 8-8). 아래 설계와 코드는 다시 켤 때를 위해 남긴다.

무기·방어구에 별을 쌓아 강화한다. 장기 목표이자 바이러스 결정·경험치의 소모처다. 이름과 구조는 익숙한 '스타포스' 방식을 따르되, 친구 서버에 맞게 **순한 맛**으로 한다.

### 1. 원칙

- **파괴 없음.** 실패하면 유지되거나 한 단계 떨어질 뿐이다. 오래 모은 장비가 한 번에 사라지는 일은 소수 인원 서버에서 이탈 사유가 된다.
- **좀비 특효.** 강화 보너스는 좀비 계열에 100%, 플레이어에게는 30% 만 적용한다. "바이러스 결정으로 벼린 장비"라는 설정과 맞고, PvP 격차를 억제한다.
- **시즌 1 최대 10성.** 시즌이 3주(핵심 유저 기준 약 75시간)라 15성까지는 닿지 않는다. 11~15성 표는 긴 시즌을 위해 남겨 둔다.

### 2. 대상

| 대상 | 보너스 |
|---|---|
| 근접 무기 (검, 도끼, 철퇴, 창 등) | 좀비 계열에 주는 피해 +2% / 성 |
| 원거리 무기 (활, 석궁) | 좀비 계열에 주는 투사체 피해 +2% / 성 |
| 방어구 (4부위 각각) | 좀비 계열에게 받는 피해 −0.8% / 성 (부위 합산) |

5·10성 달성 보너스: 무기는 피해 +5%p 추가, 방어구는 해당 부위 넉백 저항 +0.05.

| 예 | 좀비 대상 | 플레이어 대상 |
|---|---|---|
| 10성 무기 | 피해 +30% | +9% |
| 10성 방어구 4부위 | 받는 피해 −32% | −9.6% |

### 3. 확률

| 단계 (현재 → 다음) | 성공 | 실패(유지) | 실패(하락) |
|---|---|---|---|
| 0 → 1 ~ 4 → 5 | 95% → 75% (단계마다 −5%p) | 나머지 | 0% |
| 5 → 6 ~ 9 → 10 | 60% → 40% (단계마다 −5%p) | 나머지 | 0% |
| 10 → 11 ~ 14 → 15 (긴 시즌용) | 35% → 15% (단계마다 −5%p) | 나머지의 절반 | 나머지의 절반 |

- **실패 보너스**: 같은 단계에서 실패할 때마다 다음 성공 확률 **+5%p**(성공하면 초기화). 9 → 10 (40%) 도 최대 12번 안에 반드시 성공한다.
- **실패 환급**: 실패하면 바이러스 결정 절반을 돌려준다.
- **찬스 타임**: 연속 2번 하락하면 다음 시도는 100% 성공(11성 이상, 긴 시즌용).
- **스타캐치(선택 구현)**: 강화 GUI 에서 움직이는 별을 목표 칸에서 클릭하면 성공 확률 ×1.05.

### 4. 비용

| 단계 | 바이러스 결정 | 경험치 레벨 | 기타 |
|---|---|---|---|
| 0 ~ 4 | 1 | 2 | |
| 5 ~ 9 | 3 | 3 | |
| 10 ~ 14 (긴 시즌용) | 6 | 10 | 에메랄드 8 |

바이러스 결정은 좀비 계열 처치 시 드랍된다([zombies.md](zombies.md#몹-좀비화) 6절).

#### 4-1. 민심 점검 (2026-11-20, `tools/sim/starforce_sim.py`, 장비 하나 0 → 10성, 5만 번)

| 안 | 시도 평균 | 운 나쁜 10% | 운 나쁜 1% | 결정 평균 | 결정 (운 나쁜 10%) | 경험치 레벨 평균 | 연속 실패 최대 (운 나쁜 10%) |
|---|---|---|---|---|---|---|---|
| 이전안 | 16.1 | 21 | 26 | 36.6 | 50 | 63 | 6번 |
| **현재안** (실패 보너스·환급·5~9성 3레벨) | 15.3 | 19 | 23 | 27.1 | 32 | 40 | 4번 |

친구 서버에서 '스타포스'라는 이름이 주는 불안은 **파괴·하락·연속 실패·남과의 격차** 네 가지다. 그래서:

| 걱정 | 대책 |
|---|---|
| 장비가 터진다 | 파괴 없음 |
| 성이 떨어진다 | 시즌 1(최대 10성)에는 하락 없음 |
| 연속으로 실패한다 | 실패 보너스 +5%p, 실패 환급. 운 나쁜 10% 도 연속 실패 4번 |
| 장비를 바꾸면 성이 날아간다 | **성 옮기기**: 같은 종류의 새 장비(철 검 → 다이아 검)로 성의 80%(내림)를 옮긴다. 다이아 → 네더라이트 업그레이드는 대장장이 작업대에서 성이 그대로 유지된다. 일찍 강화해도 손해가 아니다 |
| 강화한 사람에게 PvP 로 진다 | 플레이어 대상 보너스는 30% 만(10성 무기 +9%, 방어구 −9.6%) |
| 남의 강화 소식이 부담 | 디스코드 알림은 **10성 달성만**. 8~9성은 인게임 소리·파티클만 |
| 경험치를 강화에 다 쓴다 | 5~9성 비용을 5 → 3 레벨로. 인첸트에 쓸 경험치를 남긴다 |

### 5. 사용 방법 (명령어 없음)

- **대장장이 작업대를 웅크리고 우클릭** → 강화 GUI(상자 메뉴)가 열린다. 일반 우클릭은 바닐라 대장장이 작업대 그대로.
- GUI 구성: 가운데 대상 아이템 칸, 아래 재료 칸, 오른쪽에 현재 성·다음 성 확률·비용 표시, '강화' 버튼.
- 결과는 소리·파티클·타이틀로 연출한다. **10성 달성만** 서버 공지와 디스코드 알림.
- 같은 GUI 에 **성 옮기기** 칸: 왼쪽에 옛 장비, 오른쪽에 같은 종류의 새 장비를 놓으면 성의 80% 를 옮긴다(옛 장비의 성은 0).

### 6. 표시

아이템 설명(lore) 첫 줄에 별을 표시한다.

```
★★★★★★★☆☆☆  7성
좀비에게 주는 피해 +14%   (플레이어 +4.2%)
```

- 채워진 별은 노랑 `#FFCC11`, 빈 별은 회색. 바닐라 기본 글꼴에 있는 문자(★☆)만 쓰므로 리소스팩이 필요 없다.
- 아이템 이름에 `+7` 을 붙이지 않는다(이름표·모루 이름을 존중).

### 7. 데이터와 상호작용

- 아이템 컴포넌트 `custom_data` 에 `{"zomapo": {"star": 7, "downStreak": 0, "failBonus": 0.05}}` 저장, lore 는 성이 바뀔 때 다시 만든다.
- 보너스는 공격력 속성이 아니라 **피해 계산 시점**에 적용한다(대상이 좀비 계열인지 플레이어인지에 따라 배율을 달리해야 하므로).
- 모루 수리·인첸트 합치기: 왼쪽 아이템의 성을 유지한다. 오른쪽 아이템의 성은 사라진다(GUI 에 경고).
- 숫돌: 성 유지.
- 망자: 성 포함 그대로 보관된다.
- (폐지) 장비 점수 P 에 성을 반영하던 감염 레벨 개인 보정은 2026-11-20 레벨 규칙 개편에서 없앴다([zombies.md](zombies.md#감염-레벨) 3-5).

## 커스텀 인첸트

### 1. 방식

- 인첸트는 1.21 이후 **데이터 기반**이다. 데이터팩으로 새 인첸트를 등록하면 바닐라 클라이언트도 이름·레벨·툴팁을 그대로 보여 준다.
- 인첸트 정의는 클라이언트로 동기화된다. 그래서 **정의 안에는 바닐라 효과 컴포넌트만** 넣는다. 모드가 새 효과 타입을 등록해서 정의에 넣으면 바닐라 클라이언트가 해석하지 못해 접속이 끊긴다.
- 바닐라 컴포넌트로 표현할 수 없는 효과는 **정의는 비워 두고 모드가 "이 인첸트가 붙어 있는가"를 검사해서** 처리한다.
- 데이터팩은 zomApo jar 에 내장한다(`zomapo-enchants`).

### 2. 목록 (6종)

| 이름 | 대상 | 최대 레벨 | 효과 | 처리 | 획득 |
|---|---|---|---|---|---|
| **정화** | 근접 무기 | V | 좀비 계열(감염형·기수형 포함)에 레벨당 +2.5 피해. 날카로움·강타·살충과 배타 | 모드 (강타는 언데드 타입만 인식하므로 감염형 크리퍼·거미에도 통하게) | 인첸트 테이블 |
| **백신** | 흉갑 | III | 감염(허기·나약함)·독·위더 지속 시간 레벨당 −20% | 모드 | 인첸트 테이블 |
| **수확자** | 무기 | III | 좀비 계열 처치 시 바이러스 결정 추가 드랍 확률 레벨당 +5%p | 루트 테이블 조건(바닐라 `match_tool`) | 보물 (둥지·블러드문 보상) |
| **결속** | 레깅스 | II | 반경 10블록 안에 자국민·동맹이 있으면 받는 피해 레벨당 −6% | 모드 | 인첸트 테이블 |
| **등불** | 투구 | I | 반경 8블록 안 좀비 계열이 **본인에게만** 발광해 보인다 | 모드 (해당 플레이어에게만 발광 플래그를 담은 엔티티 데이터 패킷 전송) | 보물 |
| **질주** | 장화 | II | 반경 12블록 안에 좀비 계열 3마리 이상이면 이동 속도 레벨당 +10% | 모드 | 인첸트 테이블 |

- **결속**은 국가 모드의 '집단 형성' 목표와 맞물리게 넣었다. 함께 다니면 강해진다.
- **등불**은 구현 난이도가 가장 높다(패킷 단위 처리). 일정이 밀리면 시즌 1 에서 뺀다.

### 3. 규칙

- 커스텀 인첸트는 **주민 거래 목록에 넣지 않는다.** 거래소로 찍어내는 것을 막는다.
- 보물 인첸트(수확자, 등불)는 인첸트 테이블에 나오지 않는다(`#minecraft:treasure`).
- 이름은 한국어 리터럴 텍스트로 정의한다. 친구들이 모두 한국어 클라이언트이므로 번역 키 대신 리터럴이 확실하다. 영어 클라이언트 대비가 필요하면 `translate` + `fallback` 으로 바꾼다.
- 정의 파일 경로: `data/zomapo/enchantment/<id>.json`, 태그: `data/minecraft/tags/enchantment/in_enchanting_table.json` 등.

### 4. 예시 (정화)

효과는 모드가 처리하므로 정의에는 표시·비용·대상·배타 관계만 둔다.

```json
{
  "description": { "text": "정화" },
  "supported_items": "#minecraft:enchantable/melee_weapon",
  "primary_items": "#minecraft:enchantable/sword",
  "exclusive_set": "#minecraft:exclusive_set/damage",
  "weight": 5,
  "max_level": 5,
  "min_cost": { "base": 5, "per_level_above_first": 8 },
  "max_cost": { "base": 25, "per_level_above_first": 8 },
  "anvil_cost": 2,
  "slots": ["mainhand"]
}
```

필드 이름은 26.3 데이터팩 형식으로 검증한 뒤 확정한다.
