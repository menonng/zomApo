# 몹 좀비화와 좀비 변종

2026-11-20 개편. 굵은 글씨는 운영자가 정한 규칙, (제안) 표시는 설계 쪽 추천이다. 판정 코드: `logic` 모듈 `spawn/Zombification.kt`(계열·출처·루트), `spawn/LevelRules.kt`(레벨별 효과).

## 1. 원칙

- **좀비화 = 원종 엔티티를 그대로 두고** 좀비 특성(2절)과 좀비화 외형([visuals.md](visuals.md)), 좀비 루트테이블(6절)을 더하는 것. 원종의 AI·기믹은 살리고, 그 위에 '좀비 느낌'의 변형을 얹는다(3절).
- 바닐라에 좀비 짝이 있는 몬스터는 그 바닐라 좀비로 바꾼다: **호글린 → 조글린, 피글린 → 좀비화 피글린**(바닐라 주민 → 좀비 주민, 말 → 좀비 말과 같은 방식).
- 이전 판의 '치환형'(원본 대신 좀비 몸체를 스폰하고 원본 머리를 씌움)은 폐기한다. 서버 리소스팩을 쓰기로 해서 원종 몸에 외형을 덧입힐 수 있게 됐고, 원종을 그대로 두면 활·자폭·순간이동 같은 기믹을 다시 만들 필요가 없다.

### 1-1. 레벨별 좀비화 계열

| 레벨 | 새로 좀비화되는 계열 |
|---|---|
| 0 | 없음 (바닐라와 같음) |
| 1 | **스켈레톤 계열**(스켈레톤, 스트레이, 보그드, 파치드), **거미 계열**(거미, 동굴 거미) |
| 2 | **크리퍼, 엔더맨, 크리킹, 슬라임** + (제안) 팬텀 |
| 3 | **좀벌레, 우민 계열**(약탈자, 변명자, 소환사, 환술사), **가디언, 브리즈, 셜커, 네더 몹**(가스트, 블레이즈, 마그마 큐브, 위더 스켈레톤, 피글린 → 좀비화 피글린, 호글린 → 조글린) + (제안) 엔더마이트, 마녀 |
| 4 | (새 계열 없음) **좀비 기본 체력 ×1.5** |
| 5 | (새 계열 없음) 알파 |

한 계열이 해금되면 그 레벨 이상 청크의 해당 자연 스폰은 **확률 없이 전부** 좀비화된다.

### 1-2. 언제 바꾸나: 자연 스폰 순간에 바꾼다

**결정: 별도의 '좀비화 몹 스폰 목록'을 만들지 않고, 원종이 자연 스폰되는 순간 그 청크 레벨을 보고 좀비화한다.**

- 원종의 스폰 조건(바이옴, 빛, 높이, 슬라임 청크, 순찰대 주기)을 그대로 따르므로 어디서 무엇이 나오는지가 바닐라 감각과 같다.
- 몬스터 수가 늘지 않는다(성능). 수를 늘리는 일은 좀비 스폰률([zombification.md](zombification.md) 2절)이 맡는다.

| 스폰 출처 (26.3 `EntitySpawnReason`) | 처리 |
|---|---|
| 야생 자연 스폰(`NATURAL`), 순찰대(`PATROL`) | **레벨이 차면 좀비화** |
| 구조물 스폰 목록(요새, 해저 신전, 전초기지, 마녀 오두막 안의 `NATURAL`) | 바닐라 그대로. **예외: 가디언**(요구), 블레이즈·위더 스켈레톤(요새에서만 나오는 몹이라 예외로 둠) |
| 구조물과 함께 생성(`STRUCTURE`, `CHUNK_GENERATION`: 엔드 시티 셜커, 저택 우민, 엘더 가디언) | 바닐라 그대로. **예외: 셜커**(엔드 시티에서만 나옴) |
| 시련 스포너(`TRIAL_SPAWNER`) | 바닐라 그대로. **예외: 브리즈**(시련의 방에서만 나옴) |
| 몬스터 스포너(`SPAWNER`) | 바닐라 그대로 (경험치 농장에서 좀비 루트를 뽑는 것을 막는다) |
| 습격(`EVENT`), 소환(`MOB_SUMMONED`, `REINFORCEMENT`), 알·명령어·번식·바닐라 변환 | 바닐라 그대로 |
| 슬라임·마그마 큐브 분열 | **부모를 따른다** |
| **슬라임** | 슬라임 청크·늪 모두 자연 스폰이므로 위 규칙대로(요구: "청크 레벨이 일정 수준 이상이면") |

## 2. 좀비 공통 특성

좀비화 몹에 붙는 것. 이미 좀비인 몹(좀비, 허스크, 드라운드, 좀비 주민, 좀비화 피글린, 조글린, 좀비 말, 낙타 허스크, 좀비 앵무조개, 26.4 프로스트바이트)은 바닐라 그대로에 레벨 강화만 받는다.

| 특성 | 내용 |
|---|---|
| 언데드 | 강타 인첸트가 먹힌다, 치유·피해 물약이 뒤집힌다, 독·재생이 듣지 않는다 (엔티티 태그는 종류 단위라 개체별로는 믹스인으로) |
| 햇빛 | **레벨 2 이상 출신은 안 탄다.** 0~1 출신은 바닐라처럼 탄다(원래 안 타는 몹은 그대로 안 탄다) |
| 태양광 알레르기 | **낮 동안 모든 좀비**에. 단계 = 4 − 스폰 레벨 (zombification.md 2절) |
| 레벨 강화 | 레벨 4 이상 체력 ×1.5 등 (zombification.md 2절 표) |
| 공격성 | 좀비화된 중립 몹(거미, 피글린)은 먼저 공격한다. 엔더맨만 원종 규칙(눈 마주침)을 지키고, 레벨 4 이상 출신은 먼저 공격한다 |
| 감염 (제안) | 근접·투사체 공격이 맞으면 허기 I 3~5초. 바닐라 허스크의 허기와 같은 결 |
| 증원 (제안) | 좀비처럼 맞으면 근처에 같은 레벨 좀비를 부를 수 있다(바닐라 좀비 증원 속성, 레벨 강화 배율) |
| 주민 | 주민을 공격하고, 죽이면 좀비 주민으로 만든다(좀비 규칙) |
| 망자 좀비 | 이 규칙들의 대상이 아니다([death-and-revenant.md](death-and-revenant.md)) |

## 3. 계열별 좀비화

원종 기믹은 모두 이어받는다. '좀비 변형' 칸이 원종 위에 더하거나 바꾸는 것이다(추가·제한·버프·반전). 모두 (제안).

| 원종 | 이름 | Lv | 좀비 변형 | 외형 방식 | 점수 |
|---|---|---|---|---|---|
| 스켈레톤·스트레이·보그드·파치드 | 부패 궁수 | 1 | 화살에 허기 추가(원종 효과 화살은 유지). 4블록 안에서는 활 대신 할퀴기(근접 2). 레벨 2+ 출신은 햇빛에 안 탐 | 장비 레이어(살점 붙은 뼈) | 2 |
| 거미·동굴 거미 | 감염 거미 | 1 | **낮에도 적대**(중립 반전). 물면 허기. Lv3+ 출신 20% 는 아기 좀비 기수 | 리그(2단계) / 포자 | 2 |
| 크리퍼 | 부패 크리퍼 | 2 | 폭발 위력 3 → 2.5 로 낮추는 대신 **포자 구름**(반경 3, 허기 II·멀미 6초)을 남기고 30% 확률로 아기 좀비 1~2마리가 기어 나온다. 대전 크리퍼 규칙 유지 | 리그 | 3 |
| 엔더맨 | 공허 부패자 | 2 | **반전**: 맞으면 도망치는 대신 공격자 **뒤로** 순간이동. 블록을 들지 않는다(지형 훼손 감소). 물 약점·진주 드랍 유지 | 리그 | 3 |
| 크리킹 | 부패 크리킹 | 2 | 시선을 받아도 0.5초 늦게 굳는다(부패로 굼뜸). 심장 연동 유지 | 리그 / 눈 텍스처 | 2 |
| 슬라임 | 부패 슬라임 | 2 | 분열 개체도 좀비화. 가장 작은 개체가 죽을 때 20% 아기 좀비 | 리그(정육면체) | 크기 1 기준 1 |
| 팬텀 (제안) | 부패 팬텀 | 2 | 레벨 2+ 출신은 안 탐. 급강하 적중 시 허기 | 리그 / 눈 | 3 |
| 좀벌레·엔더마이트 | 부패 좀벌레 | 3 | 동료를 깨울 때 10% 아기 좀비 | 포자 | 0.5 |
| 약탈자 (순찰대) | 부패 약탈자 | 3 | 석궁 화살에 허기. 순찰대 대장 깃발 유지 | 머리 모델 | 2 |

| 소환사 | 부패 소환사 | 3 | 벡스 대신 아기 좀비 3마리. **불사의 토템 드랍 유지** | 머리 모델 | 8 |

- '포자 구름'은 바닐라 잔류 효과 구름(area effect cloud)이라 바닐라 클라이언트가 그대로 그린다.
- 원종에서 진행 아이템을 주는 몹(브리즈 막대, 블레이즈 막대, 셜커 껍데기, 엔더 진주, 불사의 토템)은 원종 루트를 그대로 굴리므로 진행에 지장이 없다.

## 4. 제외

| 원종 | 이유 |
|---|---|
| 엔더 드래곤, 위더 | 보스 |
| 엘더 가디언 | 미니 보스(해저 신전당 3마리, 구조물 생성) |
| 워든 | 요구 사항 |
| 라바저 | 습격에서만 나온다(습격은 바닐라 규칙) |
| 벡스 | 소환사가 부르는 소환물 |
| 피글린 브루트 | 보루 구조물에서만 나온다 |
| 스트라이더, 유황 큐브(26.x) | 공격하지 않는 몹. 유황 큐브는 26.3 jar 기준 표적 목표를 따로 정의하고 있어 **공격성 확인 필요**. 적대라면 슬라임 계열(Lv2)에 넣는다 |
| 몬스터 분류가 아닌 몹 전부 | 늑대, 벌, 북극곰, 철 골렘 등 (요구 사항) |

`Zombification.FAMILY` 에 없는 몬스터는 제외로 두고 서버 로그에 경고를 남긴다. 버전을 올릴 때 이 경고를 보고 표를 갱신한다(26.4 프로스트바이트는 이미 좀비 계열로 넣어 둠).

## 5. 추천: 몬스터가 아닌 몹의 좀비 짝 (선택, 기본 꺼짐)

바닐라에는 동물의 좀비 짝도 있다: 말 → 좀비 말, 낙타 → 낙타 허스크, 앵무조개 → 좀비 앵무조개(1.21.11 이후 기수 몹을 태우고 나온다). 요구 규칙("몬스터만")에 따라 기본은 끄고, 분위기를 원하면 켠다.

| 설정 | 내용 |
|---|---|
| `animals.zombify = true` | Lv3 이상 청크 자연 스폰의 말 15% → 좀비 말(좀비 기수), 사막 낙타 15% → 낙타 허스크(허스크 기수), 바다 앵무조개 20% → 좀비 앵무조개 |
| 주민 | 제외. 주민 상한·번식 제한([decisions.md](../server/decisions.md) 1절)과 충돌한다 |

## 6. 드랍

> "원종의 드랍템 루트테이블에 좀비의 루트테이블을 확률과 실행 모두 개별적으로 추가"

| 개체 | 굴리는 루트 테이블 |
|---|---|
| 좀비화 몹 | **원종 테이블 + `minecraft:entities/zombie`**. 같은 루트 컨텍스트(처치자, 약탈, 사망 원인)로 **각각 따로** 굴려 둘 다 떨군다 |
| 좀비화하지 않은 개체(구조물·스포너 출신 등) | 원종 테이블만 |
| 바닐라 짝으로 바뀐 개체(조글린, 좀비화 피글린) | 그 바닐라 테이블 |
| 슬라임·마그마 큐브 | 좀비 테이블은 가장 작은 개체가 죽을 때만 |

- 경험치: 원종 × (1 + 0.1 × 스폰 레벨) (제안).
- **바이러스 결정**: 확률 = min(50%, 점수 × 2%). 스타포스·치료제 연구 재료(기존 유지).
- 구현: 26.3 `LivingEntity.dropFromLootTable(level, source, playerKill, ResourceKey<LootTable>)` 로 좀비 테이블을 한 번 더 굴린다.

## 7. 좀비 변종

바닐라 좀비 계열(좀비, 허스크, 드라운드, 좀비 주민 등)이 스폰될 때 스폰 레벨별 가중치로 변종을 고른다. 좀비화 몹은 원종 기믹이 이미 있으므로 변종을 붙이지 않는다(알파 호위로만 등장). 해금 레벨은 [zombification.md](zombification.md) 2절 표와 같다.

| 변종 | 해금 Lv | Lv5 가중치 | 능력 | 바닐라 클라이언트 외형 | 점수 |
|---|---|---|---|---|---|

## 8. 분류는 데이터로

- 계열 표의 원본은 `logic` 의 `Zombification.FAMILY`. 모드는 같은 내용을 엔티티 타입 태그로도 낸다: `#zomapo:family/skeleton`, `#zomapo:family/spider`, … `#zomapo:family/excluded`. 데이터팩으로 덮어쓸 수 있다.
- 몬스터 스포너 출신은 바꾸지 않으므로 점수 ×0.2(농장 보정)는 바닐라 좀비 스포너에만 해당한다.

## 9. 구현 메모

- 판정 지점: `Mob.finalizeSpawn` 직후(스폰 이유와 위치를 안다). `NATURAL` 인데 위치가 스폰 목록을 덮어쓰는 구조물 안이면 '구조물 스폰 목록'으로 본다(`StructureManager` 로 확인).
- 상태는 Fabric 데이터 부착으로 저장: `ZombifiedData{family, spawnLevel, origin, allergyStage}`. 저장되는 부착이라 청크를 다시 불러와도 유지된다. AI 목표(goal)는 저장되지 않으므로 불러올 때 부착을 보고 다시 붙인다.
- 언데드 처리: `LivingEntity.isInvertedHealAndHarm()`, `canBeAffected(독·재생)`, 강타 대상 판정에 부착 여부를 더하는 믹스인.
- 바닐라 짝 교체(호글린 → 조글린, 피글린 → 좀비화 피글린)는 바닐라 `convertTo` 경로를 써서 장비·이름을 옮긴다.
- 특수 공격의 피해 유형은 바닐라 것을 그대로 쓴다(발사체 보호·폭발 보호가 먹히게).
- `courierpost_bird` 태그가 있는 닭(couriersRoost 전서구)은 좀비 기수·변환 대상에서 뺀다.
