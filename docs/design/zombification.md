# 좀비화 (감염 레벨)

몹이 처음부터 전부 좀비인 것은 아니다. 땅마다 **감염 레벨**이 있고, 레벨이 높을수록 몬스터가 좀비 계열로 바뀌어 나올 확률과 변종의 종류·수가 늘어난다.

## 1. 용어

| 용어 | 뜻 |
|---|---|
| 감염 레벨 Z | 0.0 ~ 5.0 실수. 화면에는 `Lv = floor(Z)` 로 표시 |
| 영역 레벨 | 청크가 속한 영역(영토·접경·황야·특수)에 따라 정해지는 레벨 |
| 스폰 레벨 | 실제 몹이 생성될 때 쓰는 레벨. 영역 레벨에 근처 플레이어의 장비 수준을 반영한 값 |
| 국가 열기 H | 최근 7일 동안 그 국가가 얼마나 좀비를 '끌어모았는지'. 활동 국민 1인당 처치 수 기반 |
| 정화 | 레벨을 일시적으로 낮추는 플레이어 행동의 효과 |

## 2. 레벨별 효과

레벨 사이 값은 선형 보간한다(예: Z = 2.5 이면 변환 확률 47.5%).

| Lv | 몬스터 → 좀비 변환 확률 | 몬스터 상한 배율 | 새로 등장하는 변종 | 블러드문 규모 | 분위기 |
|---|---|---|---|---|---|
| 0 | 0% | ×1.0 | 없음 (바닐라 좀비 계열만) | — | — |
| 1 | 15% | ×1.2 | 러너 | 소 | 경계 진입 시 액션바 |
| 2 | 35% | ×1.4 | 비명꾼, 토사자 | 소 | 가끔 포자 파티클 |
| 3 | 60% | ×1.6 | 팽창체, 굴착꾼 / **감염 둥지 출현** | 중 | 밤에 좀비 울음 앰비언트 |
| 4 | 85% | ×1.8 | 탱커, 잠복자 | 중 | 마을 좀비화 가속 |
| 5 | 100% | ×2.0 | 알파 | 대 + 알파 | 일부 좀비가 모자를 쓰고 나와 햇빛에 타지 않음 |

- 레벨과 무관하게 **좀비 계열 자연 스폰 가중치는 항상 ×2** 다("좀비가 많이 나오는" 기본 분위기).
- 변환 대상과 변종 상세는 [mobs.md](mobs.md).

## 3. 산정식 (채택안: 하이브리드)

```
영역 레벨  Z_area  = clamp( G(t) + k·H(국가) − 정화 + 영역 보정 , 0, 5 )
스폰 레벨  Z_spawn = clamp( Z_area , P − 1 , 솔로면 P + 1.5 아니면 5 )
```

### 3-1. 전역 램프 G(t): 아포칼립스가 진행된다

```
G(t) = 2.0 × (1 − e^(−day/30)) − 치료제 보정 − 이벤트 보정
```

- 개장일 0, 2주 0.75, 4주 1.21, 6주 1.51, 10주 1.81. 서버 전체에 같은 값이다.
- 치료제 연구 단계가 하나 끝날 때마다 영구 −0.1, 블러드문 방어 성공 시 7일간 −0.1([decisions.md](../server/decisions.md) 4번).

### 3-2. 국가 열기 H: 활동이 좀비를 끌어들인다

```
H = ln( 1 + K7 / max(1, N7) / 100 )
K7 = 최근 7일 국민 전원의 좀비 처치 수 합
N7 = 최근 7일 동안 1시간 이상 접속한 국민 수
k  = 2.0 (기본값)
```

원래 아이디어("소속 국가의 좀비 스코어나 처치 수를 기준으로 영토와 주변 청크의 레벨을 올린다")를 그대로 살리되 세 가지를 바꿨다.

| 바꾼 점 | 이유 (시뮬레이션 근거는 [simulation.md](../server/simulation.md) 2-3) |
|---|---|
| **누적 대신 최근 7일** | 누적은 끝없이 올라 시즌 후반에 모든 영토가 상한에 붙는다. 6주차 3.0 → 10주차 4.6~4.8. 쉬었다 돌아온 국가가 감당 못 할 레벨에서 시작하는 문제도 있다 |
| **전원 대신 활동 국민 1인당** | 접속이 거의 없는 국민(점수 0)이 평균·중앙값을 끌어내린다. 중앙값은 국가 간 격차가 가장 크게(2.7~3.2 레벨) 벌어졌다. 합계는 인원 수에 묶여 15명 → 10명이면 레벨이 절반 이하가 된다 |
| **스코어 대신 처치 수, 그리고 로그** | 스코어는 레벨이 높을수록 처치당 점수가 커져 '레벨↑ → 스코어↑ → 레벨↑'로 스스로 증폭한다. 처치 수에 로그를 씌워 많이 잡을수록 증가 폭이 줄게 했다 |

예: 활동 국민 2명이 일주일에 380마리를 잡으면 `ln(1 + 190/100) = 1.06`, `k·H = 2.1`.

### 3-3. 정화: 레벨을 낮출 수단

| 행동 | 효과 | 지속 |
|---|---|---|
| 국가 단체 활동 | `min(1.0, 0.12 × √(최근 7일 국민 2명 이상이 함께 있던 시간))` 만큼 영토 레벨 감소 | 7일 이동 창 |
| 감염 둥지 파괴 | 둥지 반경 3청크 −0.3 | 7일 |
| 블러드문 방어 성공 | 참여자 국가 영토 −0.3 (+ 전역 −0.1) | 7일 |

정화는 "열심히 하면 무조건 어려워진다"는 느낌을 막는다. 많이 잡되 함께 잡고, 둥지를 치우면 레벨이 안정된다.

### 3-4. 영역 보정

| 영역 | 레벨 |
|---|---|
| 자국 영토 | `G + k·H − 정화` |
| 접경 (영토 경계에서 4청크 이내) | `0.7 × 영토 레벨 + 0.3 × 황야 레벨`. 두 국가의 접경이 겹치면 큰 값 |
| 황야 (누구의 영토·접경도 아님) | `G + 0.3`. 아포칼립스에서 야생이 가장 안전하면 이상하다 |
| 거점·폐허 | 주변 영역 레벨 + 1.0 |
| 감염 둥지 반경 2청크 | 최소 Lv3 |
| 생존자 캠프(중앙) | 0 고정, 적대 몹 스폰 없음 |
| 네더 | `min(4, G + 0.5)`. 피글린은 변환 상한 50%(물물교환 보호) |
| 엔드 | 0 (엔더맨·셜커는 변환 대상이 아니라 영향 없음) |

### 3-5. 개인 숙련도 보정

스폰 레벨은 몹이 생기는 자리의 영역 레벨을 근처(반경 48블록) 플레이어의 장비 점수 P 쪽으로 당긴다.

- **하한 P − 1**: 좋은 장비를 갖춘 사람 주변은 너무 쉬워지지 않는다. 대신 처치당 점수도 오른다.
- **상한 P + 1.5 (솔로일 때만)**: 반경 48블록 안에 자국민·동맹이 없을 때만 적용. 갓 들어온 사람이나 쉬었다 돌아온 라이트 유저가 활동 많은 국가의 높은 레벨에 그대로 맞지 않게 한다.
- 함께 있으면 상한이 풀리므로, 레벨이 높은 땅은 같이 가는 것이 이득이다.

시뮬레이션에서 '너무 쉬움' 비율을 35% → 15%(15명), 29% → 8%(10명)로 줄였다.

**장비 점수 P (0~5)**

```
P = 5 × ( 0.5·A + 0.3·W + 0.2·E )
A = min(1, (방어력 + 방어 강도) / 32)          네더라이트 풀세트 = 1
W = min(1, (주무기 공격력 − 1) / 7)            네더라이트 검 = 1
E = min(1, 인첸트 레벨 합 / 30 + 스타 합 / 60)
```

| 장비 | P |
|---|---|
| 맨몸 + 나무 검 | 0.6 |
| 가죽 풀세트 + 돌 검 | 1.4 |
| 철 풀세트 + 철 검 | 2.2 |
| 다이아 풀세트 + 다이아 검 + 인첸트 조금 | 3.8 |
| 네더라이트 풀세트 + 인첸트·강화 다수 | 5.0 |

## 4. 감염 둥지

- 영역 레벨 3 이상인 황야·접경에, 국가마다 3일에 하나꼴로 생긴다(최대 동시 2개). 영토 안에는 생기지 않는다.
- 바닐라 블록 구조물: 스컬크 덩굴, 진흙, 뼈 블록 사이에 **좀비 스포너**가 박혀 있다. 스포너는 해당 레벨의 변종을 섞어 낸다.
- 스포너를 부수면 파괴 처리: 좀비 스코어 보너스 30점(참여자 분배), 반경 3청크 정화, 치료제 연구 재료(둥지 핵) 드랍.
- 누군가 반경 32블록 안에 처음 들어가면 지도에 표시되고 디스코드에 알린다.

## 5. 블러드문과 호드

| 항목 | 규칙 |
|---|---|
| 시각 | 매주 토요일 21:00 (2주차부터). 설정 가능 |
| 길이 | 실시간 30분. 시작 시 시간을 한밤으로 맞추고 30분 동안 낮밤 흐름을 멈춘 뒤 새벽으로 넘긴다 |
| 표시 | 보스바 "블러드문" (빨강 `#FF0045`), 시작 시 타이틀, 뇌우 |
| 수면 | 불가 |
| 호드 | 3파. 접속자마다 주변(또는 소속 국가 수도)에 웨이브 생성. 1파 8마리 × 레벨 보정, Lv4 이상이면 3파에 알파 |
| 참여 | 국가 구분 없이 근처 누구나 함께 막을 수 있다. 성공 판정은 웨이브 종료 시 해당 지역 생존자 1명 이상 + 코어 블록(수도 깃발) 무사 |
| 보상 | 참여자 전원 좀비 스코어 보너스, 정화(3-3), 바이러스 결정 |

시뮬레이션상 국가 단위로만 모이게 하면 블러드문 단체참여율이 13~23% 에 그친다. 그래서 국가 구분 없이 함께 막을 수 있게 했다.

비명꾼 변종이 플레이어를 발견하면 반경 32블록 좀비가 몰려오는 **미니 호드**가 생긴다. 블러드문 외의 긴장 요소다.

| 접속할 때 | 채팅 1줄 | `오늘 우리 영토 감염도 2.8 (어제 2.5)` |
| 매일 06:00 재계산 | 디스코드 상태 채널 | 국가별 영토 레벨, 전역 램프, 서버 감염도 |

## 7. 원안 쪽으로 되돌리고 싶을 때

"활동이 많은 국가가 확실히 더 어려워져야 한다"는 원래 의도를 더 세게 원하면 아래 손잡이를 돌린다. 모두 설정값이다.

| 손잡이 | 효과 |
|---|---|
| `heat.k` ↑ (2.0 → 3.0) | 활동량에 따른 레벨 차이가 커진다 |
| `heat.window_days` ↑ (7 → 14) | 누적에 가까워진다(반응이 느려짐) |
| `heat.per_active` = false | 국민 수가 많은 국가가 더 어려워진다(합계 방식) |
| `heat.metric` = score | 스코어 기준(자기 증폭 위험, 로그 유지 권장) |
| `ramp.amplitude` ↓ | 시간에 따른 공통 상승을 줄이고 국가 차이를 키운다 |

## 8. 구현 메모

- 청크마다 값을 저장하지 않는다. 영역 레벨은 `(전역 램프, 국가별 H·정화, 영토·접경 판정, 희소한 이벤트 보정 목록)` 으로 즉석 계산하고, 국가별 접경 청크 집합은 영토가 바뀔 때만 BFS 로 다시 만든다.
- 저장: `SavedData` 하나(`zomapo_infection`). 전역 램프 보정, 국가별 일일 스냅샷(K7·N7·H·정화·레벨 이력), 이벤트 보정 목록(종류, 범위, 값, 만료), 둥지 목록.
- 갱신: 매일 06:00 에 국가별 H 를 다시 계산하고, 이벤트 보정은 발생 즉시 반영한다.
- 시간 기준: 06:00 재계산, 블러드문 30분, 정화 7일 만료는 **실제 시간** 기준 스케줄러로 돈다. 게임 틱 기준으로 돌리면 렉이 걸릴 때 블러드문이 길어진다(monun tap `Ticker` 의 flex 모드와 같은 생각).
- 식 자체(전역 램프, H, 정화, 개인 보정, 장비 점수)는 마인크래프트 의존이 없는 `logic` 모듈에 두고 단위 테스트한다([architecture.md](../tech/architecture.md) 3절).
- 관리자 명령: `/zomapo level get|set|clear`, `/zomapo bloodmoon start|stop`, `/zomapo nest spawn`, `/zomapo reload`, `/zomapo debug spawn <변종>`.
- 국가·영토 정보는 simpleNationWar 의 `snw-api` 로 읽는다. simpleNationWar 가 없으면 모든 땅을 황야로 본다.
