# 좀비화 (감염 레벨)

몹이 처음부터 전부 좀비인 것은 아니다. 땅마다 **감염 레벨**(0~5)이 있고, 레벨이 높을수록 좀비가 많아지고 강해지며, 더 많은 종류의 몬스터가 좀비화된다.

## 1. 용어

| 용어 | 뜻 |
|---|---|
| 감염 레벨 Z | 0.0 ~ 5.0 실수. 화면에는 `Lv = floor(Z)` 로 표시 |
| 영역 레벨 | 청크가 속한 영역(영토·접경·황야·특수)에 따라 정해지는 레벨 |
| 스폰 레벨 | 개체가 태어난 청크의 정수 레벨(좀비 떼는 목표 플레이어 청크). 개체에 저장되어 평생 따라간다 |
| 국가 열기 H | 최근 72시간(현실 시간) 동안 그 국가가 얼마나 좀비를 '끌어모았는지'. 활동 국민 1인당 처치 수 기반 |
| 정화 | 레벨을 일시적으로 낮추는 플레이어 행동의 효과 |

## 2. 레벨별 효과

2026-11-20 개편. 굵은 글씨는 운영자가 정한 규칙, (제안) 표시는 설계 쪽 추천이다. 코드: `logic` 모듈 `spawn/LevelRules.kt`, `spawn/Zombification.kt`.

- **레벨은 0~5 정수.** 청크 레벨(소수, 3절 식)을 내림한 값이다.
- 개체의 **스폰 레벨** = 태어난 청크의 레벨(좀비 떼는 목표 플레이어가 있는 청크의 레벨). 개체에 저장되고, 다른 레벨의 청크로 걸어가도 바뀌지 않는다.

| Lv | 밤 좀비 스폰률 | 낮 지상 스폰 | 햇빛 | 태양광 알레르기 (낮) | 새로 좀비화되는 계열 | 좀비 강화 | 변종 |
|---|---|---|---|---|---|---|---|
| 0 | **×1.5** | 없음 | 탄다 | **4단계**: 체력·이속 −25%, 탐지 거리 ÷1.6 | 없음 (바닐라와 같음) | — | 일반 |
| 1 | **×1.6** | 없음 | 탄다 | **3단계**: −20%, ÷1.5 | **스켈레톤 계열, 거미 계열** | (제안) 탐지 +10% | + 러너 |
| 2 | **×1.7** | **밤의 0.1배** | **안 탐** | **2단계**: −15%, ÷1.4 | **크리퍼, 엔더맨, 크리킹, 슬라임** + (제안) 팬텀 | (제안) 탐지 +15%, 증원 ×1.5, 방어구 확률 +5%p | + 비명꾼, 토사자 |
| 3 | **×1.8** | **밤의 0.1배** | **안 탐** | **1단계**: −10%, ÷1.3 | **좀벌레, 우민, 가디언, 브리즈, 셜커, 네더 몹** + (제안) 엔더마이트, 마녀 | (제안) 탐지 +20%, 증원 ×2, 방어구 +10%p, 난이도 무관 문 부수기 | + 팽창체, 굴착꾼 |
| 4 | **×1.9** | **밤의 0.1배** | **안 탐** | **없음** | — | **기본 체력 ×1.5** + (제안) 넉백 저항 +0.1, 아이템 줍기 | + 탱커, 잠복자 |
| 5 | **×2.0** | **밤의 0.1배** | **안 탐** | **없음** | — | **체력 ×1.5** + (제안) 이속 ×1.1, 공격력 ×1.2, 넉백 저항 +0.2 | + 알파 |

레벨 2 이상이면 **좀비 떼** 이벤트 대상이 된다(4절). 레벨 3 이상 황야에는 감염 둥지가 생긴다(5절).

### 스폰률

- **밤 좀비 스폰률 = 1.5 + 0.1 × 레벨** (바닐라 대비). '밤'은 바닐라 몬스터 스폰 조건(빛 0)을 뜻하므로 낮의 동굴·그늘에도 같은 배율이 적용된다. "기본적으로 낮에도 좀비가 나온다"는 이 부분이다.
- 구현: 몬스터 상한과 좀비 계열 스폰 가중치에 같은 배율을 곱해, **늘어난 자리를 좀비가 채운다.** 다른 몬스터 수는 바닐라와 같다.
- **낮 지상 스폰**(하늘빛이 드는 곳): 레벨 2 이상에서만, 그 레벨 밤 배율의 0.1배(×0.17~0.2) 밀도까지 zomApo 자체 스포너가 좀비를 채운다. 아래 조명 계수를 곱한다.
- **실내 스폰**(하늘이 안 보이는 곳): 낮·밤과 관계없이 **밝기 4 이상이어도 좀비가 나온다. 단 스폰률 1/4.** 바닐라는 블록 빛 0 에서만 나온다.

  | 블록 빛 | 조명 계수 (실내 스폰·낮 지상 스폰에 곱함) |
  |---|---|
  | 0~3 | ×1 (어두움) |
  | 4~11 | **×1/4** |
  | 12 이상 | ×0 (제안: 발광석·바다 랜턴·랜턴 바로 옆처럼 아주 밝은 곳은 안전 구역) |

  실내 스폰률 = 그 레벨 밤 배율 × 조명 계수. 횃불(빛 14) 바로 옆은 안전하지만, 횃불에서 3~10칸 떨어진 빛 4~11 구역에는 가끔 나온다. 기지는 밝게, 구석까지 비추면 안전하다.

### 햇빛과 태양광 알레르기

- **레벨 2 이상에서 태어난 좀비는 햇빛에 타지 않는다.** 레벨 0~1 출신은 바닐라처럼 탄다(투구·그늘·물 예외 그대로).
- **태양광 알레르기**: 낮(게임 시간 0~12,000) 동안 **모든 좀비**(좀비화 몹 포함, 망자 제외)에 걸린다. 단계 = 4 − 스폰 레벨.
  - **구현: 자체 상태 효과 `zomapo:sun_allergy`.** 효과 증폭값 = 단계 − 1. 체력·이속·탐지 거리 속성 수정자를 효과가 직접 건다. `/effect` 로 걸고 뗄 수 있고, 몹 정보에 효과로 보인다.
  - 바닐라 클라이언트는 이 효과를 모른다. 효과는 몹에만 걸리고(플레이어에게 걸릴 일이 없다) 파티클을 끄므로 클라이언트에 효과 id 가 전달되지 않는다. 안전장치로 Polymer core 의 상태 효과 숨김을 쓴다(리소스팩과 무관한 서버 라이브러리).

  | 단계 | 출신 레벨 | 체력·이동 속도 | 탐지 거리 |
  |---|---|---|---|
  | 4 | 0 | −25% | ÷1.6 |
  | 3 | 1 | −20% | ÷1.5 |
  | 2 | 2 | −15% | ÷1.4 |
  | 1 | 3 | −10% | ÷1.3 |
  | 없음 | 4·5 | — | — |

  식: 단계 k 에서 n = k − 1 로 두고 −(10 + 5n)%, ÷(1.3 + 0.1n). 체력 상한이 바뀔 때 현재 체력을 같은 비율로 옮긴다(낮에 깎였다가 밤이 됐다고 저절로 차오르지 않게).
- 결과적으로 **낮은 나가서 일하는 시간, 밤은 버티는 시간**이 된다. 레벨 4 이상 땅은 낮에도 약해지지 않으므로 장비가 갖춰져야 들어갈 수 있다.
- (대안) 알레르기를 하늘빛이 닿는 곳에만 걸 수도 있다. 지금은 요구대로 낮이면 어디서나 건다.

### 좀비화 (계열별 상세는 [mobs.md](mobs.md))

- 계열마다 정해진 레벨 이상 청크에서 **야생 자연 스폰**된 개체가 좀비화된다(확률 없이 전부). 좀비화 = 원종 엔티티를 그대로 두고 좀비 특성·외형·좀비 루트테이블을 더하는 것.
- 구조물·스포너·습격·시련 스포너 출신은 바닐라 그대로. 예외는 가디언·슬라임(요구), 브리즈·셜커·블레이즈·위더 스켈레톤(구조물에서만 나오는 몹이라 같은 예외로 둠).

### 2-1. 부하 연동 상한 (안전장치)

몬스터 상한 배율은 서버 틱 시간에 따라 자동으로 줄인다. 동시 접속 15명 이상이 넓은 월드에 흩어지면 틱 예산(50ms)을 넘을 수 있어서다([performance.md](../server/performance.md) 3-2·9절).

| 최근 1분 틱 중앙값 | 스폰률(밤·낮)에 곱하는 값 | 좀비화 규칙 |
|---|---|---|
| 35ms 미만 | ×1.0 | 그대로 |
| 35~45ms | ×0.8 | 그대로 |
| 45ms 이상 | ×0.6 | 그대로 (규칙은 유지하고 수만 줄인다) |

- 30초마다 판정하고, 내릴 때는 바로, 올릴 때는 2분 연속 여유가 있을 때만(오르내림 반복 방지).
- 블러드문 웨이브와 좀비 떼 크기에도 같은 값을 곱한다(떼는 최소 5마리).
- 발동하면 운영자 로그에만 남긴다. 플레이어에게 알리지 않는다.

## 3. 산정식 (채택안: 하이브리드)

```
영역 레벨  Z_area  = clamp( G(t) + k·H(국가) − 정화 + 영역 보정 , 0, 5 )
규칙 레벨  L       = floor( Z_area )            ← 2절의 모든 규칙은 이 정수 레벨로
```

### 3-1. 전역 램프 G(t): 아포칼립스가 진행된다

```
G(t) = 2.0 × (1 − e^(−day/10)) − 치료제 보정 − 이벤트 보정      day = 개장 후 현실 일수
```

- 개장일(1/16) 0, 1주(1/23) 1.01, 2주(1/30) 1.51, 3주(2/6) 1.76. 서버 전체에 같은 값이다. 23일 시즌에 맞춰 시간 상수를 30일에서 10일로 줄였다.
- 치료제 단계가 하나 끝날 때마다 영구 −0.3, 블러드문 방어 성공 시 72시간 −0.1([bloodmoon-and-cure.md](bloodmoon-and-cure.md)).

### 3-2. 국가 열기 H: 활동이 좀비를 끌어들인다

```
H = ln( 1 + K3 / max(1, N3) / 40 )
K3 = 최근 72시간 국민 전원의 유효 좀비 처치 수 합
N3 = 최근 72시간 동안 1시간 이상 접속한 국민 수
k  = 1.8 (시뮬레이션 보정값: 20명/활성 10명에서 1/29 평균 영토 레벨 3.0 → 1.81. 이전 기준 15명/활성 4명에서도 1.79)
```

원래 아이디어("소속 국가의 좀비 스코어나 처치 수를 기준으로 영토와 주변 청크의 레벨을 올린다")를 그대로 살리되 세 가지를 바꿨다.

| 바꾼 점 | 이유 (시뮬레이션 근거는 [simulation.md](../server/simulation.md) 3절) |
|---|---|
| **누적 대신 최근 72시간** | 누적은 끝없이 올라 시즌 마지막 주에 모든 영토가 상한에 붙는다. 1/29 에 3.0 으로 맞춰도 2/5 에 4.2~5.0. 쉬었다 돌아온 국가가 감당 못 할 레벨에서 시작하는 문제도 있다. 창은 시즌이 3주라 7일이 아니라 72시간(현실 시간) |
| **전원 대신 활동 국민 1인당** | 접속이 거의 없는 국민(점수 0)이 평균·중앙값을 끌어내린다. 중앙값은 국가 간 격차가 가장 크게(3.2 레벨) 벌어졌다. 합계는 인원 수에 묶여 20명에 맞춘 계수로 15명이면 1/29 레벨 0.9, 23명이면 4.3 이 된다 |
| **스코어 대신 처치 수, 그리고 로그** | 스코어는 레벨이 높을수록 처치당 점수가 커져 '레벨↑ → 스코어↑ → 레벨↑'로 스스로 증폭한다. 처치 수에 로그를 씌워 많이 잡을수록 증가 폭이 줄게 했다 |

예: 활동 국민 2명이 72시간 동안 160마리를 잡으면 `ln(1 + 80/40) = 1.10`, `k·H = 2.0`.

### 3-3. 정화: 레벨을 낮출 수단

| 행동 | 효과 | 지속 |
|---|---|---|
| 국가 단체 활동 | `min(1.0, 0.18 × √(최근 72시간 국민 2명 이상이 함께 있던 시간))` 만큼 영토 레벨 감소 | 72시간 이동 창 |
| 감염 둥지 파괴 | 둥지 반경 3청크 −0.3 | 72시간 |
| 블러드문 방어 성공 | 참여자 국가 영토 −0.3 (+ 전역 −0.1) | 72시간 |

기간은 모두 현실 시간이다.

정화는 "열심히 하면 무조건 어려워진다"는 느낌을 막는다. 많이 잡되 함께 잡고, 둥지를 치우면 레벨이 안정된다.

### 3-4. 영역 보정

| 영역 | 레벨 |
|---|---|
| 자국 영토 | `G + k·H − 정화` |
| 접경 (영토 경계에서 4청크 이내) | `0.7 × 영토 레벨 + 0.3 × 황야 레벨`. 두 국가의 접경이 겹치면 큰 값 |
| 황야 (누구의 영토·접경도 아님) | `G + 0.3`. 아포칼립스에서 야생이 가장 안전하면 이상하다 |
| 거점·폐허 | 주변 영역 레벨 + 1.0 |
| 감염 둥지 반경 2청크 | 최소 Lv3 |
| 생존자 캠프(중앙) | 0 고정, 적대 몹 스폰 없음 |
| 네더 | **탐험한 비율에 비례: 기본 0, 네더(1,000 × 1,000 = 63 × 63 청크)의 절반을 탐험하면 3.** 여기에 **플레이어의 좀비 스코어를 중심으로** 그 주변 레벨이 오른다(아래 3-6). 피글린은 좀비화 상한 50%(물물교환 보호). 해가 없으므로 낮 스폰·알레르기·좀비 떼는 없다 |
| 엔드 | 3 고정. 셜커·엔더맨이 좀비화된다(원종 드랍인 셜커 껍데기·엔더 진주는 그대로 나온다). 엔더 드래곤은 제외. 좀비 떼·낮 스폰 없음 |

### 3-6. 네더 레벨

```
네더 레벨 = clamp( 기본 + 근처 보너스 , 0, 5 )
기본       = 6 × (탐험한 청크 / 3,969)            절반 탐험이면 3, 83% 이상이면 5
근처 보너스 = max over 반경 128 안 플레이어 [ ln(1 + 좀비 스코어 / 1,500) (최대 1.5) × 거리 감쇠 ]
거리 감쇠   = 32블록 안 1, 128블록에서 0 (선형)
```

- '탐험함'은 플레이어가 선 청크 기준 반경 2청크(5 × 5)를 표시한 누적. 네더를 사전 생성해도 생성은 탐험으로 치지 않는다.
- 좀비 스코어가 높은 사람이 다니는 곳일수록 네더가 더 깊어진다(1,500점 +0.7, 3,000점 +1.1, 6,000점 이상 +1.5). 여럿이 모여도 가장 큰 보너스 하나만 더한다.
- 보너스는 사람을 따라다니므로, 몹이 태어날 때의 값이 그 몹의 스폰 레벨로 굳는다.
- 판정 코드: `logic` 의 `NetherLevels`.

**서버 부하**: 청크마다 레벨을 저장·갱신하지 않는다.

| 작업 | 언제 | 비용 |
|---|---|---|
| 탐험 표시 | 플레이어가 네더에서 다른 청크로 넘어갈 때(초당 몇 번) | 63 × 63 비트맵(약 500바이트)에 25칸 표시. 무시할 수준 |
| 레벨 계산 | 네더 몹이 태어날 때(초당 수십 번 이하), 액션바 표시(사람마다 2초에 한 번) | 반경 128 안 플레이어 몇 명의 거리·점수 계산. 1틱의 0.01ms 미만 |
| 지도 표시 | 하루 한 번 | 웹 지도 네더 레이어는 '기본' 값만 그린다(보너스는 사람을 따라다녀 그리지 않음) |

청크마다 값을 저장해 매 틱 퍼뜨리는 방식(열 확산)은 쓰지 않는다. 그쪽은 로드된 청크 수 × 틱만큼 비용이 들고, 네더처럼 작은 차원에서도 이유 없이 무겁다.

### 3-5. 개인 숙련도 보정: 폐지

2026-11-20 개편에서 뺐다. 모든 규칙(스폰률, 연소, 알레르기, 좀비화 계열, 좀비 떼)을 **청크 레벨 하나로** 정해, 플레이어가 "여기는 Lv3 이니까 낮에도 나오고 안 탄다"를 예측할 수 있게 한다. 초보·복귀 유저 보호는 개인 스폰 지점(자국 영토 안), 리스폰 직후 보호, 좀비 떼 개인 쿨다운(15분)이 맡는다.

## 4. 좀비 떼 (전역 이벤트)

| 항목 | 규칙 |
|---|---|
| 시도 | **서버 전체에서 6,000틱(현실 5분)마다 1번** |
| 조건 | **오버월드 접속자가 3명 이상일 때만 시도한다.** 혼자·둘이 노는 시간은 쉬는 시간(20명/활성 10명 기준 플레이 시간의 27%, 17/8 35%, 23/12 21%) |
| 대상 | **레벨 2 이상 청크에 있는 플레이어 중 무작위 1명**. 오버월드만. 생존자 캠프·리스폰 보호 중·최근 15분 안에 떼를 맞은 사람(제안)은 뺀다 |
| 성공 확률 | **10 + 2n %** (n = 대상이 있는 청크 레벨): Lv2 14%, Lv3 16%, Lv4 18%, Lv5 20% |
| 규모 | **5+n ~ 10+n 마리**: Lv2 7~12, Lv3 8~13, Lv4 9~14, Lv5 10~15 |
| 좀비의 레벨 | **목표 플레이어 청크의 레벨**을 따른다(알레르기·연소·체력·변종) |
| 등장 | (제안) 목표에서 24~40블록, 시야 밖 땅 위. 나타나기 5초 전 먼 울음소리. **두 무리로 15초 간격** |
| 어그로 | **목표 플레이어 고정**, 탐지 거리 48 로 늘림. 목표가 죽거나 접속을 끊으면 일반 좀비로 돌아간다 |
| 보상 | (제안) 3분 안에 80% 이상 쓰러뜨리면 그 자리에 **보급 상자**(음식, 화살, 철·금 조각, 레벨 비례 바이러스 결정). 생존일지에 기록 |

**빈도**: 시도가 서버 전체에 한 번이라, 대상 후보가 많을수록 한 사람이 맞는 빈도는 줄어든다(혼자 놀 때 더 자주).

| 레벨 2 이상에 있는 사람 (접속 3명 이상일 때) | Lv3 기준 서버 전체 떼 | 한 사람이 맞는 간격 |
|---|---|---|
| 1명 | 시간당 1.9번 (약 31분마다) | 약 31분 |
| 3명 | 시간당 1.9번 | 약 1시간 34분 |
| 6명 | 시간당 1.9번 | 약 3시간 8분 |

- 접속 2명 이하를 빼는 이유: 그대로 두면 혼자 노는 사람이 31분마다 떼를 맞는다. 혼자일 때는 둥지·보름달 밤·탐험으로 충분하다.
- (선택) 사람이 많을 때도 체감을 유지하고 싶으면 시도 횟수를 `1 + ⌊(후보 수 − 1) / 3⌋` 로 늘린다. 기본은 요구대로 1번.
- **두 무리로 나눠 보내는 이유**: 철 갑옷 플레이어(방어력 15)는 Lv3 좀비 한 대에 약 2.2 피해를 받는다. 13마리가 한꺼번에 붙으면 1~2초 만에 쓰러진다. 7마리 + 6마리 두 번이면 길목에서 받아칠 시간이 생긴다.

## 5. 감염 둥지


- 영역 레벨 3 이상인 황야·접경에, 국가마다 하루에 하나꼴로 생긴다(국가당 최대 동시 2개). 영토 안에는 생기지 않는다.
- 바닐라 블록 구조물: 스컬크 덩굴, 진흙, 뼈 블록 사이에 **좀비 스포너**가 박혀 있다. 스포너는 해당 레벨의 변종을 섞어 낸다.
- 스포너를 부수면 파괴 처리: 좀비 스코어 보너스 30점(참여자 분배), 반경 3청크 정화, 그 지역의 **지역 표본** 드랍(치료제 재료, [bloodmoon-and-cure.md](bloodmoon-and-cure.md) 2-3).
- 누군가 반경 32블록 안에 처음 들어가면 지도에 표시되고 디스코드에 알린다.

> **검토 중인 제안.** 상세 비교와 근거는 [bloodmoon-and-cure.md](bloodmoon-and-cure.md) 1절.

| 항목 | 보름달 밤 (소) | 블러드문 (대) |

| 시간 기준 | 게임 시간: 8 게임일마다(접속이 이어지는 동안 현실 약 2시간 40분마다) | 현실 시간: 19:00~24:00 사이 5명 이상·3개 국가 모두 접속 시 발동, 48시간 쿨다운, 72시간 무발동 시 21시 강제 |

| 길이 | 게임 밤 한 번(현실 약 7분) | 현실 30분. 시작 시 한밤으로 맞추고 낮밤 흐름 정지 |

## 8. 원안 쪽으로 되돌리고 싶을 때

"활동이 많은 국가가 확실히 더 어려워져야 한다"는 원래 의도를 더 세게 원하면 아래 손잡이를 돌린다. 모두 설정값이다.

| 손잡이 | 효과 |
|---|---|
| `heat.k` ↑ (1.8 → 2.7) | 활동량에 따른 레벨 차이가 커진다 |
| `heat.window_hours` ↑ (72 → 168) | 누적에 가까워진다(반응이 느려짐) |
| `heat.per_active` = false | 국민 수가 많은 국가가 더 어려워진다(합계 방식) |
| `heat.metric` = score | 스코어 기준(자기 증폭 위험, 로그 유지 권장) |
| `ramp.amplitude` ↓ | 시간에 따른 공통 상승을 줄이고 국가 차이를 키운다 |

## 9. 구현 메모

- 청크마다 값을 저장하지 않는다. 영역 레벨은 `(전역 램프, 국가별 H·정화, 영토·접경 판정, 희소한 이벤트 보정 목록)` 으로 즉석 계산하고, 국가별 접경 청크 집합은 영토가 바뀔 때만 BFS 로 다시 만든다.
- 저장: `SavedData` 하나(`zomapo_infection`). 전역 램프 보정, 국가별 일일 스냅샷(K3·N3·H·정화·레벨 이력), 이벤트 보정 목록(종류, 범위, 값, 만료), 둥지 목록.
- 갱신: 매일 06:00 에 국가별 H 를 다시 계산하고, 이벤트 보정은 발생 즉시 반영한다.
- 시간 기준: 06:00 재계산, 블러드문 30분, 정화 72시간 만료는 **실제 시간** 기준 스케줄러로 돈다. 보름달 밤만 게임 시간(달 위상)을 따른다. 게임 틱 기준으로 돌리면 렉이 걸릴 때 블러드문이 길어진다(monun tap `Ticker` 의 flex 모드와 같은 생각).
- 식 자체(전역 램프, H, 정화, 레벨별 규칙, 좀비화 판정, 좀비 떼)는 마인크래프트 의존이 없는 `logic` 모듈에 두고 단위 테스트한다([architecture.md](../tech/architecture.md) 3절).
- 관리자 명령: `/zomapo level get|set|clear`, `/zomapo bloodmoon start|stop`, `/zomapo horde <플레이어>`, `/zomapo nest spawn`, `/zomapo reload`, `/zomapo debug spawn <변종>`.
- 알레르기는 낮/밤이 바뀔 때와 개체가 불려 올 때 속성 수정자(`zomapo:sun_allergy`)를 붙이거나 뗀다. 매 틱 검사하지 않는다.
- 국가·영토 정보는 simpleNationWar 의 `snw-api` 로 읽는다. simpleNationWar 가 없으면 모든 땅을 황야로 본다.
