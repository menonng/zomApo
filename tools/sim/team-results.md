# 국가 편성 방식 비교

runs=2000 (편성 지표), 시즌 접속 150회, seed=20270116. 별점 = 상호평가 5항목 평균(활동량과 상관 0.45, 측정 오차 0.2).
단짝 = 서로 지목한 쌍(인원의 약 70%가 짝을 가짐), 단짝은 접속을 맞추는 경향(같이 접속할 확률 ×1.3, 60% 는 시각도 맞춤).

지표: 별점 격차 = 국가 평균 별점 최대-최소, 활동량 격차 = 국가 총 플레이 시간 (최대-최소)/평균, 약소국 몫 = 가장 적은 국가의 플레이 시간 비중(33%가 완벽),
핵심 격차≥2 = 하루 2시간+ 유저 수가 2명 이상 차이 날 확률, 함께 접속 = 접속 시간 중 같은 국가 사람이 함께 있던 비율.
